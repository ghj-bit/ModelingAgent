# Planning drafts

`draft.md` blueprints produced by the clean-baseline initial-draft stage.
The interaction-workflow evolution launcher starts every solver from these,
so they are inputs to the experiment rather than its output.

One directory per MM-Bench task:

```
planning_drafts/
  2014_C/draft.md
  2015_A/draft.md
  ...
```

Copied from `openclaw_experiments/interaction_strategy_clean_baseline_initial_draft_mmbench_*`
(`output/results/draft.md` of each run), keyed by the `problem_id` recorded in
that run's `meta/run.json`.
