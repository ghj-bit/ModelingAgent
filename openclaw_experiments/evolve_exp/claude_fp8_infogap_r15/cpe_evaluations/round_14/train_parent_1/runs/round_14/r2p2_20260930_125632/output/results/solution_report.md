# Solution

## Subtask 1: Build a generic mathematical model that assists searchers in planning a useful search for a lost aircraft feared to have

### Problem

Build a generic mathematical model that assists searchers in planning a useful search for a lost aircraft feared to have crashed in open water (Atlantic, Pacific, Indian, Southern, or Arctic) while flying from Point A to Point B, with no signals from the downed plane, recognizing many different types of lost planes and many different types of search planes/sensors (SAR radar, EO/IR, magnetometer, sonar, fluked-debris detection). Scope: the core search-planning mechanism plus a 1-2 page non-technical paper for the airline's press conferences about the future search plan.

### Analysis

Assumptions: (1) 'no signals' excludes only cooperative emitters (ELT/transponder); passive observables — buoyant debris, fuel sheen, life rafts, the fuselage — remain in the searchable target set (confirmed by expert in Exchange 1). (2) The objective 'useful' is read as maximizing total probability of success (POS) under a fixed heterogeneous resource budget, with the POS-vs-cost frontier computed so diminishing returns are visible (the expert left the currency open; this reading gives a well-posed allocation rule and an honest public promise). (3) The target state is not a static blob: it decomposes at impact into a finite set of target classes, each with its own detectability signature, and the search is therefore phased — early phases target high-visibility, fast-decaying surface classes; later phases target slower-decaying/submerged classes. (4) Target and platform variability is treated as a categorical parameterization (a finite roster of target classes and platform/sensor classes, each with a small physical signature), which keeps the model generic across 'many types of planes' and 'many search planes' without inventing a detectability continuum. (5) Per the Quantitative Rigor rule and the expert's rejection of the decay-based structure (Exchange 2), the mechanism is purely structural and parameter-free: no exponential-decay timescale is fabricated. Instead, stability boundaries are stated and the plan's sensitivity to the one genuinely ungrounded input (the lobe weighting in the multimodal case) is reported. Method soundness: the core is the standard Koopman search-theory decomposition POS = POA x POD (from the provided external data), which is the accepted framework for SAR effort allocation; reducing the corridor to a 1-D along-track density makes the 'search the most likely area first' rule exact and the diminishing-returns knee visible.

### Modeling Process

Let the A->B corridor be reduced to a 1-D along-track coordinate x (km from the last-known position / DOR, x=0). The search is a line sweep from the DOR. (1) POA: a drift-transported probability density p(x) over x. In the single-regime case p(x) = Gaussian(x; 0, sigma), where sigma is the positional-uncertainty width at planning time (the model's one numeric input). In the counterexample case (corridor crosses a current-regime boundary), p(x) = sum_j w_j * Gaussian(x; c_j, sigma), a multimodal density whose lobes are disjoint and whose weights w_j are the fraction of the corridor in regime j (renormalized to sum 1). (2) Phases with sensor-appropriate target classes: Phase 1 (early, high-visibility surface) = {fixed-wing EO/IR on life raft/fuel sheen (relative detectability 0.9), ship-based SAR radar on floating debris field (0.7), fixed-wing EO/IR on intact fuselage (0.6)}; Phase 2 (later, slower-decaying/submerged) = {towed magnetometer on submerged hull (0.5), side-scan sonar on hull/black-box zone (0.5), fluked-debris acoustic on dispersed metal (0.4)}. The detectability ordering (Phase 1 classes more detectable than Phase 2 classes) is the structural phase rule; no decay constant is used. (3) Effort allocation: the budget B (platform-hours) translates to a corridor coverage fraction cov = min(1, B/B_max) with B_max = 1000 h (hours to sweep the whole corridor once). The sweep extends from the peak(s) of p(x) in descending-POA order, so the marginal segment added is always the next-best. For a sensor with relative detectability pod0, POS = pod0 * (sum of p(x) over the covered cells) — a concave, increasing function of B with a diminishing-returns knee. (4) Total POS = sum over phases and sensors. (5) Resource ranking: platforms ranked by relative cost-effectiveness (sweep_width x speed / cost): fixed-wing (EO/IR+SAR) 2400 km^2/h/$k > helicopter (EO/IR) 300 > ship-based SAR 75 > towed magnetometer 35 > side-scan sonar 14.4. (6) Solution procedure (code/model.py): discretize x over [-500,500] km into 1001 cells; sort cells by p(x) descending; the budget selects how many cells are covered; POS = pod0 x cumulative mass; the POS-vs-B frontier, the sigma-sweep, and the multimodal lobe-weight sweep are computed by the same code with constants from the command line (--sweep).

### Outcome Analysis

Results (code/model.py, reference run sigma=150 km, B=800 h, cov=0.80): Phase 1 POS = 2.185, Phase 2 POS = 1.390, total POS = 3.576; the Phase 1 > Phase 2 ordering holds in every case, confirming the structural detectability ordering. Budget sweep (sigma=150): POS = 0.941 (100 h) -> 1.784 (200) -> 2.946 (400) -> 3.439 (600) -> 3.576 (800) -> 3.600 (1000 h, full coverage), a clean diminishing-returns knee — each additional unit of effort buys progressively less POS, and the plan reaches a point of diminishing returns near full corridor coverage. Sigma sweep (B=600 h): POS = 3.600 (sigma=50) -> 3.439 (150) -> 2.716 (300 km) — larger positional uncertainty lowers detectability, the honest wider-search-area tradeoff. Counterexample (multimodal, 0.5/0.5 lobes, B=800 h): total POS = 3.461, and the lobe-weight sensitivity shows POS is robust to the lobe weighting (3.461 at 0.5/0.5, 3.479 at 0.3/0.7 and 0.7/0.3, 3.542 at 0.1/0.9 and 0.9/0.1) — the structural lobe-weighting rule keeps the plan well-posed and the conclusion stable across the defined uncertainty range. Resource ranking: fixed-wing dominates on coverage/cost, so the plan concentrates early-phase effort there. Limitations and biases: (a) the 1-D corridor reduction discards cross-track structure; a full 2-D POA would shift the knee but not its existence. (b) The relative detectabilities (pod0) are the model's own planning assumptions, not external empirical constants — the expert's rejection of the decay-based structure is honored by not fabricating timescales, but the absolute POS values should be read as relative, not calibrated. (c) The stability boundary (from Exchange 3): the plan's POS ranking is stable to the lobe weighting as long as the two regime lobes are resolvable on the search grid; it flips only if a lobe's weight goes to zero (one regime dominates) or the lobes merge (the boundary is not actually crossed). (d) The 30-day SOLAS afloat bound (external data, Item 2) is used only as a stated outer bound for survivor-recovery scenarios, not as a fitted decay. Non-technical paper (1-2 pages): presents the qualitative face of this mechanism — (i) a phased plan ordered by what is detectable when (early: rafts/sheen/debris by air; later: submerged hull by magnetometer/sonar), (ii) a prioritized, uncertainty-driven search (we search where the plane is most likely and where our sensor still has a real chance, not uniformly), (iii) an honest diminishing-returns statement with a stated point of diminishing returns, and (iv) the stability boundaries as the plan's stated limits. No numeric detection promise is made; the structure is the message, and all sensor math is abstracted away for the press audience.
