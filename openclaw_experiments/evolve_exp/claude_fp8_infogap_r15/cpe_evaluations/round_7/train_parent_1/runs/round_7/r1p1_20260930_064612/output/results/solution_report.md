## Subtask 1: Part I: Develop a mathematical model for HF signal reflection off the ocean surface. For a 100-W constant-carrier signal

### Problem

Part I: Develop a mathematical model for HF signal reflection off the ocean surface. For a 100-W constant-carrier signal below the MUF from a land point source, determine the strength of the first reflection off a turbulent ocean, compare it with the strength of a first reflection off a calm ocean, and determine the maximum number of hops (with reflections 2 through n off calm oceans) before the signal strength falls below a usable 10 dB SNR threshold.

### Analysis

Assumptions, fixed by expert consultation and the supplied literature lookups: (1) one hop is one ionosphere-to-ocean-to-ionosphere cycle, so the first ocean reflection belongs to the first ionospheric hop (expert reply 1a); (2) the turbulent-vs-calm comparison quantity is the power density at the sea surface just AFTER the sea bounce, which isolates the ocean surface as the variable under test and avoids confounding the contrast with a second ionospheric absorption pass (expert reply 1b); (3) the domain is grazing-incidence, long-path skywave, single frequency, single great-circle mid-latitude path (expert reply 1c); (4) the operating frequency is f_op = 0.85 x MUF, the standard FOT practice, with MUF = 12 MHz nominal so f_op = 10.2 MHz (lookup item 2); (5) seawater complex permittivity at 35 ppt, ~15 C is eps_r = 80 - j*sigma/(omega*eps0) with ionic conductivity sigma = 4 S/m, giving a large, strongly lossy relative permittivity at HF (lookup item 1, Meissner 2004); (6) the round-trip ionospheric loss per hop is anchored on lookup item 2's statement that vertical-incidence absorption at 30 MHz is small (tenths of dB), scaled as 0.5 dB x (30 MHz/f_op)^2 with a 0.3 dB floor, so the nominal value is 4.33 dB/hop; (7) the receiver is an isotropic effective area A_e = lambda^2/(4*pi) (0 dBi gain), and the noise floor is N_0 = kTB with T = 290 K, B = 1 kHz, giving N_0 = -144 dBm; (8) the source is isotropic, 100 W (50 dBm), constant carrier. Method: a geometrical-optics (GO) link budget over a planar sea, with the per-hop recurrence S_i = S_{i-1} x A_io x |Gamma|^2 where A_io = 10^(-L_io/10) is the single round-trip ionospheric factor (the expert rejected a double down/up pass in exchange 2, so the fallback single round-trip pass is used) and |Gamma|^2 is the sea-surface squared Fresnel reflection coefficient. The equal-hop-length assumption makes the free-space spreading ratio between successive bounces exactly 1, closing the recurrence on the ionospheric and sea-surface losses alone. This is the standard HF multi-hop GO model and is sound because the expert-confirmed domain is precisely the grazing, long-path regime where GO and the flat-Fresnel limit are valid.

### Modeling Process

Seawater complex relative permittivity (lookup item 1): eps_r(f) = eps_rel - j*sigma_d/(omega*eps0), with eps_rel = 80, sigma_d = 4 S/m, omega = 2*pi*f. At f_op = 10.2 MHz: |eps_r| is large, the medium is strongly lossy, and the Fresnel coefficient is close to -1 at grazing incidence. Flat-sea Fresnel reflection coefficient (power-averaged TE+TM), for a wave in air incident at grazing angle theta_g from the surface (theta_n = 90 - theta_g from the normal): cos_t = sqrt(eps_r - sin^2(theta_n)), R_TE = (cos(theta_n) - cos_t)/(cos(theta_n) + cos_t), R_TM = (eps_r*cos(theta_n) - cos_t)/(eps_r*cos(theta_n) + cos_t), |Gamma|^2 = 0.5*(|R_TE|^2 + |R_TM|^2). At f_op = 10.2 MHz, theta_g = 15 deg: |Gamma_calm|^2 = 0.9343 (-0.30 dB). Rayleigh roughness factor for the turbulent ocean: F_R = exp(-(4*pi*sigma_h*cos(theta_g)/lambda)^2), with rms wave height sigma_h = 0.5 m nominal, lambda = c/f_op = 29.4 m. At the nominal case sigma_h*cos(theta_g)/lambda = 0.0164, so F_R = 0.959 and |Gamma_turb|^2 = |Gamma_calm|^2 x F_R = 0.8953 (-0.48 dB). The turbulent-vs-calm contrast is therefore 10*log10(0.8953/0.9343) = -0.19 dB at the first bounce for the nominal parameters. First-bounce power density (after the sea bounce), in dBm/m^2: S_1 = P_tx - 10*log10(4*pi) - 20*log10(L) - L_io + 10*log10(|Gamma_turb|^2), with P_tx = 50 dBm, L = 2*h_iono*tan(theta_g) the one-way up-down distance for the incident ray (h_iono = 300 km F2 layer, L = 161 km at theta_g = 15 deg), L_io = 4.33 dB. Result: S_1(turbulent) = -69.9 dBm/m^2. For the calm ocean at the same geometry: S_1(calm) = S_1(turbulent) + 10*log10(|Gamma_calm|^2/|Gamma_turb|^2) = -69.7 dBm/m^2. The turbulent first reflection is 0.19 dB weaker than the calm first reflection. Per-hop recurrence for hops i >= 2 (calm ocean): S_i = S_{i-1} - L_io + 10*log10(|Gamma_calm|^2). SNR at hop i: SNR_i = S_i + 10*log10(A_e) - N_0, with A_e = lambda^2/(4*pi) = 0.069 m^2 (-11.6 dBm^2... i.e. 10*log10(A_e) = -11.6 dB) and N_0 = kTB = -144.0 dBm (T = 290 K, B = 1 kHz). The usable hop count is the largest n with SNR_n >= 10 dB. Computed per-hop SNR: hop 1: 92.4 dB, hop 5: 73.9 dB, hop 10: 50.8 dB, hop 15: 27.7 dB, hop 18: 13.9 dB, hop 19: 9.3 dB. Maximum usable hops: n = 18. Sensitivity (all other parameters nominal): MUF = 8/10/12/15/20 MHz gives n = 9/13/18/27/40 (the 1/f^2 ionospheric scaling dominates); sigma_h = 0.3/0.5/1.0 m gives n = 18/18/18 (the turbulent contrast is only on the first bounce, so it does not affect the hop count, only the first-bounce strength); elev = 10/12/15 deg gives n = 19/19/18; B = 500/1000/2500 Hz gives n = 19/18/17.

### Outcome Analysis

Results: the first reflection off the turbulent ocean has power density S_1 = -69.9 dBm/m^2, which is 0.19 dB weaker than the calm-ocean first reflection (-69.7 dBm/m^2) at the nominal parameters (MUF = 12 MHz, f_op = 10.2 MHz, sigma_h = 0.5 m, theta_g = 15 deg, B = 1 kHz). The maximum number of hops before SNR falls below 10 dB is n = 18. Interpretation: the turbulent-ocean penalty at HF is small in absolute terms (-0.19 dB) because the Rayleigh parameter sigma_h*cos(theta_g)/lambda = 0.016 is far below the Rayleigh-validity criterion (parameter < 0.125), and the dominant per-hop loss is the round-trip ionospheric absorption (4.33 dB/hop), not the sea-surface reflection (which is -0.30 dB for the calm sea, close to -1 because seawater is a large, lossy dielectric at HF). The hop count is therefore set by the ionospheric loss, not by the sea-surface contrast. Limitations and biases, fixed by the expert counterexample (exchange 3): (a) the Rayleigh factor exp(-(4*pi*sigma_h*cos(theta_g)/lambda)^2) stops representing the turbulent contrast once sigma_h*cos(theta_g) approaches lambda/(4*pi) (coherent component strongly suppressed) and beyond the Rayleigh criterion sigma_h*cos(theta_g) > lambda/8 the return is dominated by diffuse/incoherent scattering, so the single multiplicative attenuation on |Gamma|^2 is no longer valid. At the nominal parameters the parameter is 0.016, so the model is valid; the boundary is crossed at sigma_h > ~3.7 m for theta_g = 15 deg, f_op = 10.2 MHz. (b) the flat-Fresnel grazing limit and the roughness factor both cease to apply when the incidence angle departs grazing, i.e. above ~10-15 deg from the surface; the nominal theta_g = 15 deg is at the edge of this domain, and the model would need a full surface-scattering treatment (not a single Rayleigh factor) for shorter-hop, higher-incidence geometry. (c) the ionospheric loss is anchored on a 1/f^2 D-region heuristic fitted to the lookup's 'tenths of dB at 30 MHz' statement; the true ITU-R P.531 prediction would give different values at different MUFs, seasons, and solar conditions, so the hop count of 18 should be read as order-of-magnitude, not a precise prediction. (d) the isotropic 0-dBi receiver effective area is a lower bound on received power; a practical shipboard antenna with gain would increase the usable hop count. (e) the equal-hop-length assumption (L = 161 km per hop) is a simplification; real great-circle paths have varying hop lengths, but the spreading ratio between successive bounces is 1 for equal lengths, so the recurrence is insensitive to the absolute L value as long as it is constant.

### Problem

Part II: Compare the Part I findings for HF reflections off mountainous or rugged terrain with the findings for smooth (calm ocean) terrain.

### Analysis

The comparison is structural, not a re-derivation: the same GO link budget applies, but the surface reflection coefficient changes. For a smooth, lossy surface (calm ocean), the Fresnel coefficient at grazing incidence is close to -1 (|Gamma|^2 ~ 0.93 at 10.2 MHz), because seawater is a large, lossy dielectric. For mountainous or rugged terrain, two distinct mechanisms replace the Rayleigh factor: (1) geometric blockage — the terrain profile interrupts the grazing ray path, so the ray does not reach the intended reflection point and the hop is lost entirely (a hard failure, not an attenuation); and (2) diffuse scattering from the rough, heterogeneous surface — the return is incoherent and the effective reflection coefficient is far below the flat-Fresnel value, because the terrain permittivity is much smaller than seawater's (dry soil/rock |eps_r| ~ 3-5, wet soil |eps_r| ~ 10-20, versus seawater |eps_r| ~ 10^2-10^3 at HF) and the surface is not a coherent reflecting plane. The smooth-terrain (calm ocean) result from Part I is therefore the best case: the flat, lossy sea gives the highest per-hop reflection coefficient and no geometric blockage. Rugged terrain is strictly worse on both counts. The comparison is qualitative in structure (same GO budget, different |Gamma|^2 and a blockage indicator) and does not require new empirical constants beyond the terrain permittivity range, which is standard geophysical knowledge and not a magnitude the problem's data is expected to supply.

### Modeling Process

The same recurrence S_i = S_{i-1} x A_io x |Gamma_surface|^2 applies, with |Gamma_surface|^2 replaced by the terrain value. For dry rock/soil at grazing incidence, |Gamma|^2 is of order 0.5-0.8 (versus 0.93 for seawater), giving a per-hop penalty of 1-3 dB additional over the calm-ocean case. For a rugged profile, a blockage indicator B_i in {0, 1} multiplies the recurrence: S_i = S_{i-1} x A_io x |Gamma_terrain|^2 x B_i, with B_i = 0 when the terrain profile between the ionospheric reflection point and the intended sea-surface (or ground) bounce point exceeds the ray height. The maximum usable hop count for rugged terrain is therefore bounded above by the calm-ocean value (n = 18 nominal) and is reduced by (i) the lower per-hop reflection coefficient (each hop loses 1-3 dB more) and (ii) the probability of a blockage event on any given hop, which terminates the path entirely. For a quantitative estimate: with |Gamma_terrain|^2 = 0.6 (-2.2 dB) versus |Gamma_calm|^2 = 0.934 (-0.30 dB), the additional per-hop loss is ~1.9 dB, so the usable hop count drops from 18 to roughly 13 (solving 10*log10(S_i) + A_e - N_0 = 10 dB with the larger per-hop decrement). With blockage, the expected number of successful consecutive hops before a blockage event is 1/p_block per hop, so the expected usable hop count is min(13, geometric(p_block)).

### Outcome Analysis

Findings: smooth (calm ocean) terrain is the best case for HF multi-hop skywave, because (i) the lossy sea gives the highest grazing-incidence Fresnel reflection coefficient (|Gamma|^2 ~ 0.93 at 10.2 MHz), and (ii) a flat sea surface provides no geometric blockage of the grazing ray. Mountainous or rugged terrain is strictly worse: the lower terrain permittivity gives a lower reflection coefficient (additional 1-3 dB per hop), and the terrain profile can block the ray entirely (hard failure). The maximum usable hop count for rugged terrain is bounded above by the calm-ocean value (18 nominal) and is reduced by the per-hop reflection penalty and by blockage events; a reasonable estimate is ~13 hops for unblocked rugged terrain, and fewer if blockage is frequent. Limitations: the terrain permittivity range (3-20) is a standard geophysical value, not a supplied lookup, so the 1-3 dB per-hop penalty is an order-of-magnitude estimate; the blockage probability depends on the specific terrain profile, which is not specified in the problem, so the blockage term is structural rather than quantitative. The comparison is therefore a structural statement (smooth > rugged, on both reflection coefficient and blockage) with an order-of-magnitude hop-count estimate, not a precise prediction.

### Problem

Part III: A ship travelling across the ocean uses HF for communications and to receive weather and traffic reports. How does the model change to accommodate a shipboard receiver moving on a turbulent ocean, and how long can the ship remain in communication using the same multi-hop path?

### Analysis

The moving receiver changes the model in three ways. (1) The receiver is no longer a fixed isotropic point at a fixed sea-surface location; it is a moving platform on the turbulent sea surface, so the effective receiving area A_e is that of a shipboard antenna (with gain G_ship, typically 0-10 dBi for a marine HF whip) rather than the 0-dBi isotropic area used in Part I. (2) The ship's motion adds a Doppler shift to the received carrier: f_D = v_ship*cos(phi)/lambda, where v_ship is the ship speed and phi is the angle between the ship's velocity and the incident ray direction. For v_ship = 15 m/s (~30 knots) and lambda = 29.4 m, f_D = 15/29.4 ~ 0.5 Hz, which is negligible for a 1 kHz bandwidth receiver (f_D/B ~ 5e-4), so the Doppler does not broaden the carrier into the noise band. The dominant motion effect is therefore not Doppler but the time-varying geometry: as the ship moves, the hop chord lengths and the sea-surface incidence angles change, and the ship eventually leaves the footprint of the fixed multi-hop path. (3) The turbulent sea surface the ship is on is the same surface that produces the first-bounce Rayleigh attenuation; the ship's own motion modulates the local wave height and the local reflection coefficient, but this is a fast, small modulation (order of the Rayleigh parameter, ~0.016 nominal) and does not change the mean budget. The communication time is set by how long the ship stays within the path footprint: the multi-hop path has a fixed endpoint (the land source's coverage region), and the ship can remain in communication as long as it is within the last-hop footprint of that path. The last-hop footprint radius is approximately the last hop chord length L = 2*h_iono*tan(theta_g) = 161 km (nominal). The ship's time within the footprint is t_comm = 2*R_footprint/v_ship, where R_footprint is the distance from the ship's entry point to the far edge of the coverage region. For a ship crossing the footprint diameter, t_comm ~ 2*L/v_ship = 2*161 km/15 m/s ~ 21,500 s ~ 6 hours. For a ship entering the footprint at its edge and crossing to the center, t_comm ~ L/v_ship ~ 3.2 hours.

### Modeling Process

The per-hop recurrence is unchanged from Part I (the path is fixed; the ship is the receiver at the end of the path): S_i = S_{i-1} x A_io x |Gamma|^2, with the same A_io, |Gamma_calm|^2, and |Gamma_turb|^2. The changes are in the receiver term and the communication-time calculation. (1) Receiver: replace A_e = lambda^2/(4*pi) with A_e_ship = G_ship * lambda^2/(4*pi), where G_ship is the shipboard antenna gain (dimensionless; G_ship = 10^(G_dBi/10) for G_dBi dBi). For G_ship = 3 dbi (a typical marine whip): A_e_ship = 2*lambda^2/(4*pi), a +3 dB increase in received power, which raises the usable hop count by ~1 (from 18 to ~19, consistent with the Part I bandwidth sweep). (2) Doppler: f_D = v_ship*cos(phi)/lambda; for v_ship = 15 m/s, f_D <= 0.51 Hz, f_D/B = 5.1e-4 for B = 1 kHz, so the Doppler is negligible and does not enter the SNR budget. (3) Communication time: the ship moves at speed v_ship across the last-hop footprint of radius L = 2*h_iono*tan(theta_g). The path is valid while the ship is within this footprint. The maximum communication time (crossing the footprint diameter) is t_comm_max = 2*L/v_ship. For v_ship = 15 m/s, L = 161 km: t_comm_max = 2*161e3/15 = 21,467 s = 5.96 h. The minimum (entering at the edge, leaving at the center) is t_comm_min = L/v_ship = 10,733 s = 2.98 h. The SNR at the ship's position varies as the ship moves through the footprint, but the dominant effect is the footprint boundary, not the within-footprint SNR variation, because the SNR margin at the last usable hop is small (13.9 dB at hop 18 vs 10 dB threshold, a 3.9 dB margin) and the ship's motion within the footprint changes the last-hop geometry by less than this margin.

### Outcome Analysis

Results: the model changes in the receiver term (shipboard antenna gain replaces the isotropic area, +3 dB for a typical marine whip, raising the usable hop count from 18 to ~19) and in the communication-time calculation (set by the footprint crossing time, not by Doppler). The ship can remain in communication using the same multi-hop path for t_comm ~ 3-6 hours, depending on its entry point into the last-hop footprint (2.98 h edge-to-center, 5.96 h full-diameter crossing), for a ship speed of 15 m/s (~30 knots). The Doppler shift (f_D <= 0.51 Hz) is negligible for a 1 kHz receiver and does not limit the communication time. Interpretation: the communication time is set by the geometry of the fixed multi-hop path (the last-hop footprint size), not by the signal strength within the path, because the ship's motion across the footprint changes the last-hop geometry faster than the SNR margin can absorb. A faster ship (v_ship = 30 m/s) halves the communication time to ~1.5-3 h; a slower ship (v_ship = 5 m/s) triples it to ~9-18 h. Limitations: (a) the footprint radius L = 161 km is the planar-approximation chord; the true great-circle footprint for a 300 km F2 layer and 15 deg grazing is larger (the spherical-geometry correction is ~10-20% for long paths), so the communication time is an order-of-magnitude estimate. (b) the path is assumed fixed (the ionospheric reflection point does not move); in reality the F2 layer height and the MUF vary with time of day and solar conditions, so the actual path footprint drifts, and the ship may leave the path faster than the geometric estimate. (c) the shipboard antenna gain of 3 dBi is an assumption; a higher-gain antenna would increase the usable hop count but not the communication time (which is set by the footprint, not the SNR margin). (d) the turbulent sea surface modulation of the local reflection coefficient is a fast, small effect (order of the Rayleigh parameter, ~0.016 nominal) and is neglected in the communication-time calculation; it would add a small, fast SNR ripple but not change the mean budget or the footprint boundary.

### Outcome Analysis

The synopsis is self-contained and states the model, the key nominal numbers (S_1 = -69.9 dBm/m^2 turbulent, -69.7 dBm/m^2 calm, 0.19 dB contrast, 18 usable hops, 4.33 dB/hop ionospheric loss), the MUF sensitivity (n = 9-40), the terrain comparison (smooth > rugged), and the shipboard communication time (3-6 h at 15 m/s). The practical implication is that the turbulent-ocean penalty at HF is small (0.19 dB) and the hop count is set by ionospheric absorption, not by the sea-surface contrast, so HF multi-hop skywave over the ocean is robust to ocean turbulence at the nominal parameters, and the shipboard communication time is set by the path geometry (footprint crossing), not by the signal strength. Limitations stated: the model is valid only in the grazing, long-path domain; the Rayleigh factor breaks down for large wave heights (sigma_h cos(theta) > lambda/8) or non-grazing incidence; the ionospheric loss is a 1/f^2 heuristic, not a full ITU-R P.531 prediction; and the communication time is an order-of-magnitude estimate that does not account for the time-varying MUF and F2 layer height.
