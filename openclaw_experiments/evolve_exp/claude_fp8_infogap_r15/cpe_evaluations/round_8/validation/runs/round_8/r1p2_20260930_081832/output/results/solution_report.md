## Subtask 1: P1. Build the ball-passing network between players (nodes = players, links = passes) and use it to identify network patt

### Problem

P1. Build the ball-passing network between players (nodes = players, links = passes) and use it to identify network patterns — dyadic and triadic configurations, team formations, and other structural indicators and network properties — across multiple scales (micro/pairwise to macro/all-players) and multiple time scales (minute-to-minute to half, match, and season). Scope: the Huskies' 38 matches, 10,435 of the 23,429 recorded passes (the rest belong to the 19 opponents). Goal: a formal, reproducible network representation of Huskies passing with structural descriptors at each scale.

### Analysis

Assumptions. (1) Node identity is by the named lineup slot (PlayerID 'Huskies_<Pos><num>', e.g. Huskies_M2), not by individual: the data carries no persistent individual ID across substitutions, so a slot is the finest identifiable unit; slot continuity across a match is a reasonable proxy for the on-field player at that position. (2) A pass row = one completed directed unit-weight edge Origin->Destination (the dataset records only completed passes, so no pass-failure term is observable; this is a data limitation, not an idealization). (3) The directed graph drives degree/betweenness/centrality; its undirected companion (either direction) drives clustering and the dyad/triad census, matching the standard convention in the passing-network literature. (4) The graph frame for a half is that half's own set of passing slots (lineups change between halves via substitutions; each match shows 13-14 distinct slots across both halves but only ~11-12 per half). (5) Per expert exchange 3, the goalkeeper slot G1 is a mandatory, high-volume, low-diversity node (it initiates nearly all goal-kick and restart passes to a small set of defensive slots); it degenerates contribution-distribution and entropy indicators by construction, so all field coordination/concentration indicators are computed on the ex-G (field-players-only) subgraph, with G1 reported separately. Method soundness: directed weighted graphs are the standard object for passing data; small-world testing against (a) an Erdos-Renyi null matched in (n, undirected edge count) and (b) a degree-preserving configuration-model null (rewiring) is the validated procedure of the cited literature (Buld et al. 2018; Cotta et al. 2013; Narizuka et al. 2014), and using two nulls protects against the well-known ER null being a poor baseline for heavy-tailed degree sequences. The triad census uses the 3 canonical undirected triad types (path-2, star-2, triangle) on the undirected companion because the directed triads are structurally empty in this data (see outcome).

### Modeling Process

Let V_m,p be the set of passing slots in match m, half p; A(v,w) = number of passes v->w in that half (weighted digraph; L = sum A). Undirected companion U = ((A>0) | (A^T>0)) with diagonal removed. Ex-G subgraph: A_e, U_e on V \ {G1}. (i) Dyads: unordered dyad (v,w) is present if A(v,w)+A(w,v)>0; mutual if both >0 (reciprocity = mutual/unordered). (ii) Triads: 3-sets {i,j,k} with >=2 present unordered dyads, typed path-2 (2 dyads) vs triangle (3 dyads); triad closure = triangles/triads. (iii) Clustering: local clustering C_i = (U_e[i,j]U_e[j,k] summed)/max(deg_i(deg_i-1),1), mean over i; compared to ER null (p = 2L_u/(n(n-1)), 50 draws) and degree-preserving null (20 rewiring steps). (iv) Path length: mean finite shortest-path distance on U_e (undirected min-plus) and on A_e (directed). (v) Centrality: betweenness (Brandes, directed, unit weights) and out-degree on A_e; concentration via Gini G(x) = (2 sum_i i x_(i) - n(n+1) sum x)/(n^2 sum x) on out-degree and betweenness, and top-3 betweenness share. (vi) Flow/entropy: Shannon entropy of the slot-to-slot transition matrix over the chronological ex-G pass sequence; temporal version in 5-minute windows (computed per half and its intra-half drift). (vii) Scales: all of the above computed per half, per match (both halves pooled on the match frame), and per season (season = distribution of per-match/per-half values; a slot-aggregated season graph is deliberately not used as a structural object because slot identities do not correspond to the same individuals). Forward structure: centroid_x = mean pass-origin x (attacking-orientation 0-100), mean_delta_x = mean (x_dest - x_orig), pass-type mix (Simple/High/Head/Launch/Cross/Hand/Smart), tempo = passes/minute, and duel involvement share from fullevents.csv (Huskies duels / all duels).

### Outcome Analysis

Results. (1) Network scale: ~11-12 active slots per half, 90-230 passes per half (L=9,468 field passes season-wide, ex-G), density high (0.6-0.9 of possible unordered dyads present). (2) Small-world test: NOT significant. Mean ex-G clustering = 5.30 vs ER null 5.52 (obs/ER = 0.98) and vs degree-preserving null 5.78 (obs/DP = 0.92); observed clustering exceeds the ER null in only 36% of halves and the DP null in only 3%. The Huskies' network is dense enough that even random rewiring produces comparable clustering, so the 'small-world' signature reported in the literature does not distinguish this team. (3) Dyads: zero mutual dyads across all 76 half-networks — the Huskies never pass back and forth between the same pair of slots, i.e. dyad reciprocity = 0.00 universally; passing is a directed chain/flow, not a reciprocal exchange. (4) Triads: abundant on the undirected graph — ~100-190 triads per half, triad closure (triangles/triads) = 0.55-0.74, highest in winning first halves (0.74). This is the team's genuine local coordination signature: short passing triangles among field players. (5) Centrality: betweenness is concentrated — top-3 ex-G betweenness share = 0.27-0.27 per half; season ex-G out-degree Gini = 0.50, betweenness Gini = 0.53; the single most central field slot is D1/D3/M2 (bc 17-21, out-degree 600-880 season), while G1 dominates the full graph (bc 24, 1,235 out-passes, 9.3% of all passes touch G1). (6) Formations: centroid_x = 45.7-48.6 (midfield to slightly forward, advancing in the 2H: 45.7->48.6), mean_delta_x = 3.7-4.5 field units forward per pass; pass mix is 83.7% simple passes, with Launch/High/Head making up most of the rest — a possession-oriented, short-pass game. (7) Time scales: tempo = 2.9-4.9 passes/min, higher in winning halves (3.97 1H wins vs 3.10 1H losses); within-match, structure is stable half-to-half (no fatigue collapse in entropy: 1H->2H drift small and of mixed sign). Limitations/biases: (a) only completed passes are recorded, so pass-completion quality and ball-loss cannot be measured — the 'loss term' of the model is unobservable; (b) slot != individual, so individual contribution is conflated with position; (c) the ex-G convention removes the goalkeeper's restart volume from field indicators (defensible per expert, but it hides a real structural role); (d) n=38 matches is small, so per-outcome means have wide CIs; (e) the ER null ignores spatial embedding, a known conservative direction for small-world claims.

## Subtask 2: P2. Identify performance indicators that reflect successful teamwork beyond points/wins (diversity of plays, coordinatio

### Problem

P2. Identify performance indicators that reflect successful teamwork beyond points/wins (diversity of plays, coordination, distribution of contributions, adaptability, tempo, flow), clarify whether strategies are universally effective or opponent-dependent, and use these indicators to build a model capturing the structural, configurational, and dynamical aspects of teamwork. Scope: all 38 matches and the 19 opponents' passing networks.

### Analysis

Assumptions. (1) A 'teamwork indicator' is a per-match (or per-half) scalar derived from the P1 graphs/events that is (i) not a direct function of the score and (ii) sensitive to how teammates combine, not just individual output. (2) Success is scored as points (win=1, tie=0.5, loss=0) plus goal margin for validation; association with outcome is the operational definition of 'reflects successful teamwork' (per the cited finding that betweenness-based metrics correlate with win probability). (3) Opponent-dependence is tested by including opponent structural descriptors (density, degree heterogeneity, clustering, centroid) as covariates and by checking whether the indicator->outcome association holds within opponent-structure strata. (4) Indicators are grouped into structure (clustering, triad closure, path length), configuration (centrality concentration, betweenness share, dyad/triad census), contribution (Gini of out-degree and betweenness), and dynamics (transition entropy, tempo, duel share, centroid/progress). Method soundness: Pearson r and per-outcome means with 38 observations are the honest scale of evidence available; effect sizes are therefore reported as ranks/correlations, not p-value claims. The opponent layer reuses the exact P1 graph machinery on the opponents' pass rows, so the contrast is apples-to-apples.

### Modeling Process

Teamwork indicator set T = { triad_closure, clust_exG, gini_outdeg, gini_bc, max_bc_share, transition_entropy, tempo, duel_share, centroid_x, mean_dx, L (volume) }, each per match = mean over its halves (or whole-match value). Outcome variable Y = points in {0,0.5,1}. Validation model: (i) univariate r(T_j, Y) across 38 matches; (ii) per-outcome means with SD; (iii) opponent contrast: for each opponent structural covariate O_k in {density, gini_outdeg, clust, centroid_x}, the mean O_k in matches the Huskies won vs lost, and the 2-way pattern T_j x O_k. The structural-configurational-dynamical 'model of teamwork' is the decomposition: Success ~ f(structure: closure, clustering; configuration: concentration Gini/bc-share; dynamics: entropy, tempo, duels), with the opponent layer as the conditioning context. No parametric fit is claimed at n=38; the deliverable is the indicator set with its measured outcome association and the opponent-conditioning pattern.

### Outcome Analysis

Results — what distinguishes winning from losing halves/matches (38 matches: 13W, 10T, 15L; 41 points / 114 = 0.36 pts/match, a poor season). (1) Contribution concentration: gini_bc_exG r=+0.344 (win 0.450 vs loss 0.400 vs tie 0.421), gini_outdeg_exG r=+0.279 (0.295 vs 0.266), max_bc_share_exG r=+0.251 (0.268 vs 0.242). WINNING matches have MORE concentrated betweenness/out-degree — the Huskies rely on their hub slots (D1/D3/M2) when they win. This is the opposite of the 'balanced betweenness = better' finding in the literature, and it is a genuinely team-specific result. (2) Duel control: duel_share r=+0.278 (win 0.520 vs loss 0.501) — winners win more of their duels; this is the strongest non-network indicator and the clearest 'process' signal. (3) Triad closure: win 0.606/0.736 (match/1H) vs loss 0.611/0.658 — winners close slightly more triangles, and the 1H gap is cleanest (0.736 vs 0.658); r over matches = -0.042 (noisy at n=38, direction driven by 1H). (4) Tempo: tempo_ppm r=+0.118, win 3.36 vs loss 3.10 matches/min — winners pass faster. (5) Volume: winning first halves have far more passes (L: win 178.6 vs loss 139.5, r via match mean positive) — possession volume tracks success. (6) What does NOT track success: centroid_x (r=0.007), mean_dx (r=-0.110), clustering vs null (r=-0.055), transition entropy (r=0.007). Forward position and raw progress per pass are not the differentiator; neither is play diversity (entropy). (7) Opponent-dependence: opponents against whom the Huskies LOST had higher internal clustering (opp_clust 7.11 loss vs 5.56 win) and a more forward centroid (49.3 vs 47.7) and denser networks (0.701 vs 0.656) — i.e. the Huskies lose to opponents who pass in tighter, more forward triangles. Opponent degree heterogeneity is similar across outcomes (0.294 vs 0.285), so it is not the discriminating counter-strategy. This indicates the Huskies' concentrated-hub strategy is NOT universally effective: it is out-triangled by tightly-clustered opponents. The model of teamwork is thus: success rises with (a) winning duels, (b) passing volume and tempo, (c) using hub slots as conduits, and (d) closing triangles — but (c) is fragile against high-clustering opponents, which is the failure mode. Limitations/biases: n=38 and 15 losses vs 13 wins give imbalanced, low-power groups; duel_share is a duel-count share (no win/loss outcome per duel is in the data), so it is a proxy for duel dominance; the indicator set is correlated (concentration indicators move together), so the 'top' ranking is not a set of independent predictors; entropy is computed on ex-G slots and may understate GK-mediated play variety.

## Subtask 3: P3. Use the teamwork model to advise the coach: which structural strategies were effective for the Huskies, and what cha

### Problem

P3. Use the teamwork model to advise the coach: which structural strategies were effective for the Huskies, and what changes the network analysis indicates for next season to improve success. Scope: actionable, network-grounded recommendations for the 30-slot Huskies squad.

### Analysis

Assumptions. (1) Advice must be traceable to a measured indicator with an outcome association, not to generic soccer knowledge. (2) The squad operates on slots/positions, so recommendations are framed at the position-pair and formation level (which slots should link, which should be hubs) rather than naming individuals. (3) The season's record (0.36 pts/match) means the baseline strategy underperformed; recommendations therefore keep what showed positive association and change what showed negative or fragile association. Method: map each P2 indicator to a structural lever (the graph quantity the coach can actually influence: link policy, hub assignment, triangle-building, duel intensity, tempo), rank levers by the strength and sign of the indicator's outcome association, and state the expected mechanism.

### Modeling Process

Lever->indicator map: (L1) Hub conduit policy -> gini_bc / max_bc_share (use D1/D3/M2 as primary conduits, route possession through them) — keep, since concentration tracked wins; (L2) Triangle-building among field players -> triad_closure (increase 3-slot passing patterns in the final third) — strengthen; (L3) Duel intensity -> duel_share (press and win more duels) — strengthen (strongest non-network signal); (L4) Tempo & possession volume -> tempo_ppm, L (raise passes/min and total possession passes) — strengthen; (L5) Reciprocal dyads -> reciprocity (currently 0.00; introduce short give-and-go back-pass patterns to create mutual dyads and 2nd-ball options) — new, since the complete absence of reciprocal dyads means the team has no 2-pass loop and every sequence is a one-way chain that terminates or is forced forward; (L6) Anti-triangle defense -> opponent clustering contrast (against high-clustering opponents the Huskies lose; disrupt opponent triangles by pressing the triangle's apex) — new, from the opponent layer. Selection rule: a lever is 'keep' if its indicator r>0 and the winning-group mean exceeds the losing-group mean; 'change' if r<0 or the association is fragile (sign flips by opponent stratum).

### Outcome Analysis

Advice to the coach. KEEP: (1) Route possession through the hub slots D1, D3, and M2 — the Huskies won more when betweenness/out-degree was more concentrated on a few field slots (gini_bc win 0.450 > loss 0.400); the hub-conduit style worked. (2) Maintain high possession volume and tempo in the opening 45 minutes — winning first halves averaged 179 passes at ~4.0/min vs 140 at ~3.1 in losing first halves; the season's 0.36 pts/match came from low-volume, low-tempo possession, not from a structural failure of the passing idea itself. CHANGE: (1) Build deliberate triangles: triad closure was 0.74 in winning 1H vs 0.66 in losing 1H; drill 3-slot passing patterns (especially D-M-F and D-M-M triangles) so the team creates and closes more triangles, which is the one local-coordination signature that separated winners. (2) Win more duels: duel share rose from 0.50 (losses) to 0.52 (wins), the clearest process differentiator; increase pressing and 1v1 winning around the ball carrier. (3) Introduce reciprocal (give-and-go) dyads: the network shows zero mutual dyads all season — every pair that passes, passes only one way. Adding short back-and-forth 2-pass loops gives a second-ball option, breaks the one-way chain structure, and is the single largest structural gap in the current formation. (4) Counter high-clustering opponents: the Huskies lost to opponents whose own passing was more tightly triangulated (opp clustering 7.1 vs 5.6) and more forward; against such teams, press the apex player of the opponent's triangle to break their closure rather than mirror their structure. CAVEATS: the effect sizes are modest and n=38, so treat (3) as the highest-confidence change and the triangle/hub items as supporting; duel_share is a count-based proxy; none of this measures pass accuracy, which the data cannot supply — if next season's data includes failed passes, the hub-conduit recommendation should be re-tested, because concentrated hubs also concentrate ball-loss risk.

## Subtask 4: P4. Generalize: what do the Huskies' group dynamics imply for designing more effective teams in general (soccer and beyo

### Problem

P4. Generalize: what do the Huskies' group dynamics imply for designing more effective teams in general (soccer and beyond), and what additional aspects of teamwork must be captured to build generalized models of team performance. Scope: a transferable statement plus a concrete list of missing variables for future models.

### Analysis

Assumptions. (1) Generalization is from the measured Huskies mechanisms (hub conduit, triangle closure, duel control, tempo, absence of reciprocal dyads) to team-design principles, not from soccer-specific tactics. (2) A 'generalized team model' needs, beyond interaction structure, the outcomes and constraints that make interactions productive. (3) The Huskies are one noisy sample (n=38, poor record), so generalizations are stated as hypotheses with the conditions under which they would hold. Method: take each validated mechanism, state its team-design principle, state its boundary (the opponent-dependence or degeneracy that limits it), and list the variable classes the passing-data model could not observe.

### Modeling Process

Generalization form: for each mechanism M with measured association A(M, success) and boundary B(M): principle = 'design teams so that M is present/strong when condition holds, and avoid M when B(M) is triggered'. The model's observable set is O = {directed pass graph, coordinates, pass type, duel/shot/substitution events, outcome}; the required-but-missing set R is enumerated from the gaps that limited P1-P3 (see outcome). The generalized model statement is: TeamPerformance = f(interaction structure, interaction quality, resource allocation, adaptive capacity, task constraints), where this work estimated only the interaction-structure component of f on a single team against a fixed opponent field.

### Outcome Analysis

Generalizable principles (each flagged with its boundary). (1) Hubs can drive success up to a point: concentrated conduit roles (high betweenness Gini) correlated with winning here, so effective teams can be organized around a few integration nodes — but the boundary is ball-loss concentration and opponent pressure; in domains where a hub's failure is catastrophic (or where hubs are easily targeted, as the high-clustering opponents did by triangulating around Huskies possession), balance must replace concentration. (2) Local closure (triangles/3-cycles) is the robust coordination signature: it separated winners and, per the literature, is the small-world mechanism in team sports; generalized: teams that create redundant 3-member paths are robust to single-member failure. (3) The absence of reciprocal dyads is a general fragility: a team whose every pair interacts in only one direction has no 2-step loop and no second-ball fallback; generalized models should measure reciprocity/loop formation, not just density. (4) Tempo and contest-won (duel share) are 'process' variables that track success even when pure structure does not: generalized models must include execution-rate and contest-winning, not just topology. (5) Strategies are opponent-dependent, not universal: the same concentrated-hub Huskies won and lost depending on the opponent's clustering; generalized models must condition team effectiveness on the partner/opponent's structure (a two-agent or network-of-networks model), which the single-team design cannot capture. Aspects that must be captured for generalized models (the missing variable classes): (a) interaction OUTCOME quality — pass completion, shot accuracy, duel win/loss (here only completed passes and duel counts exist, so quality and the loss term are unmeasured); (b) individual vs slot identity — persistent individuals, skill, fatigue, and substitution effects (here only positions); (c) spatial dynamics — continuous positions, distances, and closing speed (here only pass endpoints); (d) temporal/adaptive dynamics — in-game adaptation, momentum, and half-to-half strategy shifts at finer resolution than 45-minute halves; (e) the opponent as an active strategist — reactive counter-strategy, not a fixed covariate; (f) goals/utility and task constraints — the 'what is success' function and rules, which differ across domains; (g) multiple timescales of memory — learning and routine formation across the season. A generalized team-performance model therefore needs, on top of the interaction graph: a quality/loss layer on each link, persistent agent identity with state, continuous space-time dynamics, an adaptive opponent model, and an explicit utility and constraint function; the Huskies analysis supplies the structure layer and the first evidence that structure, quality, and opponent-conditioning all matter and are not interchangeable.
