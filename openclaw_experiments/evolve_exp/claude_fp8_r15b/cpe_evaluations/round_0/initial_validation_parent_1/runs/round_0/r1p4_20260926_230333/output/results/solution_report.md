### Problem

本任务（MM-Bench 2020_F）要求面向联合国（经国际气候移民基金会转介）就环境移民（EDPs，Environmentally Displaced Persons）问题提交一份可操作的咨询方案：受海平面上升威胁的岛国——图瓦卢、基里巴斯、马绍尔群岛、马尔代夫——将在21世纪内陆续失去居住能力，其国民将成为失去国家归属的移民群体。任务要求：(1) 界定问题范围：现在和随时间推移有多少人面临风险、其文化资产价值几何；(2) 提出保障EDPs人权与文化保护的政策建议；(3) 建立度量政策影响的模型；(4) 说明模型如何反过来设计与改进这些政策；(5) 用分析论证这些政策为何重要。提交物为一份两档混合框架（确定性情景主干 + 离散情景不确定性叠加）的定量模型及其政策建议，所有数据来自预收集的外部资料（IPCC AR6海平面情景、世界银行Groundswell、太平洋环礁CCDR报告）。

### Analysis

范围界定（模块1）：四国2026年合计约71万人（图瓦卢1.2万、基里巴斯13万、马绍尔群岛4.2万、马尔代夫52.6万），按年增长率0.8%外推至2100年约128万人。以“可行栖息土地比例低于50%”为迁出阈值，校准于[ D3 ]锚点（0.5米海平面上升淹没50–80%主要城区）：低/中/高IPCC情景下各国迁出年份分别为图瓦卢2110/2085/2068、基里巴斯2127/2097/2079、马绍尔群岛2148/2112/2090、马尔代夫2136/2103/2084。情景概率叠加显示：图瓦卢与基里巴斯在2080年前迁出的概率为33%，其余两国为0%（主干情景下）。尾部压力测试（约2米极端上升）显示四国全部在2046年前被迫迁出（图瓦卢2033、基里巴斯2039、马尔代夫2042、马绍尔群岛2046）。文化价值（模块2）：以复合文化资本指数（独特性×延续性×小岛隔离溢价）加权的人均终身共享文化体验价值，测算四国文化存量合计约993.6亿美元（图瓦卢36.9亿、基里巴斯220.3亿、马绍尔群岛114.2亿、马尔代夫622.3亿；人均11.8万–30.8万美元）。“不作为”基准下，到2100年的折现累计文化损失：低情景$0、中情景−5.17亿、高情景−193.7亿美元。Groundswell对账：全球内部气候移民约1.43–2.16亿（到2050年），EDPs是其中跨境、无国属的极小子集，本模型只刻画这一子集。任务分解为五个子问题：范围（人+文化价值）、政策（人权+文化）、政策影响模型、模型对政策的设计/改进作用、政策的必要性论证。

### Modeling Process

经三轮专家咨询确定框架（详见interaction_evidence.md）：第一轮采纳“两档混合”——确定性迁出主干（按IPCC AR6海平面路径0.38/0.56/0.77米，可行性=1−被淹没份额，阈值50%）加离散低/中/高情景概率叠加，不做连续随机化（避免为单一最不确定量支付过度建模成本）。文化价值模型：复合文化资本指数=隔离溢价(1.2−0.02·sqrt(人口/千), 下限0.4)×独特性(5分制)×延续性(0.5–0.9)，乘以人均共享文化小时数与每小时支付意愿($12/小时)。文化动态模型：微分方程 dC/dt = −d·C + u·I·C·(1−C/Cmax)（Euler积分，dt=0.25），其中d为侵蚀率、u为再生产率、I= min(1, 集群份额×50)为集群规模效应；用于模拟三种政策体制下20年文化存量存续。政策体制存续曲线：不作为=exp(−λ0·t)，λ0=−ln(0.25)/20（20年剩25%）；仅权利=exp(−0.5·λ0·t)（20年剩50%）；权利+文化保护=上述ODE（d=0.5λ0, u=0.12, 截断≤1.0）。东道国分配（第二轮专家背书）：责任调整容量公式 share=容量份额×有界分层乘数（区域邻国1.0、主要排放国1.15、殖民历史国1.25、历史排放大国1.30），每国队列60%分配至区域集群集、40%至前两大全球义务国。治理（第三轮专家背书）：联合国条约机构——认证可行性（对照50%阈值）、按责任调整公式分配队列、在固定窗口内裁决异议；EDPs享有有界否决权（一次性、一年窗口内对队列目的地提出异议并请求义务清单内的一个替代东道国）。边际成本—收益框架：庇护基线成本$93,000/EDP（全额体制），文化保护附加的边际成本$31,000/EDP（20年语言文化项目$25,000+集群住房溢价$6,000），与避免的边际文化损失对比。

### Outcome Analysis

(1) 范围结论：四国2026年约71万人面临风险，2030年73.3万、2050年86.0万，2100年约112万–128万；中情景累计迁出约127.2万。文化存量合计约993.6亿美元，是全案价值锚点。(2) 政策建议：一揽子体制=保障EDPs庇护权+5年加速入籍+资金化的集群式文化保护附加（语言与文化项目、最低集群规模规则、集群住房）。(3) 政策影响模型结果（中情景，迁出后20年）：体制间文化存量存续——不作为25%（保留248.4亿美元）、仅权利50%（496.8亿）、权利+文化保护约84%（831.9亿）；权利+文化保护相对不作为避免损失583.5亿美元，相对仅权利避免335.1亿。人权参与率代理指标：0.30（不作为）/0.80（仅权利）/0.90（权利+文化）。(4) 模型对政策的设计/改进作用：(a) 25%存续基线证明“什么都不做”等于放弃约四分之三的文化存量，驱动“保障庇护”作为非可选基线；(b) 仅权利体制下参与率从0.30升至0.80、存续翻倍至50%，证明入籍与身份保障是文化存续的先决条件；(c) 权利+文化体制的边际成本$31,000/EDP vs 边际避免损失$26,335/EDP（20年窗口内），且随集群规模增大而持续改善，证明文化附加是“边际上可负担、长期上高回报”的干预，而非昂贵附加；最小集群规则直接来自60%区域集中度测算（集群份额决定再生产输入I）；(d) 分层乘数1.15/1.25/1.30使义务份额落在5–19%可辩护区间（美国18.9%、澳大利亚16.1%、斐济12.9%、德/日各9.3%、英8.1%、法5.0%），模型证明“有界”是公式能作为条约义务而非惩罚性配额成立的前提。(5) 政策为何重要：在尾部情景下四国均于2046年前迁出，政策窗口只剩十余年——若不在2040年前建立框架，将出现无制度承接的大规模无国属人口流；全额体制成本$93,000/EDP换取84%文化存续与0.90人权参与率，相对不作为避免$45,858/EDP的文化损失（仅20年窗口，未计长期存续价值）；文化存量$993.6亿是代际不可再生资源，一旦失去国家锚点即不可恢复。治理上，UN条约机构+有界否决权使责任公式可执行、集群规模最小值有保证、个体声音真实但不阻塞系统——这是对“个人vs联合国vs东道国”问题的规范性回答。
