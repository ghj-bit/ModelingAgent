### Problem

子任务(a)：建立美国机场安检通道乘客流动模型，识别当前流程中的瓶颈与问题区域。目标与范围：对Zone A（ID检查排队）→ Zone B（开放筛查线：分箱放置、行李X光传送带、毫米波/金属探测器人身安检、失败者Zone D手检）→ Zone C（取物传送带重组）的完整流程建立可运行的模型，区分TSA Pre-Check通道（1条）与普通通道（3条，1:3比例），并用2017_ICM_Problem_D_Data.csv的实证数据和外部数据（TSA服务标准、Pre-Check基准）进行标定，最终定位瓶颈。

### Analysis

假设与建模思路：(1) 采用离散事件仿真（DES）作为唯一情景引擎——经专家咨询确认：任务(b)(c)需要表示资源竞争、共享串联资源、手检分支和行为参数（插队率、分箱速度、个人空间摩擦），只有DES能直接表示；M/G/c队列公式仅作验证层使用，避免双代码路径不一致。(2) 各服务时间拟合为对数正态分布（保留数据的偏态）：ID检查11.2s(CV 0.34)、人身安检11.6s(CV 0.50)、X光逐袋间隔5.6s(CV 1.33)、传送带全程28.6s(CV 0.49)、Pre-Check到达间隔9.2s(CV 1.04)、普通到达间隔12.9s(CV 1.23)；分箱放置30s、手检90s、随机查包60s无直接数据列，按题面流程叙述取值(CV 0.4-0.5)。(3) 载荷标定（关键决策，经专家确认）：原始数据是约10分钟高峰突发窗口（59+48人），按原始速率系统不稳定（无稳态）；因此将到达间隔按常数load_scale=0.30缩放（分布形状不变），使基线恰满足TSA官方标准'普通通道99%等待<30分钟'（GAO-18-563T），此时普通约83/h、Pre-Check约117/h、合计约200/h。原始速率下的不稳定作为次要诊断报告。(4) 瓶颈诊断方法：单区敏感性实验——逐区将服务时间减半，观察平均等待变化；并用M/G/c（Erlang-C×Pollaczek-Khinchine）交叉验证稳态等待量级。

### Modeling Process

DES事件结构（单服务台资源，无嵌套循环）：(1) 到达：按45%概率分配Pre-Check/普通，间隔~Lognormal(μ,σ)×(1/load_scale)。(2) Zone A：共享ID检查台（2名官员，FIFO，插队者位置=0）：t_id = max(t_arr, id_free) + pos·E[id]，E[id]=exp(μ+σ²/2)。(3) Zone B：最短队选择通道；每条通道含4个独立资源时间戳：bin_start_free、belt_free（行李串行走带）、scan_free（人身安检）、search_free（查包槽）。乘客在通道内的完成时间：t_bin_done = max(t_id_done, bin_start_free) + Lognormal(30s)；行李段 t_belt = 串行 max(t, belt_free)+Lognormal(5.6s)，袋数~Poisson(2)，5%概率被标记→查包延迟 max(t_belt, search_free)+Lognormal(60s)；人身安检 t_scan = max(t_id_done, scan_free)+Lognormal(11.6s)，8%概率失败→手检 t_pat = max(t_scan, pat_free)+Lognormal(90s)（2名共享手检官）；t_b_end = max(t_belt, t_pat, t_search)。(4) Zone C：t_end = max(t_b_end, reasm_free) + (Lognormal(28.6s)+courtesy)。(5) 等待时间 W = t_end − t_arr。验证层：M/G/c平均等待 W_q = E_c·s/(c−λs)·(1+C²)/2，其中E_c为Erlang-C阻塞概率，C²=(σ²+μ²)/μ²。基线参数：c=1/通道，λ=55/h/通道（均值载荷）。

### Outcome Analysis

结果（2h仿真，种子20170911，均值载荷load_scale=0.30）：普通通道 n=100，平均等待144.7s，中位142.2s，标准差53.1s，p90=207.4s，p99=285.4s，max=308.5s；Pre-Check n=92，平均146.9s，p99=298.7s。基线满足TSA 30分钟/99%标准（p99=4.75min），Pre-Check均值146.9s（2.4min）与p99 298.7s（5.0min）均满足TSA'99%<10分钟'基准，但p99达到基准的50%——说明1:3通道比例在45%占比下余量有限。瓶颈诊断（单区减半实验，普通通道平均等待变化）：分箱30s→15s：−26.5s（最大）；传送带全程28.6s→14.3s：−30.5s（最大）；X光逐袋5.6s→2.8s：−14.3s；ID检查11.2s→5.6s：−7.2s；人身安检11.6s→5.8s：−0.7s（可忽略）。结论：(1) 均值载荷下瓶颈是固定的每乘客串联处理时间，其中分箱放置与传送带重组（取物）两项占主导，而非通道数量或设备速度——这解释了为什么单纯加通道（mod2/mod3的常开形式）在中载荷下是无效操作（实验证实：常开第4通道时结果与基线逐位相同）。(2) 高峰载荷（load_scale 0.38-0.40）下通道数才成为约束：p99_reg从285s升至329-345s，重现题面'难以预测的长队'现象。(3) 次要诊断：按原始数据速率（59+48人/10分钟）运行，队列无界增长（12分钟窗口内平均已达258s且持续上升）——数据窗口是峰值事件而非稳态，说明该机场在峰值期结构性过载。(4) 验证：M/G/c对ID台（c=2, λ=200/h）给出1.3s均值等待，与DES一致（ID台非瓶颈）；单通道M/G/c（c=1, λ=55/h, s=65s, C²=0.13, ρ=0.17）给出52s均值等待，与DES中通道内排队分量（平均等待144.7s = 串联服务约93s + 排队约50s）量级一致，交叉验证通过。局限：样本小（16个ID、29个传送带观测），对数正态拟合的尾部不确定；插队、手检率(8%)、标记率(5%)、袋数(2)为叙述性假设而非数据；单条ID队列是简化（实际可能按通道分列）；仿真窗口2h含启动瞬态，尾部百分位对窗口长度敏感。

## Subtask 2: 子任务(b)：提出并仿真两种以上改进当前流程的方案，要求提高吞吐并降低等待时间方差，同时保持安全标准。目标与范围：在(a)的DES内实现并对比至少2个改造方案，验收标准为TSA 30分钟/99%服务标准（普通）与Pre-Check 10分钟

### Problem

子任务(b)：提出并仿真两种以上改进当前流程的方案，要求提高吞吐并降低等待时间方差，同时保持安全标准。目标与范围：在(a)的DES内实现并对比至少2个改造方案，验收标准为TSA 30分钟/99%服务标准（普通）与Pre-Check 10分钟基准，并展示各方案对等待均值与方差的影响。

### Analysis

方法选择（经专家咨询确认）：候选方案为Mod1扩展Pre-Check式流程（预分箱、免脱鞋带外套、电脑留在包内）、Mod2常开第4普通通道、Mod3自动落包/更快X光带、Mod4负载触发的动态通道/官员再配置（从预备池调人，队列长度超阈值时开通备用通道，2分钟启动延迟）。初步仿真显示Mod2/Mod3在均值载荷下是无效操作（瓶颈是每乘客处理时间而非通道数），故按专家建议采用策略A：完整发展Mod1（唯一载荷无关的有效改进）与Mod4（直接针对方差，并将Mod2/Mod3作为负载触发的容量手段纳入）。安全标准保持：所有方案不改变X光筛查、人身安检、手检、查包的概率与服务时间——只改变乘客准备行李的效率和容量弹性。

### Modeling Process

Mod1（扩展Pre-Check式处理）：对Pre-Check乘客 bin_srv ×0.55（免鞋带外套、电脑留包），对普通乘客 ×0.85（推行预分箱/电子物品简化）；其余资源不变。Mod4（负载触发动态再配置）：每到达检查 total_q = max(Σ_q_lane_rg, Σ_q_lane_pc)；若 ≥ q_thresh=25 且预备池有剩余（max_reserves=2），则向更拥挤的通道类型开通1条备用通道（新Lane，资源时间戳从当前时刻起算），并设置2分钟冷却（activate_delay=120s）防止抖动；ID官员交叉培训可同时支援手检。两方案叠加为mod1_plus_mod4。对比矩阵：baseline vs mod1 vs mod4 vs mod1+mod4，在均值载荷(0.30)与高峰载荷(0.38)下各运行一次；同时运行常开第4通道（q_thresh=∞的退化形式）作为'无效操作'证据。度量：n、mean、median、sd、p90、p95、p99、max，分普通/Pre-Check。

### Outcome Analysis

均值载荷(0.30)结果（普通/Pre-Check，秒）：baseline 144.7/146.9（sd 53.1/63.3，p99 285.4/298.7）；Mod1：135.4/121.4（sd 49.8/59.2，p99 266.8/256.4）——普通均值−6.4%，Pre-Check均值−17.4%、p99−14.2%，Pre-Check p95从263s降至231s；Mod4：与baseline相同（阈值25在均值载荷下从不触发——预期行为，容量手段在低载下闲置）；Mod1+Mod4：同Mod1（0.30下Mod4不触发）。高峰载荷(0.38)：baseline 177.2/155.6（p99 328.7/315.7）；Mod1+Mod4：163.7/130.5（p99 307.7/262.5）——普通均值−7.6%、p99−6.4%，Pre-Check均值−16.2%、p99−16.8%。方差：Mod1在所有载荷下降低sd（普通53.1→49.8，−6.2%；Pre-Check 63.3→59.2），因为缩短了主导串联项；Mod4在高峰下进一步压低尾部（Pre-Check p99 315.7→262.5）。无效操作证据：常开第4通道在0.30下与baseline逐位相同，证实(a)的瓶颈诊断。验收：所有方案下普通p99<30min标准；Pre-Check在Mod1下均值121s（2.0min），p99 256s（4.3min），相对'99%<10分钟'基准大幅改善。局限：Mod4的阈值25与冷却2分钟未做网格优化（仅单点），实际部署需按机场规模校准；Mod1假设普通乘客配合预分箱，行为依从率可能低于100%（若依从率50%，效应按比例缩小）；预备池2条通道的成本（设备+培训）未建模，TSA需按峰值频率权衡固定投资与动态弹性；2小时单种子运行，百分位估计的标准误约±10-15s。

参数化（经专家咨询确认，保留4个行为旋钮，每情景变一组，不加入群体聚类）：cut_rate（插队倾向，编码'插队污名'vs个人效率）：US 0.02、Swiss 0.01、China 0.15、slow 0.02；bin_factor（分箱速度乘数，编码集体纪律/个人效率）：US 1.0、Swiss 0.9、China 0.85、slow 1.5；belt_courtesy（取物处额外摩擦秒数，编码个人空间礼让）：US +2s、Swiss +1s、China 0、slow +5s；urgency（乘客侧全局速度乘数，<1更快）：US 1.0、Swiss 0.95、China 0.9、slow 1.15。每个旋钮直接映射题面点名的文化规范；'慢速旅行者'为题目明确允许的风格化类型。分析方法：单因素敏感性（每次相对US基线改变一组参数），在baseline与mod1+mod4两种配置下运行，比较均值、sd、p90、p99。

### Modeling Process

旋钮进入模型的位置：cut_rate以概率p决定ID排队位置pos=0（插队）或pos=前方人数（正常）——插队者自身等待降低但使他人位置后移，增加FIFO破坏带来的方差；bin_factor乘在分箱服务时间上（t_bin_done项）；belt_courtesy加在取物重组项上（(Lognormal(28.6s)+courtesy)/urgency）；urgency除在分箱、人身安检、取物三项乘客侧服务时间上（设备侧时间不变，因为设备不受文化影响）。仿真协议与(b)相同：2h、种子20170911、load_scale=0.30。输出：4文化×2配置=8组等待分布。

### Outcome Analysis

基线配置（普通/Pre-Check，秒）：US 144.7/146.9（sd 53.1/63.3）；Swiss 143.3/144.7（sd 52.6/62.8）；China 145.4/146.0（sd 53.4/63.2）；Slow 169.0/166.9（sd 68.8/70.8）。Mod1+Mod4配置：US 135.4/121.4；Swiss 135.1/121.8；China 137.3/123.5；Slow 147.8/125.8。解释：(1) 集体/个人效率文化（Swiss、China）使等待均值降低1-3s且sd略降——组织化的分箱与快速个人处理缩短了主导串联项；效应小是因为这些维度只作用于约30s的分箱项。(2) 高插队率（China 0.15）在均值上几乎中性（插队者省时与他人损失大体抵消）但抬高尾部：China p90_reg=212.9s高于US的207.4s，p99在Mod1+Mod4下266.1s为四者最高——插队增加等待方差，正是题面'方差'关注点。(3) 慢速旅行者最不利：均值+16-20s、sd +15-18、p99 294.8-331s，且其劣化几乎全部来自分箱(×1.5)与取物(+5s, ×urgency 1.15)两项——再次指向同一瓶颈。(4) 适应性结论（如何容纳差异）：Mod1的预分箱直接缓解慢速旅行者（缩短其主导项）；对高插队文化，队列纪律/电子围栏/叫号系统能消除位置=0的外来方差（仿真中禁用插队即恢复US分布）；对集体效率文化，分组预分拣（团体在ID前统一整理）可进一步缩短分箱项。所有文化下Mod1+Mod4均保持p99<30min标准，政策对文化差异稳健。局限：旋钮取值是基于文化刻板印象的定性赋值而非实证测量（题目允许基于真实差异或风格化模拟）；未建模文化混合机场的队列交互；单种子下各文化间<5s的差异不具统计显著性，显著结论限于Slow组（差异>15s，超出种子噪声量级）。

### Problem

子任务(d)：基于模型为安全管理者提出政策与流程建议（可全球适用，也可针对特定文化/旅行者类型定制），并给出模型验证、强弱评估与改进方向（future work）。目标与范围：将(a)-(c)的定量结果转化为可操作的政策规则（含触发阈值、资源配置、KPI），评估模型可靠性，列出局限与未来工作。

### Analysis

建议结构（经专家咨询确认采用'全球适用政策+文化定制附录'）：全球政策承载主要结果（Mod1全通道部署、Mod4阈值触发规则、交叉培训、通道比例复审），文化附录针对(c)中识别的具体脆弱性（高插队率的尾部方差、慢速旅行者的分箱瓶颈、集体文化的分组机会）。每项政策都绑定到仿真证据与验收KPI：普通通道p99<30min（GAO-18-563T标准）、Pre-Check 99%<10min（TSA基准）、队列长度/等待时间监控阈值。验证策略：(1) 外部数据锚定（标定+验收双重使用）；(2) M/G/c解析交叉验证（ID台1.3s解析vs DES一致；单通道量级匹配）；(3) 结构有效性：单区敏感性排序与数据中各服务时间量级一致（28.6s传送带、30s分箱主导）；(4) 面效度：重现题面现象（峰值窗口过载、高方差长队、Pre-Check 1:3比例下余量小）。

### Modeling Process
