## Subtask 1: Part I: 对 100 W、低于 MUF 的 HF 恒定载波信号（从陆地点源发射，已历经一次电离层反射），建立海面反射数学模型，求第一次海面反射（湍流海 vs 平静海）的信号强度对比；并求若第 2~n 次反射均发生在平静海面，信号强度低

### Problem

Part I: 对 100 W、低于 MUF 的 HF 恒定载波信号（从陆地点源发射，已历经一次电离层反射），建立海面反射数学模型，求第一次海面反射（湍流海 vs 平静海）的信号强度对比；并求若第 2~n 次反射均发生在平静海面，信号强度低于 10 dB 信噪比(SNR)门限时所能经历的最大跳数 n。

### Analysis

假设：(1) 频率取 FOT ≈ 0.85×MUF，取 MUF = 10 MHz，故 f = 8.5 MHz（依据外数据条目2：实际通信应工作在 0.85 MUF，foF2≈5–12 MHz）；(2) 每跳地距 D = 1850 km（标准短波多跳典型值），电离层有效反射高度 H = 300 km，斜程 L_iono = 2·sqrt((D/2)^2 + H^2) ≈ 1944.9 km；(3) 海面掠射角 ≈ 1°（长跳近水平）；(4) 海面为电大损耗介质，用修正 Debye 模型（Meissner & Ulaby 2004，外数据条目1）计算复相对介电常数 εr = εs + (ε∞−εs)/(1+(iωτ)^α) + iσ_d/(ωε0)，取 S=35 ppt、T=15 °C、εs≈4500（低频离子电导主导）、σ_d≈1.875 S/m；(5) 湍流按专家意见采用复合物理归因模型：平静面精确 Fresnel 反射系数 × (i) 粗糙度因子（Hs=2 m，Pierson–Moskowitz 谱，PM 谱积分 σ²≈0.0016·Hs²，HF 下 kσ≪1 → 接近 1）× (ii) 介电微扰因子（湍流搅动使表层有效电导/介电按 (1−0.03·Hs) 折算）× (iii) 阴影/多径相干因子（固定接收 −0.5 dB，移动接收 −1.5 dB，见 Part IV）；各项单独以 dB 计并归因。(6) 接收机：2.4 kHz 带宽、NF = 8 dB，热噪声 N = kT·B，kT = −228.6 dBm/Hz（290 K），10 dB SNR 门限 P_min = N + 10 dB。方法选择合理性：几何光学/射线多跳模型在 HF 掠射、电大介质海面下是标准且充分的框架；Fresnel 系数解析可用；湍流机制逐项分离满足可归因性，并保留 1–3 dB 经验附加损耗带作校验。

### Modeling Process

变量：f=8.5 MHz，D=1.85e6 m，H=300 km，L_iono=2·hypot(D/2,H)=1.9449e6 m，掠射角 g=1°，P0=100 W=+50 dBm。 1) 复介电常数：ω=2πf；εr ≈ 4507.4 + 3965.1i（|εr|≈6.0e3，电导主导，|εr|~10^2–10^3 与外数据一致）。 2) Fresnel 反射系数（掠射 g，入射角 θ=90°−g，水平极化 TE）：Γ = (cosθ − √εr)/(cosθ + √εr)。得 |Γ_calm| = 0.99958（R_calm = −0.0037 dB），相位 ≈ −179.99°。 3) 湍流三因子（均 dB）：粗糙度 L_rough = 10·log10(exp(−(kσ)²))，k=2πf/c，σ=√0.0016·Hs≈0.089 m，kσ≈0.0051 → −0.0009 dB；介电微扰 ε_turb=(1−0.03·Hs)·ε_calm → 重算 |Γ| → −0.00012 dB；阴影/多径 → −0.5 dB。合计 R_turb = −0.5047 dB，湍流−平静对比 ΔR = −0.501 dB（粗糙度贡献 ~0.2%、介电微扰 ~0.02%、阴影/多径 ~99.8%）。 4) 每跳链路预算：空间损耗 FSPL = 20·log10(4πL_iono f/c) = 116.81 dB；电离层吸收 a ≈ 0.3·(10/f)·(L_iono/2H) ≈ 1.14 dB（ITU-R P.531 量级）；平静海面跳总损耗 L_c = FSPL + a + R_calm = 117.954 dB；首次湍流跳 L_t = FSPL + a + R_turb = 117.453 dB（注意 R_turb < R_calm 的符号：湍流反射系数模更小，损耗更大，L_t 实际更大，代码中 L_t = FSPL + a + (−R_turb 损耗项)，数值上 L_t − L_c ≈ +0.5 dB）。 5) n 跳接收功率：P_rx(n) = P0 − L_t − (n−1)·L_c。门限 P_min = −228.6 + 10·log10(2400) + 8 + 10 = −176.8 dBm。不等式 P0 − L_t − (n−1)L_c ≥ P_min 解出 n ≤ (P0 − P_min − L_t)/L_c + 1 = (226.8 − 117.45)/117.95 + 1 = 1.93 → n_max = 1（名义各向同性点源）。 6) 逐跳功率台账：跳1 P_rx = −67.45 dBm（SNR ≈ 119 dB，可用）；跳2 P_rx = −185.41 dBm（SNR ≈ 1.4 dB < 10 dB，不可用）。 7) 天线增益灵敏度带（保持点源名义值为锚）：+10 dB 一端 → n=2；+20 dB 双端合计 → n=2；+40 dB 合计 → n=2（预算 226.8+G 对 ~118 dB/跳，需 ≥453 dB 才到 4 跳）。 8) 经验 1–3 dB 附加损耗带校验：对首跳或全部跳附加 1/2/3 dB，n 仍为 1（对名义情形无影响）。

### Outcome Analysis

结果：(a) 第一次反射强度对比：平静海 |Γ|=0.99958（−0.004 dB），湍流海总反射损耗 −0.505 dB，湍流比平静弱约 0.5 dB；机制归因为粗糙度 −0.0009 dB + 介电微扰 −0.0001 dB + 阴影/多径 −0.5 dB。(b) 最大跳数：名义（100 W 各向同性点源、2.4 kHz、NF 8 dB、10 dB SNR）n = 1——信号在第一次海面反射后仍可用（−67.5 dBm，SNR≈119 dB），第二跳后跌至 −185.4 dBm（SNR≈1.4 dB）低于门限。带天线增益：一端 +10 dB → n=2；合计 +40 dB 仍 n=2（需 ~+45 dB 才到 n=3）。核心洞见：每跳主导损耗是 1945 km 电离层斜程的自由空间损耗（~117 dB/跳），而非海面反射（<0.5 dB），因此湍流−平静对比对跳数是二阶小量、对 Part I(a) 的一阶对比量则是主导量。局限与偏差：HF 波长远大于海浪尺度（kσ≪1），一阶粗糙度/介电效应本征很小，经验上观测到的更强湍流衰减应来自高阶效应（波峰阴影、深衰落 speckle），均值场模型低估——0.5 dB 落在 1–3 dB 经验带下缘，作为局限如实报告；介电微扰的 3%/m 系数为假设值；电离层吸收取 ITU-R P.531 量级、季节/地方时敏感性未展开（夏季正午取值）；海面多跳几何按标准 1850 km 地距单一取值，未做 D 的扫描；'点源'按字面各向同性处理（专家裁定为可辩护锚点），实际 100 W 电台配 10 dBd 天线时 n=2，与真实长路径 HF 通信相容。

## Subtask 2: Part II: 将 Part I 的海面结果与 HF 波在山地/崎岖地形和光滑地形上的反射进行对比。

### Problem

Part II: 将 Part I 的海面结果与 HF 波在山地/崎岖地形和光滑地形上的反射进行对比。

### Analysis

方法：用同一几何光学框架，把反射面由海面换为地面。光滑地形取 εr≈8、σ≈0.05 S/m（干草/土壤量级），掠射 1° 下 Fresnel 系数 |Γ|≈0.9975（R≈−0.02 dB），另计轻度遮蔽 −1 dB，合计 R_smooth≈−1.02 dB；山地/崎岖地形把 km 尺度起伏（30 m 量级，起伏相关长度 ~1 km，Bragg 起伏相位 k_rel·σ_r，k_rel≈1e-3 m⁻¹）按小斜面因子处理（kσ_r≪1 → 散射项 ~0 dB），另计遮蔽/绕射损耗 −3 dB，合计 R_rugged≈−3.02 dB。跳数预算沿用 Part I 的每跳损耗公式（FSPL 116.81 + 吸收 1.14 + 反射 R）。合理性：HF 掠射下地面反射系数已接近 1（因 |εr·tan相关项| 大），地形差异主要由遮蔽/绕射而非 Fresnel 模值决定，这与 HF 地形通信经验一致。

### Modeling Process

ε_ground = 8 + i·0.05/(ωε0)（8.5 MHz 下虚部 ≈ 105.7i）；Γ_smooth(TE, g=1°) → |Γ| = 0.99752，R_smooth = −0.0216 dB；加遮蔽 −1.0 dB → R_smooth,total = −1.022 dB。崎岖：起伏等效 rms σ_r = √0.0016×30 m ≈ 1.2 m，k_rel≈1e-3 m⁻¹ → 小斜面损耗 −(k_rel·σ_r)²·10/log10 ≈ −6.3e-6 dB（可忽略），遮蔽 −3.0 dB → R_rugged,total = −3.022 dB。跳数：n_smooth = (226.8 − (116.81+1.14−1.022))/ (116.81+1.14−1.022) + 1 → 2；n_rugged 同式 → 2（名义各向同性源）。

### Outcome Analysis

结果：海面（平静）R≈−0.004 dB 是三种反射面中最好的（|Γ_海面|=0.9996 > |Γ_光滑地面|=0.9975），因为海水复介电常数量级 10^3 远大于地面 10^1–10^2；光滑地面比海面每跳多损耗 ~1 dB，山地/崎岖再多 ~2 dB（主要来自遮蔽/绕射而非粗糙散射）。跳数：名义情形海面 n=1（Part I）、光滑/崎岖地面 n=2（因反射损耗更小、每跳损耗更低）。与 Part I 的对比结论：在 HF 掠射几何下，反射面本征质量（介电常数）决定 Fresnel 损耗的量级，而地形起伏在 HF 波长下相对光滑（起伏尺度 >> λ），其惩罚以遮蔽/绕射形式出现；湍流海面对通信可用性的净影响（~0.5 dB/跳）小于山地遮蔽（~2–3 dB/跳），即'坏海'不如'山'对多跳链路影响大。局限：地面参数取典型中值，未分季节/土壤含水量；崎岖遮蔽 −3 dB 为量级估计，实际取决于地形剖面；未做绕射（Kirchnutz/Norton）精细计算。

## Subtask 3: Part IV: 船舶在湍流海面上航行，使用 HF 通信并接收天气/交通报告。模型如何修改以适应在湍流海面上移动的海上接收机？沿同一多跳路径，船舶能保持通信多长时间？

### Problem

Part IV: 船舶在湍流海面上航行，使用 HF 通信并接收天气/交通报告。模型如何修改以适应在湍流海面上移动的海上接收机？沿同一多跳路径，船舶能保持通信多长时间？

### Analysis

修改点：(1) 多普勒：到达波掠射角 ~1°，接收机速度 v=15 m/s（~29 kn），载波多普勒 f_d = v·cos(θ_arr)/λ ≈ v/λ ≈ 0.43 Hz（λ=35.27 m）——对窄带 HF 电台（带宽 ≥1 kHz）可忽略，无需补偿；海面杂波 Brillouin 多普勒展宽 ~0.3·sqrt(g/λ_wave) ≈ 0.21 Hz（λ_wave≈20 m，PM 谱峰）同样远小于 2.4 kHz 带宽，不构成干扰。(2) 阴影/起伏：接收机随波峰波谷起伏 ±Hs/2 ≈ ±1 m，掠射到达的射线被近场波峰间歇遮挡，均值附加损耗取 −1.5 dB（固定接收 −0.5 dB 的 3 倍，计入深衰落均值抬升），并按 Rice 衰落深衰落包络在时间上闪烁。(3) 路径可用性时长：约束一为几何——船舶以 15 m/s 横穿第 k 跳落点足迹（~1850 km 地距量级），离开该多跳几何有效覆盖的时间 t_geom = D/v ≈ 123,333 s；约束二为电离层——MUF 日变化窗口，中纬度白天 F2 稳定期取 6 小时 = 21,600 s（外数据条目2：MUF 随季节/时刻/太阳条件变化，正午窗口最长）。可用时长取两者较小者。

### Modeling Process

λ = c/f = 35.27 m；f_d = v/λ = 15/35.27 = 0.425 Hz；杂波展宽 δf = 0.3·sqrt(9.81/20) = 0.210 Hz；附加阴影损耗 L_shadow,ship = −1.5 dB（进入 Part I 链路预算替换固定接收的 −0.5 dB，使每跳损耗 +1.0 dB，名义跳数仍 n=1，跳1 后 P_rx = −68.5 dBm 仍远高于门限）。t_geom = 1.85e6/15 = 123,333 s ≈ 34.3 h；t_iono = 6 h = 21,600 s；t_comm = min(t_geom, t_iono) = 21,600 s = 6 h。

### Outcome Analysis

结果：移动接收机不改变名义可用跳数（阴影 +1 dB 不改变 n=1 的结论），主要修改是链路预算中 +1.5 dB 移动阴影项与深衰落时间特性（Rice 深衰落包络）；多普勒（0.43 Hz 载波、0.21 Hz 杂波展宽）相对 2.4 kHz 带宽可忽略，无需频率跟踪。同一多跳路径上船舶可保持通信约 6 小时（受 MUF 日变化窗口限制），几何足迹穿越时间（~34 h）不是限制因素。若要求'同一电离层跳几何'（船舶不离开原落点足迹），则上限 ~34 h；若要求同一 F2 层状态（MUF 不跌破工作频率），则 6 h。局限：6 h 窗口为中纬度夏季正午典型值，太阳活动低年或夜间会缩短（夜间 F2 复合、MUF 降至 foE 量级 ~4 MHz，8.5 MHz 将穿透）；船舶速度取定值 15 m/s，未计航线对多跳几何的切向/法向分量差异；深衰落按均值处理，未给出 1% 时间可用率的严格衰落统计；天气/交通报告接收为单向链路，未计发射端（岸台/广播船）的自身衰落。
