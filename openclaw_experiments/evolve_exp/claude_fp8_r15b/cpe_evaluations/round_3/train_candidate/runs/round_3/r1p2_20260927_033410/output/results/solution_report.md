### Problem

子任务(a)：探索美国机场安检通道中旅客的流动并识别瓶颈。目标：对完整安检流程（A区证件检查→B区开放安检线（行李传送带X光扫描与毫米波/金属探测人体扫描并行，部分被标记者进入D区人工复检）→C区取包离开；另有TSA Pre-Check快速通道）建立可运行的流量模型，用数据标定各阶段服务参数，识别当前流程中的问题区域（瓶颈位置）及其成因。范围：单通道、10小时运营窗口（06:00–16:00）、基于提供的8.8分钟观测数据外推的到客率，含Pre-Check与常规两类旅客。

### Analysis

建模思路（经专家确认的混合框架）：以全通道离散事件仿真（DES）为主体刻画队列交互、传送带并行结构、标记复检返工与通道开关规则；用解析M/M/c（Erlang-C）模型对各阶段做交叉验证，并导出闭式 staffing 规则。合理性：纯解析模型无法表达传送带批量、复检返工与高峰需求波动（问题中所述'无法解释的长队'正是饱和系统的方差特征），纯DES又缺乏可辩护的瓶颈归因与政策公式；混合框架两者兼得，且解析服务率与DES采用同一组输入参数（μ_id=1/63s、μ_line=1/60s、μ_belt=1/37s）保持一致。关键假设：(1) 到客为每小时率的Poisson流，8.8分钟快照的到客间隔率乘以日内权重（10:00高斯峰+0.35底）外推到全天——这是模型最弱假设，已做0.5×–1.5×敏感度分析；(2) 观测数据中'ID Check Process Time'记录的是证件核验到呼叫下一位的间隔（均值11.2s），完整工作站服务时间按核验+文件处理估计为常规63s、Pre-Check 35s（lognormal）；(3) 扫描线服务= max(行李传送带环节60s, 人体扫描50s)，被标记（常规12%、Pre-Check 3%）者追加~150s人工复检；(4) Pre-Check按'每3条常规线配1条Pre-Check线'的比例配置，服务更快（免脱鞋/腰带/电脑，传送带环节×0.75、人体扫描×0.90）；(5) 标志物/复检率与复检时长为工程估计值。

### Modeling Process

解析部分：每阶段为M/M/c队列。利用率 ρ(c)=λ/(c·μ)；Erlang-C等待概率 P_wait(c,ρ)= [ (cρ)^c/!(c)! · 1/(1−ρ) ] / [ Σ_{k=0}^{c−1} (cρ)^k/k! + (cρ)^c/!(c)!·1/(1−ρ) ]；平均等待 E_W=P_wait/(c·μ−λ)；系统内人数 E_L=λ(1/μ+E_W)。staffing规则（闭式政策公式）：c_min(λ,μ,p99)=满足 ρ<1 且 E_W(c)·ln(100)≤p99 的最小c（等待时间近似指数尾，99分位≈E_W·ln100）。DES部分：事件驱动，事件类型{到客, 证件完成, 扫描线完成, 取包完成}；每阶段c个同构服务台+FIFO队列；服务时间取lognormal（由数据均值与CV标定）；扫描线服务=max(传送带环节, 人体扫描)+标记复检；每日按小时分60s块用Poisson计数播种到客（PC与常规独立双流）。指标：各阶段与总等待的mean/p50/p90/p99/max/CV，以及服务水平分位数（Pre-Check<10min、常规<30min 的占比，与TSA/GAO标准对比）。求解：/public1/home/stu52275901007/anaconda3/envs/math_modeling/bin/python 运行 code/checkpoint_model.py，8次重复取均值。

### Outcome Analysis

核心发现：在观测到客量下（峰值λ≈951 pax/hr，快照中8.8分钟出现58名Pre-Check+47名常规旅客），当前通道配置（4个证件台/4条扫描线/3条取包带）在峰值时段每个阶段都饱和：解析 ρ_id=2.08（用完整工作站服务率63s计，若按观测的11.2s呼叫间隔则ρ更高）、ρ_lines=1.32、ρ_belt=1.63，均>1；DES基线总等待均值≈1020min、p99≈1970min，常规旅客<30min占比仅1.6%（GAO标准99%），Pre-Check<10min占比0.6%（TSA基准99%）。瓶颈归因（按'到达该阶段时系统最紧张'排序）：证件检查为第一瓶颈（λ/c·μ最高、呼叫间隔方差大CV=0.33），取包传送带为第二瓶颈（ρ=1.63且3条带为固定硬件），扫描线第三。'无法解释的长队'得到机制解释：ρ>1时队列长度无稳态，等待呈重尾且间歇性爆炸——高方差是饱和的特征而非独立故障。staffing规则给出峰值所需容量：证件台c_min=17、扫描线c_min=16、取包带c_min=10（scale=1.0）；0.5×–1.5×外推敏感度下ρ_id始终>1（1.04–3.12），c_min(id) 9→26、c_min(lines) 9→24、c_min(belt) 5→15，结论对外推假设稳健。局限与偏差：(1) 快照到全天的外推不可验证，是最弱假设（已做敏感度分析）；(2) 完整ID工作站服务时间(63s)是估计值，观测的11.2s只是呼叫间隔子集——若真实服务更短，ρ_id下降但结论方向不变（belt仍>1）；(3) M/M/c的指数尾对p99为近似；(4) 单通道单次观测，未含航班到达批次效应（会加剧峰值）；(5) DES随机误差：8重复下服务水平分数的95%CI约±1个百分点。

### Problem

子任务(b)：设计并模拟对当前流程的两项以上改进，证明其对吞吐量与等待时间方差的影响。目标：在保持同等安保标准前提下提高通道吞吐并降低等待方差。范围：两项过程改进（不改变安保流程本身）及其与扩容的组合效应，全部在同一DES框架中模拟。

### Analysis

基于(a)的瓶颈归因选择改进方向。改进1（扩容型流程再配置）：证件台4→6、扫描线4→6——直接抬高第一、第二瓶颈的容量c，降低ρ与Erlang-C等待概率；代价是 staffing 成本，故同时给出解析 staffing 规则作为'按需求预置'的替代（见子任务d）。改进2（自服务分装/自助传送带）：旅客在排队末端预先完成脱鞋、取物、分箱，把'传送带环节'从60s压缩到30s（并行环节从belt转为scan，瓶颈环节服务时间减半），取包带滞留从37s降到22s；这缩短扫描线服务时间并降低服务方差（staging环节原本CV最大）。两项改进互补：改进1抬容量，改进2降单客占用与服务方差，故组合效应应超线性。模拟方法：同一DES，基线8重复 vs 各改进8重复，比较总等待分布与两个服务水平分数。

### Modeling Process

改进1：c_id: 4→6，n_lines: 4→6（其余参数不变）。改进2：belt_serve: 60s→30s，belt_reg: 37s→22s（scan_serve 50s不变，故扫描线服务=max(30,50)×旅客系数，标记复检不变）。组合：两者叠加。解析侧对应变化：μ_line=1/60s→1/50s（瓶颈环节切换）、μ_belt=1/37s→1/22s；重新计算ρ与c_min。DES侧：run_des(rates, cfg, n_reps=8)，指标同(a)：总等待mean/p99/CV、pc<10min%、reg<30min%。另做容量阶梯扫描（n_lines∈{4,8,12}×c_id∈{4,8}×n_belt∈{3,6}，4重复）以量化'容量每增加一档'的收益。

### Outcome Analysis

结果（总等待，基线均值≈1020min）：改进1：均值351.6min（−65%），p99≈1120min，reg<30min 1.6%→2.8%，pc<10min 0.6%→1.2%；改进2：均值444.7min（−56%），reg<30min→2.4%；组合：均值241.2min（−76%），p99≈755min，reg<30min→5.6%，pc<10min→1.4%。CV基本稳定在0.58–0.60，说明在饱和区改进主要平移分布；真正的方差压缩出现在容量越过ρ=1之后。容量阶梯（无过程改进）：4/4/3→8/4/3均值降至579.5min（扫描线是绑定约束）；8/8/6→368.7min；12/8/6→156.0min、p99 278.8min、pc<10min 9.3%、reg<30min 17.5%。组合改进+容量(8/12/6)：均值152.0min（较基线−85%）、p99≈279min，reg<30min 17.5%→约19%、pc<10min 9.3%。结论：(1) 在观测到客量下，两项过程改进本身可将等待压缩76%，但无法达到GAO/TSA服务水平标准——容量才是绑定约束，改进是'任意容量下都有效的方差/均值削减器'；(2) 过程改进使同等 staffing 下可服务的需求提高约30–40%（等价于把c_min需求从17/16/10降到约12/12/8量级），降低扩容成本；(3) 扫描线数量比证件台数对吞吐更敏感（8/4/3 vs 4/4/3：−43%均值，而证件台4→8在4线配置下仅−0.5%），说明扩容应优先加扫描线。局限： staffing 成本未货币化；改进2假设旅客愿意且能够提前分装（需培训/引导，见d）；未模拟设备故障导致的临时降级。

## Subtask 3: 子任务(c)：文化规范/旅客风格敏感度分析。问题指出不同文化塑造不同的社会互动规则（美国重视个人空间、插队受社会谴责；瑞士强调集体效率；中国强调个体效率），要求将其作为敏感度分析纳入模型（可采用真实文化差异或模拟的旅客风格，如'较慢旅客'）

### Problem

子任务(c)：文化规范/旅客风格敏感度分析。问题指出不同文化塑造不同的社会互动规则（美国重视个人空间、插队受社会谴责；瑞士强调集体效率；中国强调个体效率），要求将其作为敏感度分析纳入模型（可采用真实文化差异或模拟的旅客风格，如'较慢旅客'），并说明安检系统如何 accommodating 这些差异以提高吞吐、降低方差。

### Analysis

经专家确认采用'旅客风格=服务环节乘数向量+插队倾向'的参数化（而非仅改变到达模式）：每种风格由四个乘数刻画瓶颈环节——t_stage（分装/上带速度）、t_scan（人体扫描配合速度）、t_belt（取包速度）、t_brief（证件呈递速度）——加插队倾向 p_cut（每次进入新阶段时尝试插队的概率；仅当该阶段有服务台空闲且队列非空时成功，即'插到队首'这一可见形式，把'插队受谴责'映射为低p_cut、把'个体效率优先'映射为高p_cut+快乘数）。四种风格（模拟风格，按题目许可标注，非文化测量）：US基准(1.0,1.0,1.0,1.0;p_cut=0)；中国个体效率(0.85,0.90,0.80,—;p_cut=0.20)；瑞士集体效率(0.85,0.90,0.85,0.90;p_cut=0.05)；模拟慢旅客(1.25,1.15,1.20,1.15;p_cut=0)。在推荐容量配置(8证件台/12线/6取包带)下对每种风格运行DES（4重复）。另做Pre-Check占比45%→70%的需求侧敏感度（$85/5年费用决定注册弹性，外部数据支持）。

### Modeling Process

服务时间改为 lognormal(m·t_style, s)，其中m为环节基准均值：svc_line=max(lognormal(60·t_stage·pc_f,0.35), lognormal(50·t_scan·pc_f,0.30))+标记复检；svc_belt=lognormal(37·t_belt,0.28)；svc_id=lognormal(63·t_brief,0.35)。插队机制：进入阶段k时以概率p_cut尝试，若 len(queue_k)>0 且该阶段存在空闲服务台则越过队列直接占用（cuts_ok计数），否则照常排队。Pre-Check混合率：将PC流率乘以 mix/0.45 重加权（总到客量不变，PC/常规份额变化）。指标：每种风格的总等待mean/p99/CV、pc<10min%、reg<30min%、插队尝试/成功次数。

### Outcome Analysis

结果（8/12/6容量下）：US基准 均值156.0min、p99 278.8min、CV 0.63、reg<30min 17.5%；中国个体效率 均值151.5min（−2.9%）、p99 273.1min、reg<30min 18.2%，插队尝试5640次/成功12次——快分装小幅降均值，但插队几乎无法成功（饱和区队列总非空），说明插队在饱和系统里收益趋零、代价是冲突与方差；瑞士集体效率 均值111.9min（−28%）、p99 200.9min（−28%）、reg<30min 20.9%——集体效率（快分装+快取包+有序呈递）是最有效的风格，方差同时下降；模拟慢旅客 均值232.7min（+49%）、p99 419.5min、reg<30min 10.3%——慢风格使服务水平大幅恶化，CV反而略降（0.61）但分布整体右移。Pre-Check混合率：45%→70%（总量不变）使总体均值36.8→90.4min、reg<30min 43.3%→23.4%、pc<10min 25.0%→13.9%——因为Pre-Check线池只有常规线的1/3（'1:3'配置），高注册率反而把更多客导入容量较小的PC池，总体恶化；这给出系统 accommodating 文化差异的关键设计约束：PC池容量必须随注册率扩容。系统 accommodating 措施（据结果）：(1) 快风格（瑞士/中国）：express lane + 提前分装引导 + 蛇形队列保持公平感知；(2) 慢旅客：辅助通道（协助分装/老年与行动不便旅客）与预留容量，否则其p99>400min；(3) 插队倾向高的人群：可见的FCFS蛇形队列+电子号码牌把'插队'外部化为可管理行为，饱和区插队收益≈0（12/5640成功）故社会规范+队列设计即可抑制，无需执法成本；(4) Pre-Check池按注册率动态扩容（每注册率+25pct，PC线+1），否则高注册文化地区总体等待上升。局限：乘数为风格化假设（题目允许模拟风格）；未做混合人群单次运行（45/30/30/5），因为专家回复指出其边际洞察有限、参数不可识别；插队成功的定义（队首空闲）是简化。

### Problem

### Analysis

政策设计原则：把模型中的闭式规则与触发阈值直接转化为运营规则，使管理者无需仿真即可执行；全球通用规则基于瓶颈归因（容量绑定、方差是饱和特征）；分文化/旅客类型建议来自(c)的风格敏感度。验证策略：(1) 数据层——服务参数直接来自CSV（ID呼叫间隔、belt滞留、mm-wave间隙）；(2) 交叉验证——解析Erlang-C与DES在ρ、等待量级上一致（两者都显示基线饱和、扩容后E_W与DES均值同数量级）；(3) 服务标准锚定——外部数据（GAO-18-563T的30min/99%、TSA的Pre-Check 10min/99%与$85/5年）作为校准目标与验收标准；(4) 假设稳健性——0.5×–1.5×外推敏感度显示核心结论（ρ>1、容量绑定）不变。

### Modeling Process
