## Subtask 1: 任务(a)：建立一个可探索乘客通过机场安检检查点全流程的模型，并识别当前流程中的瓶颈与问题区域。范围包括四个阶段：(A) 证件核验排队与核验、(B) 开放安检线（行李分箱准备 + X光机传送带扫描 与 人体毫米波/金属探测扫描 两条并行活动

### Problem

任务(a)：建立一个可探索乘客通过机场安检检查点全流程的模型，并识别当前流程中的瓶颈与问题区域。范围包括四个阶段：(A) 证件核验排队与核验、(B) 开放安检线（行李分箱准备 + X光机传送带扫描 与 人体毫米波/金属探测扫描 两条并行活动，失败者进入D区人工搜身）、(C) 后传送带取物离开；Pre-Check 与常规通道以约 1:3 的通道比并行运行，且共享证件核验民警。数据为一段约100分钟的现场快照日志（58条到达记录、两名民警核验时钟、扫描仪出机时间戳、两条X光带出包时间戳、29条取物时间），另采用两条外部实证基准：TSA 常规通道'<30分钟 99%'服务标准（GAO-18-563T）与 Pre-Check '<10分钟 99%'目标（TSA 官方页面）。

### Analysis

假设：(1) 快照中的服务时间戳是通道组（3常规+1 Pre-Check）的聚合输出，据此反推并行设备数，而非直接当作单台设备速率（专家第二轮修正：不应强加 观测速率÷通道数，而应从服务时间列拟合同阶段服务分布，再让并行台数在拟合中确定，使模拟组吞吐量与观测聚合匹配）；(2) 证件核验日志记录的是'呼叫下一位'间隔（均值1.65 s），完整文件审查另含一个10 s的陈述性审查阶段；(3) 行李侧：常规旅客分箱准备90 s（脱鞋/腰带/外套、电脑分箱等），Pre-Check 仅40%（36 s），X光带上包服务45 s（由带1的36包/100 min聚合推出）；(4) 人体扫描出机间隔经验重采样（中位11 s），4台并行；(5) 搜身复检率15%（常规）/5%（Pre-Check），服务60 s；(6) 取物时间经验重采样（均值28.6 s，CV 0.49，对数正态拟合AIC最优）；(7) 到达间隔直接经验重采样观测到的103个间隔（CV²=1.40），不另设人为混合参数（专家第二轮要求以观测间隔分布锚定方差）。建模框架（专家第一轮认可的混合方案）：解析法做瓶颈定位（利用率ρ与Kingman近似），离散事件仿真（DES）承担任务(b)改造与(c)敏感性中的max(两流)同步与返工逻辑。方法合理性：安检阶段行李X光与人体扫描并行且需同步（阶段时间=两流最大值），纯解析排队网络在此结构上系统性失真，故仅用解析法定位瓶颈、用DES做what-if。

### Modeling Process

变量：λ_p=0.57/min（Pre-Check到达率）、λ_r=0.29/min（常规），λ=λ_p+λ_r=0.86/min；到达间隔序列 G_i 经验重采样并按均值1/λ缩放。阶段服务：ID核验 S_id ~ 经验重采样(间隔序列, 均值1.65 s, CV²=0.88, 对数正态s=0.00167, scale=0.00110) + 10 s审查阶段，c=2名共享民警；行李侧 S_bag = Prep + Belt，Prep_regular=90 s、Prep_pre=36 s，Belt=45 s，c_b=2条带并行（FIFO，取最早空闲带）；人体侧 S_person ~ 经验重采样(出机间隔, 中位11 s)，c_s=4台并行，失败概率q（0.15/0.05）追加 S_pd=60 s；取物 S_col ~ 经验重采样(均值28.6 s, CV 0.49)。乘客总耗时 T = W_id + max(S_bag, S_person) + S_col（W_id为ID队列等待）。瓶颈定位（解析）：ρ_id = λE_id/c ≈ 0.083–0.15，Kingman W_q ≈ 0.2–0.9 s → ID非瓶颈；行李侧服务时间 常规135 s vs 人体侧约11 s×忙时 → max()由行李侧主导（常规）；人体侧在Pre-Check流与复检返工时主导。方差来源：到达间隔CV²=1.40的突发到达 + max(两流)同步 + 15%复检返工。DES实现：事件驱动（到达/ID完成/行李完成/人体完成四类事件，堆优先队列），330 min仿真时长、30 min预热，每情景20次独立重复（种子1000s+7）。

### Outcome Analysis

基线（快照配置：2民警/4扫描仪/2带，λ=0.86/min，Pre-Check占比55%）：n≈247，平均等待3.95 min，SD 1.79 min，P95 7.57 min，P99 9.02 min，100%<30 min，98.6%<10 min。瓶颈结论：当前配置下瓶颈是安检阶段的行李侧（分箱准备+X光带）与人体扫描阵列在突发到达下的max()同步，而非ID核验（Kingman证实）；方差主要来自突发到达（间隔CV²=1.40）与15%复检返工，其次才是行李侧服务时间本身。验证：低负载(λ=0.40)吞吐量0.414 vs 0.40 pax/min，守恒成立；ID队列解析W_q与DES一致。局限：(1) 全部服务参数来自单段100 min快照，外推到全天/高峰需再校准；(2) 分箱准备90 s与X光带45 s为文献一致假设（日志无进入带的时间戳）；(3) 快照到达率若持续全日（0.86 pax/min > 人体扫描阵列可持续率0.44 pax/min）将突破服务标准——sustained工况验证中模拟均值3.86 min但Pre-Check侧10 min标准在持续高负载下不可持续，这正是任务(d)的驱动失效模式；(4) 未建跨检查点/全机场客流模型。

## Subtask 2: 任务(b)：设计两个（或更多）对当前流程的改造方案，提升乘客吞吐并降低等待时间方差，并用模型量化其影响。候选改造需保持同等安全标准。

### Problem

任务(b)：设计两个（或更多）对当前流程的改造方案，提升乘客吞吐并降低等待时间方差，并用模型量化其影响。候选改造需保持同等安全标准。

### Analysis

改造设计基于瓶颈分析：既然方差主要来自行李侧max()同步与突发到达，两个改造分别针对（1）行李侧服务时间的均值与方差（自助/预组织分箱，减少旅客在分箱区的操作时间与犹豫时间）、（2）人体扫描阵列容量与行李侧的联合再平衡（增开第5台扫描仪+分箱准备小幅压缩，使max()中两流更均衡）。两者均为结构性流程改造而非单纯加人，与ICM团队'有创造性地同时提高吞吐与降低方差'的要求对应。按专家第二轮要求，改造效果用DES量化（max同步与返工逻辑只有在仿真中才真正起作用）。评估指标：平均等待、SD、P95/P99、<10 min比例（Pre-Check基准）、<30 min比例（TSA标准）。

### Modeling Process

Mod1（自助/预组织分箱改造）：Prep_regular: 90 s → 54 s（-40%，旅客提前在分箱区外完成分箱、自助式固定格口），其余参数同基线。数学上等价于 S_bag,regular = 54 s + 45 s = 99 s，使常规流max(S_bag,S_person)从135 s降至99 s，行李侧不再是常规流主导项，方差中由行李侧长尾贡献的部分被直接削减。Mod2（动态扩容+联合再平衡）：c_s: 4 → 5台扫描仪（按通道组可持续需求增配），Prep_regular: 90 s → 72 s（-20%）。人体侧可持续率由 4×(60/11)≈21.8 pax/min(阵列空闲极限) 对应的实际聚合0.44 pax/min 提升至约0.55 pax/min（+25%），同时行李侧降至117 s，两条流的服务时间分布更接近，max()的分布尾部变薄（E[max]对两流CV的联合敏感性下降）。两情景均保持λ=0.86/min、20次重复。

### Outcome Analysis

结果（20次重复均值）：Mod1：平均等待 3.95→2.57 min（-35%），SD 1.79→0.89 min（-50%），P95 7.57→4.35 min，P99 9.02→5.42 min，<10 min比例 98.6%→100%。Mod2：平均等待 3.11 min（-21%），SD 1.26 min（-30%），P95 5.73 min，P99 6.94 min，<10 min 100%。Mod1在方差削减上优于Mod2（其直接攻击行李侧长尾），Mod2在可持续吞吐上更优（阵列+25%），两者互补：Mod1是'方差削减+高峰容量'措施，Mod2是'高峰容量+再平衡'措施。组合情景 Mod1+文化A（不利旅客风格）仍达平均2.95 min、P95 5.21 min、100%<10 min，说明Mod1对不利条件稳健。局限：-40%/-20%的压缩幅度是工程假设而非测量值，落地前需用试点机场实测分箱时间分布再校准；Mod2假设第5台扫描仪可在高峰前就位（物理与排班约束未建模）。

### Problem

任务(c)：文化规范/旅客风格敏感性分析。美国人重视个人空间、对插队有社会污名；瑞士人强调集体效率；中国人（题目设定）强调个体效率；另可模拟与特定文化无关的'慢速旅客'。要求给出安检系统如何 accommodates 这些差异以提高吞吐并降低方差。

### Analysis

将文化差异参数化为对流程时间的乘子，而非改写模型结构（保持可辨识性）：空间意识强的旅客在分箱区停留更久（怕碰他人物品/保持距离），取物时也更慢；集体效率型旅客分箱更协调、取物更快；个体效率型旅客自我节奏快、分箱最快；慢速旅客两项都慢。乘子只作用于分箱准备与取物两个'旅客自主时间'阶段（民警主导的ID核验、X光带、扫描仪不受文化影响），这使敏感性分析直接对应'系统如何 accommodating 差异'——即系统应针对这两个阶段做差异化设计。四情景：A 空间意识（bin +20%，coll +15%）、B 集体效率（bin -15%，coll -10%）、C 个体效率（bin -25%，coll 0）、D 慢速旅客（bin +30%，coll +25%），均叠加在基线配置上，20次重复。

### Modeling Process

对情景k：S_bag,k = S_bag × m_bin,k，S_col,k = S_col × m_coll,k，其中 (m_bin,m_coll)：A=(1.20,1.15)，B=(0.85,0.90)，C=(0.75,1.00)，D=(1.30,1.25)。到达率与设备配置不变（文化改变的是旅客侧时间，不是需求）。总耗时 T_k = W_id + max(S_bag,k, S_person) + S_col,k。附加组合实验：Mod1×A（不利风格下检验改造稳健性）。

### Outcome Analysis

结果（20次重复均值）：A：平均5.49 min，SD 2.64，P95 10.69，<10 min 90.2%；B：3.24 min，SD 1.36，P95 6.11，99.8%；C：2.96 min，SD 1.15，P95 5.32，100%；D：6.86 min，SD 3.28，P95 13.02，<10 min仅79.7%（失效模式）。结论：(1) 旅客风格对等待的影响完全经由分箱准备/取物两个阶段传导，且与基线方差同向叠加——D情景的SD(3.28)是基线的1.8倍，说明'高方差等待'问题在慢速/谨慎旅客中会自我放大；(2) 系统 accommodates 差异的手段：为A/D型旅客提供带个人空间隔断、固定格口的分箱区（把'空间成本'工程化，把m_bin从1.20-1.30压回~1.0）；为B/C型旅客提供单列快速流（少等待点、一次性完成分箱-过检-取物，进一步压低其m_bin）；(3) 改造的稳健性：Mod1在A情景下平均2.95 min、100%<10 min，即自助分箱改造对最不利文化风格仍达标。局限：乘子幅度是假设（题目允许'模拟不同旅客风格'），未区分同文化内部差异；未建模文化对到达时刻分布（航班结构）的影响。

## Subtask 4: 任务(d)：基于模型向安检管理者提出政策与流程建议（可全球适用、可针对特定文化/旅客类型），并完成模型验证、优缺点评估与未来工作。

### Problem

任务(d)：基于模型向安检管理者提出政策与流程建议（可全球适用、可针对特定文化/旅客类型），并完成模型验证、优缺点评估与未来工作。

### Analysis

建议框架采用专家第三轮认可的'surge-and-variance'（高峰与方差）叙事：由于快照到达率下所有情景均已满足30 min/99%标准，把'加容量'作为主头条会高估一段100 min日志的能力；最强证据是改造削减SD/P95并挽救不利文化与持续高负载工况，故建议以方差削减+高峰容量为主线，以持续负载突破（0.86 pax/min > 人体扫描阵列可持续0.44 pax/min）与文化D失效（79.7%<10 min）为驱动失效模式。门槛型触发器为可操作的政策构造（专家第三轮确认：X须由校准模型导出、实时可观测、并注明快照校准 caveat）。

### Modeling Process

动态开线触发器：对并行台数c_s∈{4,5,6}，用校准DES做λ二分搜索，求满足 P95(T) < 10 min 的最大可持续到达率 X(c_s)。结果：X(4)≈0.93 pax/min（15 min滚动到达率），X(5)、X(6)在同一搜索网格内同为0.93（6次重复下分辨率有限，表明在λ≤1.86网格内瓶颈先转移到行李侧，触发器对扫描仪台数不敏感——本身即一条政策信息：只加扫描仪不加行李侧容量时触发点不变）。Pre-Check占比扫描（固定配置）：pre_share 0.30/0.45/0.55/0.70 对应平均等待 5.60/4.30/3.86/3.28 min，单调下降→通道比应随注册占比动态调整。验证方法：(1) 守恒性——低负载λ=0.40时模拟吞吐0.414 pax/min（匹配）；(2) 解析交叉验证——ID阶段ρ≈0.083、Kingman W_q≈0.2 s与DES一致，确认ID非瓶颈；(3) 分布拟合质量——ID间隔对数正态AIC=-80.2优于正态-57.7/指数288.9，取物对数正态AIC=1.17优于正态3.24；(4) 服务级对标——基线98.6%<10 min、100%<30 min，与TSA/Pre-Check公开基准方向一致。

### Outcome Analysis

政策建议（surge-and-variance框架）：(1) 自助/预组织分箱（Mod1）——全球适用，方差削减最大（SD -50%、P95 -42%），优先部署；(2) 实时动态开线：当15 min滚动到达率超过约0.9 pax/min（由校准模型导出、按机场再校准的区间0.8–1.0）时开启第5台扫描仪，且必须与行李侧扩容联动（否则触发点不移动）；(3) Pre-Check通道占比跟随实际注册占比动态调整（当前1:3对45–57%的需求偏低，扫描显示占比每+10个百分点平均等待约降0.6 min）；(4) 文化/旅客类型适配：为空间意识型与慢速旅客设带隔断的固定格口分箱区，为效率型旅客设单列快速流；全球适用项是(1)(2)(3)，(4)按机场旅客构成配置。验证与评估：优点——混合框架（解析定位+DES what-if）结构正确（max同步与返工在纯解析网络中失真）；全部随机输入经验重采样自同一份现场日志，无人为混合参数；20次重复给出均值±重复间波动。缺点/偏差——单段100 min快照校准（外推风险）；分箱准备90 s与X光带45 s为陈述假设；触发器分辨率受重复次数限制；未建模设备故障、民警缺勤、航班时刻结构；Pre-Check 99%<10 min基准在持续高负载下不可达，模型如实给出该突破。未来工作：多机场/多时段现场数据再校准；分箱时间实测；设备故障与排班的鲁棒性建模；将动态开线做成在线控制（模型预测控制）并与TSA AOC监控接口对接。
