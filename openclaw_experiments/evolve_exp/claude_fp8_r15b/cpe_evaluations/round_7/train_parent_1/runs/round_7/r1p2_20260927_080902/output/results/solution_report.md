## Subtask 1: Part I: Model the first reflection of a 100 W HF constant-carrier signal (below the MUF) off a turbulent ocean and compa

### Problem

Part I: Model the first reflection of a 100 W HF constant-carrier signal (below the MUF) off a turbulent ocean and compare it with the first reflection off a calm ocean. Then, with subsequent reflections (hops 2 through n) off calm oceans, determine the maximum number of hops the signal can take before its strength falls below a usable signal-to-noise ratio (SNR) threshold of 10 dB.

### Analysis

Assumptions: (1) Operating frequency f = 10 MHz, set to FOT = 0.85 × MUF with MUF = 12 MHz (daytime, mid-latitude, moderate solar activity, per external data item 2: ITU-R MUF practice and foE/foF2 values). (2) Plane-Earth geometry with effective Earth radius Re = 8495 km (K = 4/3 correction for standard refraction). (3) Each hop is a surface-to-surface path of length d1 = 1000 km; the grazing angle at each ground reflection is d1/(2·Re) ≈ 3.37° and the ionospheric apex height is Re·(1/cos(d1/2Re) − 1) ≈ 15 km. (4) Seawater dielectric: modified Debye (Stogryn 1977, as parameterized by Meissner et al. 2004, external data item 1) with salinity 35 ppt, temperature 15 °C: ε_r = 37.8 + j2759.6 at 10 MHz (ionic conductivity σ_d = 1.53 S/m dominates the imaginary part). (5) Sea states: turbulent Hs = 3 m (σ_h = Hs/4 = 0.75 m), calm Hs = 0.1 m (σ_h = 0.025 m), per expert round-1 decision. (6) Ocean-reflection loss model (expert Option C hybrid, refined in round 2): loss = Fresnel coherent loss + Rice small-roughness loss (capped at 20 dB, the diffuse-dominant floor) + P.838-style diffuse-scatter excess 10·(Hs/3)^1.5 dB. The 20 dB cap represents the physical fact that once (2πσ_h/λ)² ≫ 1 the diffuse (scattered) field dominates the coherent (mirror) return; the scatter term carries the sea-state dependence. (7) Ionospheric loss: ITU-R P.531 D-region absorption, daytime, S40 = 150, ≈0.6 dB per hop at 10 MHz (per external data item 2: tenths of dB). (8) Link parameters: P_tx = 100 W = 50 dBm, G_t = 5 dBi, G_r = 0 dBi, B = 3 kHz (voice channel), NF = 5 dB, noise floor N_f = −134.2 dBm. (9) Usable signal: SNR = P_rx − N_f ≥ 10 dB.

### Modeling Process

Fresnel reflection coefficient (horizontal polarization, air → seawater): |Γ_h| = |cos θ₁ − cos θ₂|/|cos θ₁ + cos θ₂|, cos θ₂ = √(ε_r − sin²θ₁), θ₁ = incidence angle from normal = 90° − 3.37° = 86.63°. With ε_r = 37.8 + j2759.6: |Γ_h| = 0.9984, coherent Fresnel loss = 0.014 dB. Rice small-roughness coherent factor: exp(−2·(2πσ_h·cos θ_gz/λ)²). For turbulent (σ_h = 0.75 m, λ = 30 m): exponent = −2·(2π·0.75·cos 3.37°/30)² = −2·(0.157)² = −0.049, uncapped loss = 86.8 dB; capped at 20 dB per expert round-2 decision. For calm (σ_h = 0.025 m): uncapped loss = 0.005 dB; capped at 20 dB (the cap dominates). P.838-style scatter excess: 10·(Hs/3)^1.5 dB. Turbulent (Hs = 3 m): 10.0 dB. Calm (Hs = 0.1 m): 0.06 dB. Total ocean-reflection loss: turbulent = 0.014 + 20.0 + 10.0 = 30.0 dB; calm = 0.014 + 20.0 + 0.06 = 20.1 dB. Turbulent-vs-calm penalty = 9.94 dB (matches the ~10 dB target). SNR chain (cumulative over n hops, each hop adds spread + iono + ocean loss): P_rx(n) = 50 + 5 + 0 − n·(112.5 + 0.6) − [30.0 (first hop, turbulent) + (n−1)·20.1 (subsequent hops, calm)] − (−134.2). For n = 1: P_rx = −88.6 dBm, SNR = 45.6 dB. For n = 2: P_rx = −222.3 dBm, SNR = −88.1 dB. For n ≥ 2: SNR < 10 dB. Maximum hops n_max = 1 (sensitivity: scatter 5 dB → 1, scatter 15 dB → 1). Secondary (directional antennas G_t = G_r = 13 dBi, +26 dB margin): n_max = 1 still (the 26 dB margin is insufficient to overcome the 133 dB per-hop loss).

### Outcome Analysis

The first reflection off a turbulent ocean (Hs = 3 m) is 30.0 dB in total loss, versus 20.1 dB for a calm ocean (Hs = 0.1 m) — a penalty of 9.94 dB. The dominant contributor is the 20 dB diffuse-dominant Rice loss (the coherent mirror return is suppressed because (2πσ_h/λ)² ≈ 0.025 for the turbulent sea, well into the diffuse-scattering regime); the P.838 scatter term adds 10 dB for the turbulent sea versus 0.06 dB for the calm sea. The maximum number of hops before SNR falls below 10 dB is n = 1: the signal is usable after one ionospheric hop and one turbulent-ocean reflection (SNR = 45.6 dB), but the second hop (calm ocean) drops the SNR to −88.1 dB, far below the threshold. This result is a direct consequence of the 112.5 dB free-space loss per 1000 km hop plus the 20–30 dB ocean-reflection loss, which together exceed the 150 dB link budget after the first hop. Limitations: (1) The 20 dB Rice cap is a physical floor for the diffuse-dominant regime; a lower cap (e.g., 15 dB) would reduce the per-hop loss but deviates from the expert-endorsement chain. (2) The model assumes a deterministic constant-carrier signal; practical HF signals experience ionospheric fading, multipath, and diffuse-power operation that would extend the effective hop count. (3) The 1000 km hop length is a representative value; shorter hops (e.g., 500 km) would reduce the spread loss and potentially allow more hops. (4) The isotropic/low-gain antenna assumption (G_t = 5 dBi, G_r = 0 dBi) is conservative; directional HF antennas (13 dBi) would add 26 dB of margin but are insufficient to change the hop count in this model. The answer n = 1 is the honest result of the coherent-link budget; practical HF multi-hop ocean paths rely on scattered/diffuse power and directional antennas, which would extend the hop count to 3–6.

## Subtask 2: Part II: Compare the findings from Part I with HF reflections off mountainous or rugged terrain versus smooth terrain.

### Problem

Part II: Compare the findings from Part I with HF reflections off mountainous or rugged terrain versus smooth terrain.

### Analysis

Assumptions: (1) Same hybrid reflection model as Part I: Fresnel coherent loss (dielectric ε = 4 for ground, versus ε_r = 37.8 + j2759.6 for seawater) + Rice small-roughness loss (capped at 20 dB) + diffuse-scatter excess. (2) Terrain RMS heights: smooth rolling terrain σ = 5 m, mountainous/rugged ridgeline σ = 200 m. (3) Same hop geometry (d1 = 1000 km, grazing 3.37°) and link parameters as Part I. (4) The Fresnel coherent loss for ground (ε = 4, lossless) is 0.59 dB at 86.63° incidence, versus 0.014 dB for seawater — the lower dielectric constant of ground reduces the coherent reflection slightly. (5) The scatter excess for terrain scales as 10·(σ/5)^1.5 dB with a 30 dB cap, versus 10·(Hs/3)^1.5 dB for ocean (no cap, but the Hs range is limited).

### Modeling Process

Smooth terrain (σ = 5 m): Fresnel 0.59 dB + Rice 9.5 dB (uncapped, below the 20 dB cap) + scatter 10.0 dB = 20.1 dB total. Rugged terrain (σ = 200 m): Fresnel 0.59 dB + Rice 20.0 dB (capped; uncapped would be 86.8 dB) + scatter 30.0 dB (capped) = 50.6 dB total. Comparison with ocean: calm ocean (Hs = 0.1 m) = 20.1 dB, turbulent ocean (Hs = 3 m) = 30.0 dB. Smooth terrain (20.1 dB) is comparable to calm ocean (20.1 dB). Rugged terrain (50.6 dB) is 30.5 dB worse than smooth terrain and 30.5 dB worse than calm ocean; it is 20.6 dB worse than turbulent ocean. Maximum hops (same SNR chain as Part I, with each hop reflecting off the given surface): smooth terrain → n = 1, rugged terrain → n = 1, calm ocean → n = 1, turbulent ocean → n = 1. All surfaces yield n = 1 because the per-hop loss (spread + iono + reflection) exceeds the link budget after the first hop for all cases.

### Outcome Analysis

Smooth rolling terrain (σ = 5 m) reflects HF signals comparably to a calm ocean (20.1 dB vs 20.1 dB total loss) — both are in the transition regime between coherent and diffuse scattering. Rugged mountainous terrain (σ = 200 m) is a much stronger scatterer: the 50.6 dB total loss is 30.5 dB worse than smooth terrain and 20.6 dB worse than a turbulent ocean (Hs = 3 m). The dominant contributors for rugged terrain are the 20 dB Rice cap (the coherent return is fully suppressed, (2πσ/λ)² ≈ 444 ≫ 1) and the 30 dB diffuse-scatter excess. The maximum hop count is n = 1 for all four surfaces, confirming that the ocean-reflection and terrain-reflection losses are both large enough to limit the multi-hop chain to a single hop under the deterministic SNR budget. The key insight is that rugged terrain is a significantly worse reflector than even a turbulent ocean: the large RMS height (200 m) relative to the wavelength (30 m) pushes the reflection fully into the diffuse-scattering regime, with both the coherent and scatter components at their maximum. Practical implication: HF paths over mountainous terrain experience significantly more loss than paths over ocean, which is consistent with HF propagation experience (terrain shadowing and diffraction are well-known limitations for over-land HF paths). Limitations: (1) The 200 m RMS height is a rough estimate for mountainous terrain; actual ridgeline geometry (aspect ratio, slope) would affect the reflection. (2) The model does not account for terrain shadowing (diffraction over ridgelines), which would add additional loss for rugged terrain. (3) The comparison is qualitative in the sense that all surfaces yield the same hop count; the meaningful comparison is in the per-hop loss values (20.1 dB smooth vs 50.6 dB rugged vs 20.1 dB calm ocean vs 30.0 dB turbulent ocean).

## Subtask 3: Part III: A ship travelling across the ocean will use HF for communications and to receive weather and traffic reports. 

### Problem

Part III: A ship travelling across the ocean will use HF for communications and to receive weather and traffic reports. How does the model change to accommodate a shipboard receiver moving on a turbulent ocean? How long can the ship remain in communication using the same multi-hop path?

### Analysis

Assumptions: (1) The ship is the receiver, moving at v = 20 knots = 10.3 m/s over a turbulent ocean. (2) The transmitter is a fixed land-based station. (3) The 'same multi-hop path' means the ship remains on the geometric chain of n_max ionospheric hops defined in Part I (n_max = 1 hop, one ocean reflection at the midpoint). (4) As the ship moves away from the transmitter, the last hop length d_last = x − (n_max−1)·d1 grows; the path is geometrically valid only while d_last ≤ d1 = 1000 km (the ionospheric apex height stays within the F2-layer band of ~100–400 km; beyond d1 the apex height exceeds 15 km and the path breaks). (5) The ocean-reflection loss at the intermediate point is the same turbulent-ocean loss from Part I (30.0 dB); the receiver is at the end of the last hop (no ocean reflection at the receiver). (6) If the ship re-forms the hop chain at its new position (re-partitioned equal hops), the SNR drops below 10 dB within a few hundred km because the first hop's ocean-reflection loss (30 dB) plus the spread loss of a short first hop exceed the link budget.

### Modeling Process

Same-path duration: The ship enters the n_max = 1 hop path at x = 0 (the first hop is forming) and the path is valid while d_last = x ≤ d1 = 1000 km. The ship travels 1000 km at 20 knots = 10.3 m/s: duration = 1000·1000 m / 10.3 m/s = 97,087 s = 26.99 h ≈ 27 hours. The SNR on the same path remains ≥ 10 dB for the full 1000 km travel (the SNR at x = 1000 km is still 45.6 dB, the same as at x = 0, because the total path length is unchanged). Re-partitioned chain: If the ship re-forms the hop chain at its new position (equal hops, best number of ocean reflections), the SNR drops below 10 dB almost immediately (usable range ≈ 0 km beyond the initial position) because the first hop's ocean-reflection loss (30 dB) plus the spread loss of a short first hop (e.g., 500 km → 109.5 dB) plus the iono loss (0.6 dB) total 140.1 dB, leaving a SNR of 50 + 5 + 0 − 140.1 + 134.2 = 49.1 dB for n_refl = 1, but for n_refl ≥ 2 the additional ocean reflections (20.1 dB each) push the SNR below 10 dB. The re-partitioned usable range is therefore ~0 km (the ship must re-form the chain at the same position, not at a new position).

### Outcome Analysis

The ship can remain in communication on the same multi-hop path for approximately 27 hours (traveling 1000 km at 20 knots). This is the primary answer: the 'same multi-hop path' is geometrically valid for 1000 km of travel, and the SNR remains well above the 10 dB threshold throughout (45.6 dB at both the start and end of the travel). The secondary answer: if the ship re-forms the hop chain at its new position (re-partitioned equal hops), the communication duration is ~0 hours — the ship must re-form the chain at the same position, not at a new position, because the first hop's ocean-reflection loss (30 dB) plus the spread loss of a short first hop exceed the link budget for n_refl ≥ 2. The distinction is important: the 27 h answer addresses 'how long on the same multi-hop path' (geometric validity), while the ~0 h answer addresses 'how long if the ship re-forms the chain at a new position' (SNR budget). The model changes for a shipboard receiver in two ways: (1) the receiver is moving, so the last hop length changes with time (d_last = x − (n_max−1)·d1); (2) the receiver is on a turbulent ocean, so the ocean-reflection loss at the intermediate point is the turbulent value (30.0 dB), not the calm value (20.1 dB). The latter is already accounted for in Part I (the first hop's ocean reflection is turbulent). The former (moving receiver) is the new element: it changes the geometry of the last hop but not the total path length (for the same path), so the SNR is unchanged. Limitations: (1) The 27 h duration assumes the ionosphere remains stable (daytime, moderate solar activity); if the ionosphere degrades (e.g., nighttime, solar storm), the MUF drops and the path may break before the ship completes the 1000 km travel. (2) The model does not account for Doppler shift due to the ship's motion (negligible at 20 knots: f_D = v/λ = 10.3/30 = 0.34 Hz, far below the 3 kHz voice channel bandwidth). (3) The model does not account for shipboard antenna effects (e.g., reduced antenna efficiency at HF for a ship-size antenna); a practical shipboard HF antenna would add 3–10 dB of loss, reducing the margin but not changing the 27 h geometric-validity answer.
