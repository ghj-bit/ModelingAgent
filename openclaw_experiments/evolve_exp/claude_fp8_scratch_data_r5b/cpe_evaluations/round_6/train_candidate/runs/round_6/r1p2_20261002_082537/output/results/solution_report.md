## Subtask 1: Build a model that captures the flow of play as points occur in the Alcaraz-Djokovic Wimbledon 2023 final (match 2023-wi

### Problem

Build a model that captures the flow of play as points occur in the Alcaraz-Djokovic Wimbledon 2023 final (match 2023-wimbledon-1701) and at least one other match. The model must say, at any moment, which player is performing better and by how much, and produce a match-flow visualization based on the model. The serving advantage must be handled explicitly. Visualization: the per-point series is stored in results/flow_*.json (downsampled every 5th point) as the data for a line chart of M_t vs point number with zero-line crossings marking flow reversals; no image file is produced per submission rules.

### Analysis

The dataset is a per-point log for 31 featured Wimbledon 2023 men's matches (7284 points, no duplicates, serve alternation verified consistent in every match). Data cleaning: none of the structural fields were corrupted; the repairs were (i) numeric re-coding of the 15/30/40/AD score columns, (ii) re-sorting rows by elapsed_time within each match, and (iii) a decision about the incomplete fields. Serve speed is blank on 10.3% of points, return depth on 18%, and distance-run is zero on 0.43% of rows. An expert consultation (Exchange 1) established that these gaps are not missing at random but track the point type that produced them (short return exchanges, second serves, tracking dropouts); I verified this in the data: speed blanks are concentrated on 2-shot return points (19.3% blank) and second serves (15.9% vs 7.2%), so speed and distance are treated as informative indicators and are never imputed. The modeling approach: (a) fit a logistic 'base-rate' model of the point outcome conditional on the server, serve number, break-point state, and in-game progress; (b) define the match flow as a smoothed deviation of the actual results from that base rate. Conditioning on the server is what isolates 'performing better' from the mechanical serving advantage, exactly as the problem note requests. The smoothing memory is set at game scale (half-life 6 points), because Exchange 2 established that point-level runs revert to the base rate while genuine swings persist for 2-4 games; the half-life was tested against 3, 6, 10 and 20 points (see parameter table).

### Modeling Process

Variables: y_t = 1 if player 1 wins point t; s_t in {1,2} the server; r_t in {1,2} the serve number; B_t = 1 if the point is a break point; q_t = (points already played in the game)/12; T_t = 1 if in a tie-break game. Point model (logistic, MLE by gradient ascent on all 7284 points): logit P(server wins point t) = b0 + b1*I[s_t=1] + b2*I[r_t=2] + b3*B_t + b4*q_t + b5*T_t. Fitted coefficients: b0=1.037, b1=0.153, b2=-1.002, b3=0.043, b4=0.011, b5=0.057; in-sample AUC 0.626 (the residual is mostly player skill and state, which is exactly what the flow metric is meant to capture). The server's expected win share is p_t = P(server wins); player 1's expected point share is E1_t = p_t if s_t=1 else 1-p_t. Match-flow (momentum) score: M_t = ewma( y_t - E1_t ), M_t = a*(y_t-E1_t) + (1-a)*M_{t-1}, a = 1-exp(-ln2/6), half-life 6 points ~= one game. M_t > 0 means player 1 is currently outperforming his base rate; |M_t| is the magnitude. Parameter table (empirical inputs used by the model): (1) ewma_half_life = 6 points, interval tested [3,20]; source: sweep in this dataset (results/sweep_hl.json) — sign agreement of M_t with the winner of the next 10 points is 0.597 at half-life 3, 0.584 at 6, 0.573 at 10, 0.567 at 20, so the game-scale half-life is the most responsive setting and the choice is robust within a factor of 3; (2) turn_threshold = 2 straight games (break followed by hold), convincing case = 3 straight games; source: expert Exchange 3, calibrated against the data (P(next game won by same player | just broke serve) = 0.862 over 152 break games; 1188 games total); (3) all base rates (server wins 0.673 of points, 0.754 on first serve, 0.530 on second serve; break points converted by receiver in 32.1% of 504 break-point occurrences; overall break rate 15.9%) come from the supplied dataset itself. No external empirical values were needed; nothing was taken from memory.

### Outcome Analysis

Featured match (Alcaraz 2-3 Djokovic in sets, 334 points, 4h42m): per-set mean flow for Alcaraz is set 1 -0.095 (Djokovic's 6-1 demolition), set 2 -0.007 (even, decided by tie-break), set 3 +0.126 (Alcaraz's 6-1), set 4 -0.028 (even on average but with a -0.265 trough as Djokovic closed the set 6-3), set 5 +0.003 (even, decided 6-4). The flow chart (results/flow_2023-wimbledon-1701.json holds the full downsampled series for plotting) is a sign-alternating trace: the match swung lead four times, and each swing is visible as the trace crossing zero around the set points. The model reproduces the narrative of the match - big one-sided stretches in sets 1 and 3, tight seesaw elsewhere. Applied to other matches (e.g. Alcaraz-Jarry 1301: mean +0.023 with a +0.329 Alcaraz peak; Rublev match 1407: near-zero mean, both peaks around 0.25) the same trace behaves as expected: comfortable wins show a persistent offset, close 5-setters oscillate around zero. Limitations and bias: the score is a residual against a pooled base rate, so it measures deviation from a typical point, not absolute quality; it cannot see fatigue or tactical intent directly; and because speed/distance fields are missing-not-at-random, any extension that uses them must inherit the E1 caveat. The metric is symmetric in the sense that a negative value is just the other player's positive value, which is desirable for a 'who is better right now' gauge.

### Problem

Test the coach's claim that swings in play and runs of success are random. Use the model/metric to assess whether 'momentum' is a real phenomenon or just streakiness in independent outcomes.

### Analysis

The claim is testable as a null hypothesis: point outcomes are independent draws from the conditional base-rate model of Task 1 (i.e., once server, serve number, break-point and progress state are accounted for, no further memory exists). The correct null therefore keeps the state-dependent probabilities and shuffles only the outcomes within strata of (match, server), which preserves the base rates. Two observed statistics are compared against the null: (i) the maximum absolute value of the flow score M_t in the match, and (ii) the number of 4-point same-player streaks. Expert Exchange 2 supplied the scale at which to look: point-level runs are expected to revert (they are base-rate noise), while game-level runs are where a real effect would live; Exchange 3 supplied the action threshold (2+ straight games, not 2-3 points).

### Modeling Process

For each match m: compute S_obs = max_t |M_t| and K_obs = #{t: points t-L+1..t all won by the same player, L=4}. Generate 40 null realizations by permuting the point outcomes within each (match, server) stratum and recomputing S and K with the same expected values E1_t (which depend only on state, not on outcomes). One-sided p-values: p_S = (1/40) sum I[S_perm >= S_obs], p_K analogously. A complementary direct test at the game level: let G_i be the winner of game i within a set; the null of independence predicts P(G_{i+1} != G_i | streak) is constant. Measured over all 31 matches (1188 games): P(next game changes winner | prior streak 1) = 0.741, |streak>=2| = 0.681; and the structurally decisive numbers: after a break game, the breaker wins the next game in 86.2% of 152 cases, while after a hold the opponent wins the next game in 83.7% of 919 cases. A swing is therefore not a random event: it is strongly coupled to the break/hold structure.

### Outcome Analysis

Result 1 (point level - the coach is right): in the featured match S_obs = 0.309 with p_S = 0.775, and K_obs = 23 four-point streaks with p_K = 0.500; across all 31 matches, none reaches p_S < 0.10 and only 3 of 31 reach p_K < 0.10. Point-level 'runs' (3-5 points) are base-rate noise: the data gives P(same player continues a run | run length 1,2,3) = 0.541/0.559/0.567, dropping to 0.430/0.402 at runs of 4/5 - runs revert. Result 2 (game level - the coach is wrong): swings are a real, structured, game-scale phenomenon. The break->hold persistence (86.2%) is far above the 50% the independence null would assign to a second consecutive break, and single-game streaks dominate (median streak length 1, P(streak>=2)=0.18, P(streak>=3)=0.13). Verdict: 'momentum' as a point-streak is not detectable above randomness; 'momentum' as a game/set-scale shift tied to serving status (break, hold, changeover) is real and quantifiable. Limitations: 40 permutations per match make p-values coarse (resolution 1/40); the test uses the in-sample point model, so the null is slightly optimistic - a conservative reading strengthens the conclusion that no point-level effect survives; the game-level test does not condition on serve number, an omission that biases against finding persistence.

## Subtask 3: Develop a model that predicts when the flow of play is about to change from favoring one player to the other; identify t

### Problem

Develop a model that predicts when the flow of play is about to change from favoring one player to the other; identify the most related factors; advise a player going into a new match against a different player; test the model on other matches and assess how well it predicts swings; note factors for future models and how generalizable the model is (women's matches, other tournaments, other surfaces, other sports such as table tennis).

### Analysis

The operational definition of 'a flow change' follows from Exchange 3 and the verified data structure: the flow changes when the game-level winner changes away from the current streak, and the coach-recognized unit of a genuine turn is a break of serve followed by a hold (2 straight games). The prediction task is posed at the game level: at the end of game i, given the observable state, predict whether game i+1 is won by the other player (a swing). This is the only scale at which Task 2 found real signal, so a point-level predictor would be chasing noise. Candidate factors, all observable live: who is serving the current game, whether it is a set point (5-x), the current streak length of consecutive games won by the same player, whether the previous game was a break, and elapsed match time (fatigue). The design uses a holdout: the model is fitted on the 30 non-featured matches (1030 games) and tested on the Alcaraz-Djokovic final (41 games), plus the pooled persistence table as a robustness check.

### Modeling Process

Game-level logistic regression. State at end of game i (all known before game i+1): X = (I[server of game i = p1], I[set point in game i: p1_games>=5 or p2_games>=5], streak_i, I[game i-1 was a break], minutes elapsed). Target: Y = I[game i+1 winner != game i winner]. Coefficients by gradient-descent MLE on standardized features (standardization fit on train only); 2000 iterations, lr 0.01. Train AUC 0.60, test AUC on the held-out final 0.579, accuracy at threshold 0.5 = 0.634 against a base rate of 0.634 - i.e., the classifier is at chance in absolute terms, and the honest statement is that the features carry weak but nonzero signal (AUC ~0.58). The informative part is the conditional table the same data produces without any fitting: P(swing | just broke serve) = 0.138, P(swing | just held) = 0.837, P(swing | streak>=2) = 0.681 vs 0.741 | streak 1. Those conditionals ARE the practical prediction rule: after your player breaks, expect the flow to keep going their way (~86%); after they hold while the opponent is hot, the opponent's serve game is where the flow most often flips back (84%).

### Outcome Analysis

Most related factors: (1) the break/hold state of the immediately preceding game - by far the strongest, and it is structural (serving advantage) rather than 'mystical momentum'; (2) whether the match is at set point, which slightly concentrates intensity; (3) streak length, a weak persistence effect (0.74->0.68). Elapsed time shows no usable signal in this dataset, consistent with expert Exchange 2 (swings reset at changeovers/breaks rather than accumulating with fatigue over 4+ hours, at least in featured matches where players rotate to fresh courts). Advice to a player facing a different opponent: (a) treat your break as a 2-game possession - win the hold, because 86% of the time the turn belongs to you; (b) if the opponent breaks on your serve, do not expect an immediate bounce-back - the statistically correct response is to defend out and reset at the next changeover, not to swing for the fence; (c) ignore point streaks of 2-5 points entirely (they are base rate, p~0.5 in the permutation test) and react only to the game-level events. Testing on other matches: the holdout design above tests on the final; the pooled table (which pools all 31 matches) shows the same conditional structure, so the rule generalizes across the featured set. Factors missing from this model that future versions should add: first-serve percentage and second-serve aggression per game (Exchange 2 names these as what coaches actually watch; the dataset has serve_no but not first-serve-in rate per game, which can be reconstructed), aces and unforced errors per game, body-language/proxy measures, court surface and tournament context, and player-specific priors (the dataset is all Wimbledon 2023 men's, so it cannot identify surface or sex effects). Generalizability: the structural rule (break->hold persistence, point-streak noise) depends only on the tennis scoring structure and the serving advantage, both of which exist in women's matches, other tournaments, and other surfaces, so the qualitative advice should transfer; the quantitative 86%/84% figures are Wimbledon-2023 men's estimates and would need recalibration. For other sports: table tennis has a serving advantage but far shorter units (2 points per game) and 11-point games, so the game-scale threshold must be rescaled to the sport's unit of momentum; the two-level design (base-rate model at the small unit, flow at the larger unit, randomness test at both) transfers directly.
