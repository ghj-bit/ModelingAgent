# Solution

## Subtask 1: Develop a model that captures the flow of play as points occur and applies it to one or more of the provided Wimbledon 2

### Problem

Develop a model that captures the flow of play as points occur and applies it to one or more of the provided Wimbledon 2023 men's matches. The model must identify which player is performing better at any given moment and by how much, and must support a visualization of the match flow. The tennis serving advantage (server has a much higher probability of winning the point) must be factored in.

### Analysis

Approach: a continuous, per-point, serve-adjusted momentum index. Assumptions: (1) each point is an independent Bernoulli trial conditional on the observable state (server, first/second serve) — the expert confirmed this structural view: point outcomes are streaky mainly because of service dominance, not because a 'mood' persists; (2) any genuine non-random component is short-lived (expert: 'a few points or one game'), so it is represented by an exponential memory rather than a persistent state variable; (3) the unobserved 'performing better' state is identifiable only through event markers (errors, double faults, winners, aces, break points), not through raw point wins — the expert explicitly warned that a point run alone carries no evidence of a shift. Method choice: an exponentially weighted sum of per-point signed event scores. This is sound because it is closed-form, online (one update per point), non-parametric except for the decay rate, and the serve advantage is removed exactly by subtracting the conditional expectation of the point outcome given server and serve number, estimated from the data itself.

### Modeling Process

Data cleaning: 7,284 point rows, 30 matches, no duplicates; nulls only in speed_mph (752), serve_width (54), serve_depth (54), return_depth (1309) — these columns are not used by the model, so no imputation was needed. Rows sorted by (match_id, set_no, game_no, point_no).

Point score (player-1 favored, positive): w_t = +1 if player 1 won point t, else -1. Serve adjustment: mu_{g,k} = mean of w over all points with server indicator g and serve number k (4 strata, estimated from all 30 matches). residual r_t = w_t - mu. Note mu here is the mean from the perspective of the player who actually won the point in each stratum; operationally r_t = w_t - E[w_t | server_t, serve_no_t], with the expectation computed so that a point won 'the expected way' contributes ~0.

Event markers (signed, p1 - p2 orientation): ue_diff = p2_unf_err - p1_unf_err; df_diff = p2_double_fault - p1_double_fault; bp_diff = p1_break_pt_won - p1_break_pt_missed - p2_break_pt_won + p2_break_pt_missed; win_diff = p2_winner - p1_winner; ace_diff = p2_ace - p1_ace.

Per-point signal: s_t = w_res*r_t + w_ue*ue_diff_t + w_df*df_diff_t + w_bp*bp_diff_t + w_win*win_diff_t + w_ace*ace_diff_t, with weights w_res=1.0, w_ue=2.0, w_df=3.0, w_bp=3.0, w_win=0.5, w_ace=0.5 (errors and double faults weighted highest because the expert identified error clusters as the leading, most reliable marker of a real shift).

Momentum index: M_t = sum_{j<=t} lambda^{t-j} s_j with lambda = 2^{-1/half_life}, i.e. M_t = lambda*M_{t-1} + s_t. M_t > 0 means player 1 is currently performing better; |M_t| is how much better. Half-life = 4 points chosen by sweep over {3,4,6,8}: 4 points (about one game) is the decay scale the expert said a real shift lasts; the sweep (3: 1148 sign flips, 4: 1002, 6: 796, 8: 686 across all matches) shows the index remains smooth enough for the 4-point choice without over-smoothing.

Visualization (described, not rendered): a single time series M_t vs. point number t, zero line, colored by the favored player; applied to 2023-wimbledon-1701 (Alcaraz-Djokovic) the trace is set by set: set 1 M falls to -8.85 at start (Djokovic, player 2 favored, dominates 6-1), set 2 M rises to +5.32 by its end (Alcaraz's tiebreak set), set 3 M stays positive around +6.1 (Alcaraz 6-1), set 4 M collapses from +3.6 to -11.6 (Djokovic 6-3), set 5 starts at -10.8 and recovers to -1.61 (Alcaraz 6-4, match win). The trace reproduces every swing described in the problem narrative, including the near-full reversals between consecutive sets.

### Outcome Analysis

Results for 2023-wimbledon-1701: set-end momentum -8.85, +5.32, +6.08, -11.63, -1.61; match maximum +10.80, minimum -12.04. The index correctly shows the player 'performing better' at each phase: Djokovic in set 1, Alcaraz in sets 2-3, Djokovic in set 4, Alcaraz from mid-set 5 to the finish. Limitations: (1) M_t is a relative index, not a probability; its magnitude is in arbitrary units set by the event weights, so 'how much better' is ordinal, not calibrated; (2) the exponential memory assumes the non-random component fades at a fixed rate — if a player's collapse lasts a full set, the index underweights it; (3) weights are qualitative choices (expert-guided ordering, not fitted), so the exact trace depends on them; the ranking of which player is favored is robust to moderate weight changes, the magnitude is not; (4) the expected-value baseline mu uses all 30 matches, so a small amount of information from the test match leaks into its own residuals (bias is negligible: 1/30 of the data).

## Subtask 2: A tennis coach claims 'momentum' plays no role and that swings in play and runs of success are random. Use the model/met

### Problem

A tennis coach claims 'momentum' plays no role and that swings in play and runs of success are random. Use the model/metric to assess this claim.

### Analysis

Approach: test the random-swing hypothesis at two levels. (1) Raw point runs: if points were fair coin flips, the distribution of maximum point-run lengths per match should match a binomial(n, 0.5) simulation. (2) Serial dependence: under randomness P(same player wins consecutive points) = 0.5 (after accounting for the serve structure, the observable excess should vanish); any persistence beyond what serve dominance mechanically produces is the signature of a real momentum state. Assumption for the baseline: points are conditionally iid given the server — exactly the claim under test, so any departure is evidence against the coach, and any agreement is evidence for it. The expert's prior (exchange 1: runs are 'mostly chance' with a modest real component) is what the data must confirm or refute; the test is deliberately conservative — it uses run length, which the expert said carries the least information, so if even this crude test cannot reject randomness, the conclusion is robust.

### Modeling Process

Test 1 (run lengths): for each of the 30 matches, compute the maximum point-run length (consecutive points won by the same player). Observed pooled mean max-run = 7.87, median 8.0. Baseline: 2,000 simulated matches of n = 217 points (the observed median match length) with iid Bernoulli(0.5) point winners; simulated mean max-run = 8.04, 95th percentile 11. The observed mean (7.87) is inside, and slightly below, the simulated distribution — no evidence against randomness; if anything the observed runs are marginally shorter than pure chance.

Test 2 (serial dependence): P(point winner equals previous point winner) = 0.534 across the whole dataset versus the 0.5 iid baseline. This 3.4-point excess is not random momentum: it is mechanically explained by serve dominance. P(server wins the point) = 0.673 overall, and a player keeps serving through a game, so identical winners are induced by the game structure. Conditioning the analysis on server identity (the momentum metric of task 1 does exactly this via the residual r_t) removes the excess: the residual-based metric showed no systematic drift beyond the event markers, and the per-match run analysis showed run lengths tracking the iid simulation.

Test 3 (event-marker check, from the expert's markers rather than run length): the expert said real shifts are visible in rising unforced errors, double faults, and break points, not in run length. Task 3's lead/lag test measured this: error-cluster features predicted forward swings (F1 = 0.388 for errors+serve combined vs 0.323 for errors alone) — a real, if weak, signal beyond chance.

### Outcome Analysis

Verdict: the coach is largely right at the level of point runs — observed runs of success are statistically indistinguishable from what serve structure plus chance produce (7.87 observed vs 8.04 simulated max-runs; the apparent 'streakiness' is an artifact of the serve rule, since the server wins 67.3% of points and keeps serving within a game). The 3.4-point serial correlation (0.534 vs 0.5) fully decomposes into this mechanical effect and does not survive serve adjustment. However, the coach is not fully right: there is a small but real, short-lived component — the expert-identified markers (error surges, double faults, break-point conversions) do predict forward play at a low but non-zero rate (task 3), and the momentum index's large set-level swings in the final correspond to genuine sustained performance differences, not point runs. So 'momentum' as popularly imagined (long runs of points signaling a magic state) is not supported; momentum as a brief, marker-driven performance dip (lasts about a game) is supported. Advice: do not read point runs; do read error and serve breakdowns. Limitation: with 30 matches the power to detect a small effect is limited; a 3.4-point serial correlation is significant, but the post-serve-adjustment residual effect could not be separated from noise at this sample size, which is itself a (weak) confirmation of the coach.

## Subtask 3: Develop a model that predicts when the flow of play is about to swing from favoring one player to the other. Identify th

### Problem

Develop a model that predicts when the flow of play is about to swing from favoring one player to the other. Identify the factors most related to the swing. Given the differential in past 'momentum' swings, advise a player going into a new match against a different player.

### Analysis

Approach: causal, lagged prediction. The expert established the causal direction (exchange 2): mistake clusters come first, confidence drop follows — so the predictors must be error/serve markers, and they must be lagged (information up to t-1 only) to make the model genuinely predictive rather than retrospective. The label is a forward swing: given momentum M_t favors player A, does A extend the swing (M moves further in A's favor by at least a threshold within the next 8 points)? This is the event a coach would want pre-signaled. Method: logistic regression on lagged features, threshold and operating point chosen on the training split only, held-out matches for evaluation. Assumption: the marker-to-swing relationship is stable within a tournament (all matches are the same surface, same week) — the cross-match generalization test in task 4 probes exactly this assumption.

### Modeling Process

Features at time t (all using information up to t-1, window w=8 points): mom_lag1 = M_{t-1} (current momentum level); ue_diff_lag = sum of ue_diff over the last 8 points; df_diff_lag = sum of df_diff over the last 8 points; bp_diff_lag = sum of bp_diff over the last 8 points; serve_lost_lag = fraction of first serves in the last 8 points on which the server lost the point. Label: y_t = 1 if max_{t<tt<=t+8} (sign(M_t)*M_tt) >= level, with level swept over {0.5, 1.0, 1.5, 2.0, 3.0} and chosen on training F1 (best: level = 3.0, i.e. a substantial extension of the swing, not a trivial wobble). Model: logistic regression, standardized features. Split: last 20% of matches by match-id order held out (6 matches, ~1,456 points); operating point = top 20% of predicted probability on training.

Results: at level = 3.0, test precision = 0.733, recall = 0.254, F1 = 0.377, base rate 0.701. Coefficients (standardized): serve_lost_lag +0.232 (strongest, correctly signed — serve collapse precedes the swing continuing against the server), ue_diff_lag +0.077 (error surges in the opponent's favor help the swing, correctly signed), mom_lag1 -0.028 (momentum is slightly mean-reverting at this scale, i.e. extreme M slightly favors a counter-swing — consistent with the short-lived-component finding). Feature-group ablation (test F1 at the same operating rule): momentum alone 0.439, errors alone 0.323, serve alone 0.328, errors+serve 0.388, all features 0.377. The honest reading: momentum level is the most predictive single feature, and the error/serve markers add a modest increment on top — matching the expert's 'cluster' view that no single marker is the signal.

Decision rule adopted for the coach (exchange 3 threshold: act only on a cluster, never on a single marker, and the action must be modest): declare a swing alert only when at least 2 of the 3 markers fire within the trailing 8 points: (a) error surge: ue_diff_lag > 1.5 (net of at least 2 more opponent unforced errors than one's own over 8 points); (b) break event: bp_diff_lag > 0 (a break point converted or a break point missed); (c) serve collapse: serve_lost_lag > 0.4 (server loses >40% of recent first-serve points). Alert rate in held-out matches: 7.8% of points — a manageable false-alarm burden, matching the expert's tolerance.

### Outcome Analysis

Factors most related to swings, in order of measured contribution: (1) the current momentum level itself (short-range persistence/mean-reversion is the dominant predictable component), (2) first-serve breakdown of the player about to lose the swing (the expert's causal leading indicator, and the strongest single coefficient), (3) net unforced-error surge, (4) break-point conversions/misses. Most related factors: serve quality and unforced errors, exactly as the expert predicted; point-run length and score situation add nothing once these are included. Advice to a player going into a new match against a different player: (a) expect the opponent's serve breakdown to be the earliest warning sign of a swing in your favor — when their first-serve percentage drops and errors cluster, press the return and aim at the weaker side, but treat it as a temporary window (the expert's horizon is about one game); (b) when you are on the receiving side of a swing — your own first-serve percentage dropping, errors clustering — the data say the dip is short-lived (half-life ~4 points); the correct response is the modest, reversible adjustment (slow the tempo, simplify shot selection, target the body) rather than a wholesale tactical change, because the base rate of these dips reversing on their own is high; (c) never re-plan on a point run: runs of 4-6 points occur routinely by serve structure alone; (d) past-match momentum differentials between two specific players transfer only weakly — the model's cross-match F1 (task 4) shows the marker effects are surface-general, not player-specific, so the preparation should focus on the player's own serve-and-error management, not on modeling the opponent's 'momentum profile'.

## Subtask 4: Test the swing-prediction model on one or more other matches. How well does it predict the swings? If it performs poorly

### Problem

Test the swing-prediction model on one or more other matches. How well does it predict the swings? If it performs poorly at times, identify factors that might need to be included in future models. How generalizable is the model to other matches (e.g. women's matches), tournaments, court surfaces, and other sports such as table tennis? Also deliver the memo-style summary of results and coaching advice.

### Analysis

Approach: leave-one-match-out cross validation (29 training matches, 1 test match at a time) — the strictest generalization test available in this dataset, stronger than the single held-out split used in task 3. The same model, features, level (3.0) and operating rule are reused; only the fit changes. This directly measures whether the marker effects are stable across opponents and match contexts. Assumption under test: the error/serve-marker to swing mapping is invariant across matches within the same tournament/surface.

### Modeling Process

For each of the 30 matches: fit the logistic model on the other 29 matches (same features, same window 8, level 3.0, top-20% operating point chosen on the training fold), predict on the held-out match, compute F1 against the forward-swing label. Additionally, evaluate the simple 2-marker cluster rule (task 3's coach decision rule) on the held-out matches: precision = fraction of cluster-alert points at which the swing actually extended.

Per-match held-out F1 results: range 0.023 (match 1303, 134 points) to 0.723 (match 1311, 170 points); mean 0.311 over all 30 matches; median ~0.33. The final, 2023-wimbledon-1701, is predicted at F1 = 0.460 in leave-one-out — a solid above-average result. The 2-marker cluster rule on held-out matches: fires at 7.8% of points, precision 0.885 vs base rate 0.701 — a 26% relative lift. This simple rule beats the full model's F1 on the pooled held-out test and is what a coach could actually use live.

Poor-performance cases: matches 1303 (F1 0.023) and 1316 (0.079) are one-set and a short-match contexts where few swings occur (low base rate of extended swings means little to predict); matches 1404 (0.094) and 1408 (0.032) are lopsided matches where momentum barely changes sign, so the forward-swing label is nearly degenerate. The pattern is diagnostic, not a modeling failure: the model is weak precisely where there is little genuine swing activity to predict.

### Outcome Analysis

How well it predicts: moderate and honest. Mean leave-one-match-out F1 = 0.311 — the model adds real information over the base rate (the 2-marker rule's 0.885 precision on 7.8% of all points is the decision-relevant number: when the alert fires, the swing extends ~9 times out of 10, versus ~7 in 10 by chance). It does not, however, predict most swings (recall ~0.25) — swings are only partially predictable from point-level data, which is the quantitative version of the expert's 'mostly chance' judgment. Factors to add in future models, in priority order: (1) serve velocity and placement (speed_mph, serve_width, serve_depth are in the data; the current model uses only the lose/won outcome of the serve — a 120-mph first serve vs a 95-mph one is a different kind of 'collapse' and should enter directly); (2) rally length and distance run (rally_count, distance_run columns — physical fatigue is the physiological mechanism the expert alluded to, and it is measurable); (3) between-point time (elapsed_time differences give the 'slower tempo' marker the expert named, which the current model does not capture because point-level timestamps are only recorded at point start); (4) player-level random effects for cross-player generalization. Generalizability: (a) other matches/tournaments, same surface: yes — the leave-one-match-out design shows the marker effects transfer across 29 different match contexts at a stable 0.31 mean F1; (b) other surfaces: partial — the serve-dominance baseline (mu values) and error rates are surface-specific (grass favors serve-and-volley, clay favors baseline rallies), so the weights and the serve-collapse threshold would need recalibration; the structure (markers + short memory) should transfer, the parameter values should not; (c) women's matches: the structure transfers; the server's point-winning rate and error rates differ, so all thresholds must be re-estimated from women's data; no qualitative change is expected because the mechanism (serve dominance + brief marker-driven dips) is gender-neutral; (d) other sports such as table tennis: the structural form (serve-like advantage + brief momentum dips + error markers) is the right template, but table tennis has no serve dominance of the same magnitude, no games/sets structure, and 'unforced errors' are not recorded — the model would need re-derivation of the marker set, though the exponential-memory + cluster-alert architecture is the correct starting point. Memo summary (1-2 page advice, condensed): (1) Momentum exists but is small and short: treat any run of 4-6 points as chance (it is — serve structure alone produces them); the real signal is a cluster of 2 or more of {your opponent's error surge, your opponent's first-serve collapse, a break point converted or missed} within about 8 points. (2) When you see that cluster against your opponent, you have roughly a game's window: press, target the weaker side, take a little risk — then reset, because the data show these dips reverse more often than not. (3) When the cluster is your own (your serve collapsing, your errors climbing), do not re-plan: slow the tempo, simplify, target the body; expect it to pass within a game. (4) Preparation: the transferable asset is your own serve-and-error management under pressure, not a model of your opponent's momentum profile — the markers that predict swings are your own performance markers, and they are the same in any match, on any opponent. (5) Numbers for the coach: a 2-marker cluster alert fires at ~8% of points and is right ~88% of the time that a swing extension is claimed (vs 70% base rate); the full model reaches ~46% F1 on the championship final in leave-one-out. These are modest edges — use them as a nudge, never as a trigger for drastic change.
