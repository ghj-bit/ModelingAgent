# Solution

## Subtask 1: Develop an optimal 5-year investment strategy for the Goodgrant Foundation's $100,000,000-per-year (2016-2020) donation:

### Problem

Develop an optimal 5-year investment strategy for the Goodgrant Foundation's $100,000,000-per-year (2016-2020) donation: an optimized and prioritized candidate list of US post-secondary schools, the per-school investment amount, an estimated return on investment (ROI) appropriate for a charitable organization, and the time duration the money should be provided to maximize the likelihood of a strong positive effect on student performance. Deliverable: a ranked 1-to-N school list with per-school award, ROI, and a recommended ROI concept for future philanthropic assessment. Scope: based on the IPEDS candidate list (~3,000 schools) and College Scorecard 'Most Recent Cohorts' performance data, restricted to a meaningful, defensible subset of those two data sets.

### Analysis

ASSUMPTIONS. (A1) Per expert exchange 1, the $100M/year figure is an annual outflow, so the program's total commitment is F = 5 x $100M = $500,000,000, and each school's award is a multi-year commitment paid in installments over the 5-year horizon (not a one-time transfer). (A2) Per expert exchange 2, raw outcome rates (graduation, earnings, repayment) are dominated by the quality of the students a school admits; the signal of 'effective use of private funding' is value added - performance above what the school's own intake profile predicts - not the raw rate. (A3) Per expert exchange 3, ROI is a relative, rank-based quantity (value added per dollar committed, compared against the marginal funded school); no arbitrary absolute earnings threshold is imposed. (A4) A grant reaches the full-time enrollment stream of a school over the 5-year window, so students affected is proxied by undergraduate headcount UGDS. (A5) Eligibility: a school is fundable only if it has a positive, statistically-identified value-added estimate and non-missing enrollment. METHOD. (1) Data cleaning: coerce the mixed string/numeric Scorecard columns to numeric, deduplicate on UNITID, inner-join the Scorecard performance table to the 2,977-school IPEDS candidate list on UNITID, giving 2,936 candidate-school rows with performance data; repair the mixed-type object columns (e.g. C150_4_POOLED_SUPP, md_earn_wne_p10, gt_25k_p6, RPY_3YR_RT_SUPP, GRAD_DEBT_MDN10YR_SUPP) that stored numbers as strings. (2) A value-added regression model: for each outcome, regress it on intake proxies (PCTPELL socioeconomic mix, SAT_AVG selectivity, PCIP10 business-major share) and use the residual as the school-specific value added, which is the defensible criterion for 'demonstrated potential for effective use of private funding.' (3) Standardize the residuals to z-scores and combine an earnings value-added score (primary ROI signal) with a completion value-added score. (4) A rank-driven budget allocation (marginal value-added-per-dollar knapsack): sort fundable schools by value-added and commit awards top-to-bottom until the $500M commitment is exhausted, with per-school awards scaled to student reach and bounded within a defensible grant band.

### Modeling Process

CLEANING. Let S be the Scorecard table (7,804 rows x 122 cols) and C the IPEDS candidate list (2,977 rows). For each outcome column v in V = {C150_4_POOLED_SUPP, C200_L4_POOLED_SUPP, md_earn_wne_p10, gt_25k_p6, RPY_3YR_RT_SUPP, GRAD_DEBT_MDN10YR_SUPP, UGDS, PCTPELL, SAT_AVG, PCIP10} and each PCIP field, set S[v] := to_numeric(S[v]). Merge M := S ⋈ C on UNITID (inner), M has 2,936 rows. Define the applicable completion rate COMPLET := C150_4 if present else C200_L4. VALUE-ADDED MODEL. For outcome y_i and intake vector x_i = (PCTPELL_i, SAT_AVG_i, PCIP10_i), fit OLS  y_i = β0 + β1 PCTPELL_i + β2 SAT_AVG_i + β3 PCIP10_i + ε_i  over the common non-missing support (OLS via lstsq, n>=30). The residual r_i := y_i - x_i'β̂ is the school's value added. Earnings outcome: y = ln(md_earn_wne_p10) (log for normality); intake-model R^2 = 0.447, so ~55% of earnings variation is intake-explainable and the residual is the funding signal. Completion outcome: y = COMPLET; intake-model R^2 = 0.715. Standardize: z_earn := (r_earn - mean)/sd, z_comp := (r_comp - mean)/sd. Combine per school (renormalizing weights when a component is missing): VA_i := (0.6 w_e z_earn,i + 0.4 w_c z_comp,i)/(0.6 w_e + 0.4 w_c), with w_e=1{z_earn present}, w_c=1{z_comp present}. Schools with no identified value added get VA := NaN and are ineligible. ALLOCATION. Let A_i be the committed award to school i. Constraints: A_i in [A_min, A_max] = [$1M, $10M]; sum_i A_i <= F = $500,000,000; eligibility E := {i : VA_i > 0 and UGDS_i > 0}. Rank E in descending VA. Set A_i := clamp((UGDS_i / max_j UGDS_j) x A_max, A_min, A_max), fund in rank order, dropping the lowest-VA schools until sum A_i <= F. The funded set is the retained prefix (N=290 schools, sum A_i = $499.91M, 100.0% of budget). ROI (charitable, relative, per expert exchange 3): define the value of one additional graduate at lifetime earnings premium P, and the ROI to school i as  ROI_i := (VA_i x P x UGDS_i) / A_i  = student-$ of value added per $1M of foundation commitment. Portfolio ROI := sum_i (VA_i x P x UGDS_i) / sum_i A_i. PARAMETER TABLE (empirical inputs; every reported number is either here or from the task dataset): P = 25000 $/yr per additional graduate, interval [15000, 40000], source: Mincer-style degree-premium literature - Card (2001) returns to schooling / Carneiro-Hastings-Naylor and the NBER Mincer-equation synthesis, doi:10.3386/w11544 and doi:10.1007/s13524-015-0407-0 ('Education and Lifetime Earnings in the United States'). F = 500000000 $ total commitment, interval [500000000,500000000], source: expert exchange 1 (the $100M is the annual outflow over 5 years). A_min = 1000000 $, A_max = 10000000 $, interval [1e6,1e7], source: defensible per-school grant band (planning-level assumption; not derived from the dataset). w_earn = 0.6, w_comp = 0.4, interval [0.5,0.7]/[0.3,0.5], source: relative emphasis on earnings as the primary charitable ROI signal. UGDS, PCTPELL, SAT_AVG, PCIP10, md_earn_wne_p10, C150_4_POOLED_SUPP, C200_L4_POOLED_SUPP: task-provided Scorecard/IPEDS dataset. n_common >= 30 for OLS identification: identification threshold (not an empirical parameter).

### Outcome Analysis

RESULTS. 290 schools are funded, committing $499,910,000 (100.0% of the $500M five-year commitment). Awards range from the $1M floor to a $10M ceiling (mean $1.72M); 290 schools span 40+ states, concentrated in PA (58), CA (48), NY (33), NJ (22), MA (20). The funded set's value-added (z) ranges from a marginal 0.596 to 4.326. The top of the ranked list is dominated by small-to-mid career and health-science colleges that out-perform their intake profiles: Charles R. Drew University of Medicine (CA, VA=4.33), MCPHS University (MA, 4.14), Maine Maritime Academy (ME, 3.04), Albany College of Pharmacy and Health Sciences (NY, 3.02), Albertus Magnus College (CT, 2.94). University of California-Irvine appears higher in the list (VA=2.17) and receives a larger $5.35M award because of its large enrollment (23,517 students), which scales the commitment. PORTFOLIO ROI. Using P = $25,000/yr per additional graduate, the estimated portfolio value added is ~$5.0e10 in student lifetime earnings, a portfolio ROI of ~100x (student-$ of value added per $1 of foundation commitment) - i.e., the philanthropic spend buys large per-student gains, consistent with the charitable (not dollar-repaying) framing of exchange 3. LIMITATIONS AND BIASES. (1) Value added is a regression residual from a linear OLS model on three intake proxies; SAT_AVG covers only 47% of schools (the rest fall back on PCTPELL and PCIP10), so the earnings-residual identification pool is 1,358 schools and the completion pool 1,375 - schools with thin intake data are under-identified and conservatively excluded rather than given a spurious score. (2) UGDS is a headcount proxy for 'students affected'; it over-counts at schools where a grant cannot realistically move all students and ignores cohort churn, so the ROI is an upper-bound planning estimate, not a causal effect of the grant itself (the data is cross-sectional, pre-donation, so the model ranks schools' demonstrated value added, not the grant's own treatment effect). (3) The award band and the 60/40 earnings/completion weighting are planning-level judgments; the ROI scales linearly in P, so the ranking is robust but the dollar ROI is not. (4) Suppressed small-n Scorecard values are treated as missing, biasing the fundable set slightly toward larger, well-reported institutions. CONCLUSION. The recommended strategy is a 290-school, $500M five-year commitment ranked by demonstrated value added, with per-school awards scaled to student reach and a relative charitable ROI defined as value added per dollar committed. The ROI concept Goodgrant should adopt is this rank-based value-added-per-dollar metric, not an absolute earnings threshold.
