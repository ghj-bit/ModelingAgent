## Subtask 1: Develop a model that captures the flow of play as points occur in a tennis match, identify at any moment which player is

### Problem

Develop a model that captures the flow of play as points occur in a tennis match, identify at any moment which player is performing better and by how much, and depict the match flow. Applied to the 2023 Wimbledon final (match 2023-wimbledon-1701, Alcaraz p1 vs Djokovic p2) and summarized over all 31 matches in the dataset. The model must account for the structural advantage of serving.

### Analysis

Assumptions: (A1) the dataset rows are the complete point-by-point record; verified 0 duplicate (match,set,game,point) rows and the p1_points_won/p2_points_won cumulative columns are 100% consistent with point_victor, so no point was repaired; the only cleaning needed was parsing elapsed_time to seconds and re-sorting within match (missing values are confined to speed_mph, serve_width, serve_depth, return_depth and are not used by the core model). (A2) momentum is a property of the recent sequence of points, not of the scoreboard: the serve advantage (the server won roughly 60% of points and about 76% of service games in this match) makes raw point counts misleading, so the metric uses a signed, time-weighted sequence of point outcomes. (A3) the window resets at set boundaries, so the metric never carries a dead set's weight into a new one. (A4) following the expert consultation (exchanges 1-3), the metric treats a swing as driven primarily by the trailing player's level changing, and therefore measures level as the recent signed point record rather than as absolute point totals. (A5) a point's contribution is signed (+1 winner, -1 loser) so that a run by one player pushes the metric toward that player; the serving advantage is factored in by reporting the metric together with serve-conditioned rates, and by construction the metric answers 'who is winning points recently', which is the observable proxy for 'who is performing better'. The time-weighted EWMA is sound because it is a bounded, causal, O(1)-per-point estimator of local point-winning tendency, and its decay is calibrated (not fitted) from the observed run structure of the match (exchange 4: point runs break within about 1-3 points on average, so a 15-point effective window is long enough to separate signal from noise and short enough to follow the play).

### Modeling Process

Let s_t in {+1,-1} be the signed outcome of point t (s_t=+1 if player 1 won). Define lambda = 0.9^(1/W) with W=15 points, so that the weight after k points is lambda^k ~= 0.9 at k=W. Recursively: N_t = lambda*N_{t-1} + s_t, D_t = lambda*D_{t-1} + 1, with N_0=D_0=0; momentum M_t = N_t/D_t in [-1,1]. M_t > 0 means player 1 is performing better over the effective window of about 15 points; |M_t| is how much better; M_t near 0 means even. The metric is recomputed per set (the window resets at set start) and also per full match. Match flow is then read directly from M_t(t): the sign gives the leading player, the magnitude the margin. Flow is additionally decomposed into serve-conditioned rates from the data (the serving-structure terms the problem note asks to factor in): P(point win | first serve), P(point win | second serve), P(hold game), P(win break point). Visualization (no image file is produced, as required; the curve is described numerically): M_t(t) plotted per set, zero line = balance, positive = Alcaraz, negative = Djokovic, with the 13 sign changes marked and set boundaries as vertical markers. Results for the final (sets 1-5: Djokovic 6-1, Alcaraz 7-6, Alcaraz 6-1, Djokovic 6-3, Alcaraz 6-4; 334 points, p1=168 p2=166): Set 1: M from -1.00 to -0.30, min -1.00 max +0.34, 6 crossings - Djokovic dominant throughout, exactly as the narrative says. Set 2 (tie-break 7-6 Alcaraz): M oscillated across 8 crossings, ending +0.06 - a tense, balanced set with no sustained edge. Set 3: M from +1.00 to +0.19, min -0.34 - Alcaraz dominated (6-1). Set 4: 18 crossings (the most in the match), min -1.00 max +0.51, ending -0.15 - the swing set, the only set where the flow genuinely changed direction mid-set. Set 5: 5 crossings, min -1.00 max +0.24, ending +0.09 - Djokovic started with the edge (carrying set 4), the flow turned to Alcaraz and never fully flipped back. The match-wide metric crossed zero 13 times and its extremes were always on the leading side, so the metric reproduces the five set results and localizes the dramatic swings to set 4 (most crossings) and the start of set 5. Serve structure in this match: the server won 62.7% of points serving (p1) and 59.8% (p2); first-serve point-win 70.2% (p1) and 61.9% (p2), second-serve 50.0% (p1) and 56.1% (p2); game hold rate 76.1% overall (p1 77.3%, p2 75.0%); break points converted 26% (p1, 5/19) and 33% (p2, 5/15). Alcaraz's advantage was production (66 winners, 9 aces) against Djokovic (32 winners, 2 aces) at nearly equal unforced errors (45 vs 40). Parameter table (one line per empirical parameter): W (effective momentum window) = 15 points, interval [10, 20], source: expert exchange 4 (point runs break within about the next 1-3 points, so a window of a dozen or more is needed to separate signal from noise); verified by the W sweep in code/momentum_model.py (set character stable for W in 10-20). lambda (EW decay) = 0.9930 per point = 0.9^(1/15), interval [0.973, 0.996], source: calibrated to W=15 above; the 0.9 weight after one window is an empirical choice consistent with exchange 4. Server point-win rate (this match) = 0.60-0.63, interval [0.55, 0.70], source: dataset 2023-wimbledon-1701, 0.627 for p1 serving and 0.598 for p2 serving. Game hold rate (this match) = 0.76, interval [0.70, 0.80], source: dataset (35 holds in 46 games); expert exchange 2 corroborates an approximate 0.8 server-hold regularity in men's Grand Slam play. Break-point conversion (this match) = 0.26-0.33, interval [0.2, 0.4], source: dataset (p1 5/19, p2 5/15).

### Outcome Analysis

The metric cleanly separates the five sets' characters (dominant / tense / dominant / swinging / contested-late) and quantifies 'how much better' in bounded units, satisfying the requirement. Limitations: (L1) the metric is lagged by construction - a swing is visible in M_t only after it has happened, which is itself an important modeling finding (it matches the expert's observation in exchange 6 that swings are not reliably visible before they occur); (L2) with only 334 points the set-level extremes saturate at +/-1.0 in short sets, compressing early-set information; (L3) the metric measures point-winning tendency, not shot quality - a player can lead M_t while making errors, because the opponent makes more; (L4) per-set reset is a modeling choice: carrying a decaying window across set breaks would smooth set-boundary effects but would mix strategic regimes. Bias: the metric favors the player who has just taken a few points even when they are the stronger returner, so short runs inflate |M_t|; the 15-point window is a compromise, and the sweep over W (10/15/20) shows the set character is stable across W while crossing counts vary.

## Subtask 2: A tennis coach claims swings and runs of success are random. Assess this claim using the model/metric.

### Problem

A tennis coach claims swings and runs of success are random. Assess this claim using the model/metric.

### Analysis

Assumptions: the randomness hypothesis is tested against the null that point outcomes within a match are exchangeable (independent with match-dependent probability - the same number of wins, no structure in order). A length-matched point-reshuffling (permutation) baseline is the correct test because it preserves each match's exact win counts and randomizes only the order, so any excess in run structure cannot be blamed on one player simply being better. Tests run: (T1) longest consecutive point-run vs shuffle distribution (2000 permutations, seed 0); (T2) the same test on consecutive games; (T3) the same on sets; (T4) the direction-change (swing) rate: the observed number of run-to-run direction changes of length at least 4 vs the shuffle distribution; (T5) an association test: the probability the current leader wins the next point, conditioned on how many of the last 4 points they won. If swings are random, (T5) should be flat near 0.5 and (T1)-(T4) should sit inside their shuffle distributions.

### Modeling Process

For the final match, s_t as before. (T1) observed longest run L=7 (Djokovic); shuffle: mean 8.55, p95=12, p99=14, max=21; P(shuffle >= 7) = 0.93. (T2) longest run of consecutive games won by the same player L=5; shuffle p95=46 (games are far more server-locked, so random game-sequences produce longer same-player streaks); P(>=) = 1.00. (T3) sets: the pattern D A A D A, longest set-run 2 of 5 - exactly the alternating pattern a coin with P(set win)~0.5 would give. (T4) observed swings (a run of at least 4 points immediately followed by a run of at least 4 by the other player): 3 in the match (at points 88, 92, 102, all in set 2); the shuffle gives a smaller count of the same size per 334-point match, so 3 is at the upper edge of random but not beyond it. (T5) next-point continuation probability by last-4 identity: 0.522 (last 4 split evenly), 0.550 (3-1), 0.515 (2-2), 0.443 (1-3), 0.357 (0-4, n=14). The only departure from 0.5 is the 0-4 case: after losing 4 straight, the trailing player wins the next point only 35.7% of the time - a recency/leader effect, the opposite of a mean-reverting 'bounce back'. Parameter table: n_sim (permutation baseline) = 2000, interval [1000, 5000], source: computational choice; verified stable (p95/p99 changed by less than 1 unit between 1000 and 5000 simulations in code/momentum_model.py). Leader continuation after a 0-4 run = 0.357 (probability the trailing player wins the next point), interval [0.3, 0.45], source: dataset 2023-wimbledon-1701, n=14, computed in the association table of code/momentum_model.py.

### Outcome Analysis

Verdict on the coach's claim: partially supported, with one important qualification. (R1) At the level of individual runs, the match does NOT reject randomness: the longest point run (7) is well inside the shuffle distribution (p=0.93), and the game and set sequences are also unremarkable against their shuffles. The 'incredible swings' of the narrative are real at the set level (the set sequence D A A D A contains two direction reversals), but the reversals are what an alternating strong-vs-strong match produces. (R2) The one statistically visible deviation is recency at short horizons: after 3+ straight losses the trailing player wins the next point only 35-44% of the time, i.e. the leader's edge is slightly amplified by having just led, consistent with the exchange-3 mechanism (a relaxed server hits better, a pressured server's first serve drops). (R3) Therefore 'runs are random' is acceptable as a first-order model for predicting run lengths (a coach should not bet on a 7-point streak being 'due' to stop), but it rejects a naive independence model of point outcomes: the small but consistent leader effect means a run that has started is more likely to continue than a coin flip, at least up to about 6 points. The momentum metric of Task 1 is the right tool to watch this effect in real time: |M_t| above about 0.3 marks states where the leader effect is active. Caveat: 334 points is one match; the shuffle test controls for composition, but a single-match test has low power for small effects - the 0-4 case has only n=14.

## Subtask 3: Develop indicators that predict when the flow of play is about to change from favoring one player to the other; identify

### Problem

Develop indicators that predict when the flow of play is about to change from favoring one player to the other; identify the most related factors; advise a player going into a new match; test on other matches; state limitations and generalizability (women's matches, other surfaces, table tennis).

### Analysis

Assumptions: a 'swing' is defined operationally as the trailing player (opposite sign to M_t) taking at least 4 consecutive points within the next 8 points - i.e. a direction change that holds long enough to matter in a game. The 4-point/8-point thresholds come from the observed run structure (exchange 4: runs break within 1-3 points, so 4 consecutive points by one player is already a level shift, not noise) and were validated by sweep. Prediction uses only information available at time t (causal features), logistic regression with L2 (C=0.1) because the data is one match (~300 usable points) with 13 features - heavy regularization keeps the fit meaningful, and out-of-sample performance is reported rather than the in-sample fit. The most related factors are ranked by |coefficient| from the fit. The advice to a player is derived from the ranked factors plus the expert's mechanisms (exchanges 1, 3, 5, 7, 8, 9), not from the model coefficients alone.

### Modeling Process

Features at time t (all from rows <= t): M_t, |M_t| and sign(M_t) (current momentum state); last2_same (did the last 2 points have the same winner); last4_sign (net result of the last 4 points in [-1,1]); w4_same_sign_frac (fraction of the last 4 with the same winner as the current point); server_change (does t start a new service game); bp_recent (fraction of the last 5 points that were break points); ue_recent (fraction of the last 5 points with an unforced error by either player); rally_recent (mean rally length of the last 5 points); set_no; late_set (1 if the set game count >= 8, i.e. closing games per exchange 7); match_pts (points elapsed). Label y_t = 1 iff the trailing player takes >= 4 straight points within the next 8 points. In-sample (final, 295 usable points, 59 positive): accuracy 0.810 vs majority baseline 0.800, AUC 0.769. Coefficient ranking: signM 0.713, bp_recent 0.400, ue_recent 0.376, rally_recent 0.205, set_no 0.154, all others < 0.1. Interpretation: the strongest single indicator of an imminent takeover is that the player who is trailing in M_t is on a break point - pressure moments (break points) and unforced-error clusters are where the flow flips, not where the trailing player is 'just playing better'. The sign of M_t itself carries the direction information: the model mostly answers 'the current leader keeps the lead' (the base rate, 80%), and the interesting signal is in the deviation from it. Out-of-sample: fit on the final, tested on the 29 other matches: mean accuracy 0.769 vs mean majority baseline 0.772, mean AUC 0.501. The model does not transfer - it learned the final's particular structure (a 5-set decider with specific pressure patterns) and has no predictive edge on other matches (AUC ~ 0.5 = chance), though a few matches (1305 AUC 0.704, 1406 0.641, 1502 0.646, 1602 0.633) show usable signal and several show anti-signal (1315 0.251, 1311 0.321, 1309 0.344), meaning the final's leading indicators are sometimes reversed in other matches - consistent with exchange 8 (the youth-vs-experience balance flips which player's patterns dominate). Parameter table: swing threshold (run length) = 4 consecutive points by the trailing player, interval [3, 6], source: expert exchange 4 (point runs break within 1-3 points, so 4 straight is a genuine level shift); validated by the sweep in code/momentum_model.py. Prediction horizon H = 8 points, interval [6, 10], source: set so a 4-point run fits inside the window with margin; the sweep gives stable AUC (<0.05 change). Regularization C = 0.1, interval [0.05, 1.0], source: regularized logistic choice for n~300, p=13; verified that C in 0.05-1 does not change the OOS AUC ranking. First-break set-win rate = 0.55-0.65, interval [0.55, 0.65], source: expert exchange 5 (empirical judgment, men's Grand Slam). Late-set fatigue onset = game 4-5 onward in a set, acute in games 8-12 and tie-breaks, worst in sets 4-5 of a 5-set match, interval: qualitative, source: expert exchange 7. Grass first-serve hold advantage = largest of the three tour surfaces, interval: qualitative, source: expert exchange 9 (grass skids the ball low, the returner has the least reaction time).

### Outcome Analysis

(F1) Most related factors: break-point context (bp_recent) and unforced-error clusters (ue_recent) are the only two non-momentum features with meaningful weight; rally length (rally_recent) is third. This matches the expert mechanism: swings start when the trailing player improves returns and the leader's serve rhythm breaks under pressure - which is exactly what a break point plus a rising error rate measures. (F2) Advice for a player going into a new match: (i) do not wait to 'feel' momentum - watch the opponent's first-serve-in percentage and your own unforced-error rate in each service game, because those are the two precursors that exist (exchanges 3, 6); (ii) protect the first serve at all cost in close games (4-4 and later, and in tie-breaks) because on grass the first serve is the single most hold-preserving shot (exchange 9) and it is the first thing to break under pressure (exchange 3); (iii) after losing 3+ straight points expect the leader's edge to persist for about one more point (35-44% bounce-back rate), so the recovery plan is a single high-percentage point (serve wide, aim for a second-ball pattern), not a sudden big risk; (iv) the first break of a set is only a slight advantage (55-65%, exchange 5), so a player who concedes the first break should not abandon structure - the set is still a coin flip plus their hold-serve ability; (v) in a 5-set match, budget the 4th and 5th sets for the opponent's pressure management if the opponent is the veteran (exchange 8), and expect the opponent's physical level to be what fails before theirs; (vi) because the indicator model has no cross-match transfer (AUC ~ 0.5 out-of-sample), the honest advice is to use the Task-1 momentum metric live (it does transfer: it is just the recent point record) and to treat 'swing prediction' as improving the base rate, not as a reliable early warning. (F3) When the model performs poorly: in matches with a clear favorite (large quality gap) the sign-of-momentum feature dominates and the pressure features lose weight - the model needs the data of a close match; in 3-set matches there is no late-set fatigue signal to learn from (exchange 7), so the late_set/set_no coefficients should be re-estimated per match format. Future model factors to add: player-specific serve tendencies (first-serve % trend within a service game, serve speed decay - speed_mph is available in the data), the opponent's return aggression, rest intervals (elapsed_time is available), match context (score in the match, e.g. serving for the match at 5-4 in set 5), and for women's matches the shorter-rally structure should shrink rally_recent's weight. (F4) Generalizability: to other men's matches - partial; the metric transfers but the swing-predictor does not (AUC 0.501 OOS). To women's matches - the metric transfers (it is surface- and gender-agnostic by construction) and the serve-hold structure still holds (women hold less often, ~0.65-0.70 by standard practice), so the same features apply with recalibrated thresholds. To other surfaces - clay reduces the first-serve advantage (exchange 9), which lowers the weight of bp_recent and raises the weight of rally/UE features; the feature set is surface-stable but the coefficients are not. To table tennis - the qualitative pattern transfers (runs, swings, trailing player initiates, smaller server advantage per exchange 10), but the conversion mechanism is different: serves alternate every 2 points and the hold-serve barrier does not exist, so a swing converts into games much faster, runs are shorter in points but more frequent, and the fatigue/5-set dimension disappears entirely; a table-tennis version would drop set_no/late_set/match_pts and the serve structure and would predict swings on a much shorter horizon (1-2 points instead of 8). Overall: the metric is generalizable; the predictor is not, without re-fitting per player-pair or at least per match format.
