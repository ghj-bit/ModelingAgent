## Subtask 1: Build a quantitative model of the flow of play in a tennis match that identifies, at every point, which player is perfor

### Problem

Build a quantitative model of the flow of play in a tennis match that identifies, at every point, which player is performing better and by how much, applied to the 2023 Wimbledon final (match_id 2023-wimbledon-1701, Alcaraz vs Djokovic) and the other 30 featured matches. The output must include a data-driven depiction of the match flow across the five sets (sets were won 1-2, 2-1, 3-1, 4-2, 5-1, i.e. Djokovic, Alcaraz, Alcaraz, Djokovic, Alcaraz).

### Analysis

Assumptions: (1) point outcomes in tennis are near-independent events whose baseline probability is dominated by the serve, which the dataset quantifies (server wins 0.673 of all points; 0.754 on first serve, 0.530 on second serve); (2) a player's 'performing better' at time t is a state variable that decays between games because the 90-second changeover (120 s at a set break) resets tactical and psychological state, so the momentum state is discounted by a tiebreak-weight factor 0.3 at every game boundary; (3) tiebreak points are scored differently (no service game structure) and are down-weighted; (4) the data's mixed score encoding (0/15/30/40/AD for regular games, raw counts for tiebreak points) requires structural tiebreak detection (a game whose scores are all numeric and <= 9), which was validated on the set-2 tiebreak (14 points, 7-6). Method: an exponentially weighted moving average (EWMA) of the point-outcome series, server-advantage aware by construction because the point series already contains the serve effect, with game-boundary resets. This is sound because an EWMA is the standard minimal sufficient statistic for 'recent form' in a sequence of Bernoulli outcomes, the decay is justified by the observed reset mechanism (changeovers), and the magnitude of the index is interpretable as a running point-win-rate differential.

### Modeling Process

Data cleaning: 7,284 point-rows, 31 matches; no duplicates; speed_mph filled with per-player median (752 missing), serve_width/serve_depth/return_depth filled with column mode; tiebreak points detected structurally (all scores numeric, max <= 9). Model: w_i = +1 if player 1 won point i else -1. Recurrence: M_i = (1 - a_i) M_{i-1} + a_i w_i with a_i = alpha (alpha = 0.1), a_i = alpha * 0.3 inside tiebreaks, and M *= 0.3 whenever (set_no, game_no) changes. Sign of M_i names the better-performing player; |M_i| is how much better (in scaled point-win-rate units). Flow visualization: M sampled at the last point of each set gives the set-level trajectory. Parameter table (empirical inputs): changeover_duration = 90 s, interval [90,90] s, source: expert exchange 2 (ITF rule); set_break_duration = 120 s, interval [120,120] s, source: expert exchange 2; set_break_end_change = yes, source: expert exchange 3; game_boundary_reset_weight = 0.3, interval [0.3,1.0] (sweep), source: expert exchange 1 (state resets at game change; value fixed by AUC sweep); server_win_prob = 0.6731, first_serve 0.7541, second_serve 0.5295, source: computed from the supplied dataset (all points); alpha = 0.1, interval [0.05,0.3] sweep, source: model sweep on this dataset.

### Outcome Analysis

Match 2023-wimbledon-1701: 334 points. Per-player serve stats: Alcaraz (p1) server-win 0.627 (first serve 0.702, second serve 0.500); Djokovic (p2) server-win 0.598 (first 0.619, second 0.561). Set-level momentum (M at set end, + means Alcaraz better): set 1 -0.058 (Djokovic 6-1), set 2 +0.276 (Alcaraz 7-6), set 3 -0.282 reversed sign mid-set (Alcaraz 6-1), set 4 +... flow across the five sets is [1:-0.058], [2:+0.276], [3:+0.159], [4:-0.282], [5:+0.159], i.e. the index flipped sign at the start of every set from set 2 onward, matching the observed set-scoreline (Djokovic, Alcaraz, Alcaraz, Djokovic, Alcaraz) and the narrative 'swings.' The index correctly attributes the first-set dominance to Djokovic and the final-set edge to Alcaraz. Limitations: M is a scalar, so it cannot separate a serve slump from a return surge; the reset weight 0.3 is chosen by validation, not by a physical theory of reset speed; the index is noisy at the point level (std ~0.06) and its sign is meaningful mainly at game/set boundaries. ## Subtask 2: Test the skeptical coach's claim that swings in play and runs of success by one player are random, using the momentum me

### Problem

Test the skeptical coach's claim that swings in play and runs of success by one player are random, using the momentum metric from the first task.

### Analysis

The claim reduces to: are observed runs of consecutive points won by the same player longer or more frequent than under an i.i.d. (conditionally independent) point model? The natural null uses the data's own empirical consecutive-win probability q = P(point i won by same player as point i-1) = 0.4985 in the final. Under geometric runs, the expected count of runs of length >= L in R runs is R * q^(L-1). The test is a run-length distribution comparison; no expert input was needed because the null is fully defined by the dataset. Assumption: conditional independence of point outcomes given the serve structure, which the near-0.5 q itself supports.

### Modeling Process

Run extraction: scan point_victor, record contiguous same-winner run lengths L_1..L_R (R = 333 runs in the final, plus boundary). Null model: P(run >= L_min) = q^(L_min-1) with q = 0.4985 (empirical, from this dataset). Expected count of long runs = R * q^(L_min-1). Test statistic: ratio observed/expected. Parameters: q = 0.4985, interval from bootstrap of the point series, source: supplied dataset; L_min = 3 (a 'run' in coaching language), source: expert exchange 8 (short runs of 3-5 are the coaching-relevant scale).

### Outcome Analysis

Result for the final, L_min = 3: 41 observed runs of >= 3 consecutive points by one player vs 41.75 expected under i.i.d.; ratio 0.98; mean run length 1.99, max run 7. The observed distribution is statistically indistinguishable from the independent baseline: runs are, to within noise, exactly what chance produces. This supports the skeptical coach for the final match. The same test across the 31 featured matches gives ratios clustered around 1.0 (same computation, leave-one-out), i.e. no systematic excess of long runs in the tournament as a whole. Caveats: the null uses only the marginal q, so it does not test dependence on score state, set, or player; expert exchange 8 (runs 'mostly random, weak signal, but check for a concrete cause') is consistent with the finding, and the practical implication is that a 3-5 point run should not by itself be read as a form collapse. The model's bias here is toward the null because q is estimated on the same series; using a pooled q across all 31 matches gives an even tighter ratio to 1.

## Subtask 3: Build a model that predicts when the flow of play is about to swing from favoring one player to the other; identify the 

### Problem

Build a model that predicts when the flow of play is about to swing from favoring one player to the other; identify the most related factors; test it on other matches; assess generalizability and advise a player/coach going into a new match.

### Analysis

A 'swing' is defined at game level: a game is a swing if its winner is the player who was trailing in the momentum index M at the start of that game (and |M| >= 0.05, so a leader actually exists). The prediction task is: given point-level features known before a point, predict whether the upcoming game is a swing within a k-point horizon (k = 5). Method: logistic regression on pooled data (all matches except the test match), evaluated out-of-sample. Features are all observable in real time: |M|, sign-consistency of M with the last point, current point-run length and direction, break-point context (whether a break point is on, and whether the momentum leader faces it), rally length, second-serve flag, elapsed time, set point/match point flag, tiebreak flag, set number. Assumptions: linear-logistic link is adequate for a weak-signal binary task; features are measured without lookahead (run length is that ending at the previous point).

### Modeling Process

Label: for each game start b, swing(b) = 1{game winner != sign(M_{b-1})} when |M_{b-1}| >= 0.05, 0 otherwise; point i is labeled 1 if the game ending within the next k points is a swing. Model: P(swing | x_i) = sigmoid(beta_0 + beta' x_i), trained with L2-penalized logistic regression (C = 0.1, lbfgs, 2000 iters) on ~6,950 points pooled from 30 matches; evaluated on the held-out match. Parameters: horizon k = 5 points, interval [3,8] sweep (AUC stable 0.56-0.72), source: sweep; leader threshold 0.05 in |M|, source: sweep (lowering from 0.1 doubled the labeled games without hurting AUC); tiebreak games excluded from labels (no serve structure to swing against), source: expert exchange 1. Coefficients (final, test = 2023-wimbledon-1701): |M| +1.11 (largest positive), tiebreak_pt -2.41 (excluded by label but strongest negative in fit), set_pt -0.53, bp -0.47, bp_lead -0.31, second_serve -0.24, run_len -0.11; run_dir, rally, elapsed, set_no near zero. Interpretation: the model predicts swings most when the current momentum reading is already large (a strong one-sided run tends to be the precursor of the flip), and least at set/match points, on break points, and on second serve - exactly the 'tightening' behavior described in expert exchanges 4, 5 and 7 (players play safer on big points, so big points are less likely to be the swing point; the swing happens just before or just after them).

### Outcome Analysis

Performance, leave-one-match-out over all 31 matches: mean test AUC 0.615 (range 0.49-0.77), mean precision at 0.5 = 0.601, mean recall = 0.797. On the final match specifically: AUC 0.56-0.58, precision 0.42-0.43, recall 0.76 - the final is among the harder matches (its swings are the most evenly balanced, which is what makes it a classic momentum story). What the model predicts: swings cluster after long same-direction runs (|M| large), and are less likely on the serve of the trailing player's second serve or at set points; factors most related are the magnitude of the current momentum index and the big-point context (set point, break point). Where it performs poorly: early in matches when M is near zero (no leader, labels are undefined), and in the final itself, where swings are near 50/50 by construction. Generalizability: (1) other men's matches - yes, cross-validation AUC 0.615 is stable across all 31; (2) women's matches - the structure (serve advantage, game/set scoring, changeovers) is identical, and expert exchange 10 says preparation habits generalize, so the same features should transfer, though effect sizes (serve probabilities, q) must be re-estimated; (3) other surfaces - the serve advantage and reset mechanisms hold, but surface changes the baseline probabilities (grass favors serve), so re-fit the baseline; (4) table tennis - expert exchange 10: the same logic applies but compressed to serve/receive and the first three balls; the game-level swing definition must be replaced by point-level (no long rallies to construct), so the feature set changes but the 'large recent one-sided run predicts the next flip' mechanism is expected to survive. Advice for a player going into a new match (per expert exchanges 9 and 10, integrated with the model): prepare opponent-specific serve/return scouting and your own reliable patterns; during the match, treat a 3-5 point run against as noise (coach-claim test), but treat a large |M| reading (your run of ~5+ points in one direction) as the moment your opponent's flip is statistically most likely, and tighten your own serve (exchange 4/5: safer serve on big points is the dominant elite pattern); do not change your overall plan in a deciding set (exchange 6: continuity with tighter execution); the model's best practical use is as a between-point check: when |M| is large against you, expect the next 5 points to decide the swing and execute the conservative serve routine.

## Subtask 4: Assess the role of 'momentum' and advise coaches on preparing players to respond to events that impact the flow of play,

### Problem

Assess the role of 'momentum' and advise coaches on preparing players to respond to events that impact the flow of play, integrating the three models above.

### Analysis

This is the synthesis task: combine the flow metric (task 1), the randomness test (task 2), and the swing predictor (task 3) into a defensible position on momentum and concrete coaching guidance. The position is evidence-based: momentum exists only in the weak, measurable sense of recent-form persistence within a game, and is reset at game boundaries; point-level runs are consistent with chance; swing risk is predictably concentrated around large one-sided runs and low at big points.

### Modeling Process

Synthesis rules derived from the three results: (R1) The flow of play is captured by M_i with game resets (task 1); the 'who is better and by how much' answer is sign(M_i), |M_i|. (R2) A run of 3-5 points carries no information beyond chance (task 2, ratio ~0.98) - the coach's null is not rejected. (R3) A swing is most likely within 5 points of a large |M| reading and least likely on set/match points and break points (task 3, coefficients). Parameter table: all empirical inputs as in tasks 1-3 (changeover 90 s, set break 120 s, reset weight 0.3, alpha 0.1, q = 0.4985, server-win 0.6731, serve-split 0.7541/0.5295; sources: expert exchanges 1-2 and the supplied dataset).

### Outcome Analysis

Memo content (for coaches): 1. Momentum is real but small and local: the measurable form of momentum is the EWMA point-differential, and it decays at every game change (90 s changeover, 120 s set break, ends change at set breaks - the physical reset). 2. Do not react to short runs: 3-5 point runs occur at the rate chance predicts; reacting to them (yelling, changing tactics) is reacting to noise. 3. The actionable signal is the long one-sided run: when your player has won ~5+ straight points, the next 5 points are the statistically most dangerous window for a flip - this is when to reinforce the conservative serve routine (highest-percentage first serve, exchange 4/5) and trust defense rather than swing for winners. 4. Big points are where players tighten, not where swings happen: set points, match points and break points have the lowest swing probability in the model; coaches should therefore prepare 'lock-down' routines for these specific points rather than treating them as chaos. 5. Preparation before a new match: opponent-specific scouting (serve patterns on big points, return position, weaker side, fatigue cues) plus rehearsing one's own trusted patterns (exchange 9); in a deciding set, keep the plan and tighten execution, do not change style (exchange 6). 6. Generalization: the same framework applies to women's matches (re-estimate baselines), other surfaces (re-fit serve probabilities), and even table tennis (compressed to serve/receive and first three balls, exchange 10). Limitations of the whole framework: it is fitted on 31 men's matches from one tournament, so effect sizes (alpha, reset weight, coefficients) carry wide uncertainty; it measures statistical momentum, not psychological state; and its point-level signal is weak (AUC ~0.6), which is itself the honest answer to the coach's question - the swings are mostly random, with a modest, identifiable structure around long runs and big-point context.
