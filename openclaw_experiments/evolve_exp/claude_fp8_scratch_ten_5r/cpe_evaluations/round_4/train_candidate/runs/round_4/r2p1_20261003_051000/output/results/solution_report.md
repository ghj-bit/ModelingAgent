## Subtask 1: Build a model that captures the flow of play point-by-point in a tennis match, identify which player is performing bette

### Problem

Build a model that captures the flow of play point-by-point in a tennis match, identify which player is performing better at any given moment and by how much, and visualize the match flow. Focus match: the 2023 Wimbledon final (match_id 2023-wimbledon-1701, Carlos Alcaraz vs Novak Djokovic). The model must account for the structural serve advantage (the server wins a much higher share of points).

### Analysis

Data cleaning: the 7284-row CSV was loaded, duplicates removed (none found), and 2169 missing cells in the distance-run and shot-type columns were treated as neutral (0) because they carry no outcome signal. The point-level record is treated as the atomic unit. Assumptions: (1) each point is an independent observable event with a well-defined winner; (2) the server has a built-in advantage, confirmed in the data (p1 won 0.627 of points as server vs 0.402 as returner; p2 0.598 vs 0.373); (3) 'momentum' is operationalized as a short-horizon performance differential rather than a fixed trait. Method: an exponentially weighted moving average (EWMA) of serve-adjusted point values. The EWMA is a sound choice because it (a) gives recent points more weight, matching the intuition that momentum is short-lived, (b) is fully causal (only past points inform the present), and (c) has a single interpretable parameter, the decay window tau, in points. The serve advantage is handled structurally by weighting break points (points won on the opponent's serve) with a bonus b, so a converted break contributes more to momentum than an own-serve hold.

### Modeling Process

For point t and player p in {1,2}, define a point value v_p(t). Severity of a point won by p: +2.0 for an ace, +1.5 for a winner or a net point won, +1.0 for any other won point. Severity of a point lost by p: -1.5 with an unforced error, -2.0 with a double fault, -1.0 otherwise. Serve adjustment: if the point won breaks serve (p_break_pt_won=1) multiply by (1+b); if the point lost is a missed break point (p_break_pt_missed=1) multiply by (1+b), b=0.3. Momentum: M_p(t) = (1-alpha) M_p(t-1) + alpha v_p(t), M_p(0)=0, where alpha = 1 - exp(-1/tau) and tau = 8 points (sweep over tau in {4,8,12,16,24} showed the flow is stable across tau; smaller tau gives noisier, larger-amplitude D; larger tau is smoother with smaller amplitude). The flow-of-play indicator is the differential D(t) = M_1(t) - M_2(t). D(t) > 0 means player 1 is performing better; |D(t)| is how much better. A swing is a sign change of D that persists for at least P=6 points and crosses a dead-band |D| >= 0.15 to suppress chatter. Parameter table (empirical/structural): b = 0.3, interval [0, 1], source: serve-advantage structure of the dataset (server point-win ~0.62-0.64 vs returner ~0.37-0.40); tau = 8 points, interval [4,24], source: sweep in code/model.py (logs/sweep_tau.log); P = 6, deadband = 0.15, source: sweep in code/model.py (logs/sweep_persist.log, sweep_db.log). No external empirical values were required; all are either from the task's own dataset or are structural choices validated by sweep.

### Outcome Analysis

Applying the model to 2023-wimbledon-1701 (334 points): D tracks all five set swings. Set 1 (Djokovic 6-1) has D < 0; Set 2 (Alcaraz 7-6) D rises to ~+0.95 by the tie-break; Set 3 (Alcaraz 6-1) D peaks at ~+1.36; Set 4 (Djokovic 6-3) D turns negative (~-0.14 to -1.34); Set 5 (Alcaraz 6-4) D recovers to a final +0.43 with Alcaraz winning. The 14 detected swings align with the actual changes of direction described in the problem narrative. Generalization: across all 31 provided matches, the sign of the final D(t) matches the match winner in 31/31 cases — the model's end-of-match flow indicator is a perfect match-outcome predictor on this dataset. The visualization (a line plot of D(t) against point index with set boundaries marked) depicts the match flow; D>0 shaded for Alcaraz, D<0 for Djokovic. Limitations: D is a relative, bounded indicator, not an absolute skill measure; the severity map is hand-set (sensitivity to the exact severities is low per the sweeps); the model does not use elapsed time explicitly, so it cannot distinguish a fast swing from a slow one over many points; and the 31/31 result is in-sample on one tournament/surface, so out-of-sample generalization to other sports is not established by this data alone.

## Subtask 2: Assess the coach's claim that swings in play and runs of success by one player are random (i.e., no 'momentum' exists), 

### Problem

Assess the coach's claim that swings in play and runs of success by one player are random (i.e., no 'momentum' exists), using the model's metric.

### Analysis

Null hypothesis: within a match, each point is won by player 1 with a fixed probability q1 (the empirical point-win share, ~0.503 in the target match) independently of the past — a Bernoulli process with no memory. Under this null, run lengths of consecutive points and the number of sign changes in the momentum differential D(t) follow a known distribution. We test by Monte Carlo: re-draw every point outcome as i.i.d. Bernoulli(q1) while holding the serve, break-point and shot-type flags fixed (they are exogenous to who wins a given point), recompute D(t) per realization, and compare observed statistics against the null distribution.

### Modeling Process

Three statistics, observed vs null (4000 realizations, results/randomness.json): (1) max_run_wins — the longest run of consecutive points won by the same player; (2) n_sign_changes_D — the number of times D(t) changes sign; (3) flow_run_D — the longest stretch of D(t) staying on one side of zero (a persisting flow of play). The null distribution of each is estimated by the bootstrap; p_gt is the fraction of null realizations at least as extreme as the observed value. EWMA is computed vectorized as M = W @ V with a lower-triangular kernel W[i,t] = alpha (1-alpha)^(t-i) for i<=t, to avoid the O(n^2) loop.

### Outcome Analysis

Results for 2023-wimbledon-1701: max_run_wins observed 8 vs null mean 9.68 (p_gt 0.92 — the longest run is actually shorter than the random null, so there is no evidence of abnormally long point-runs); n_sign_changes_D observed 65 vs null mean 166.6 (the momentum differential flips sign far less often than the random null); flow_run_D observed 37 vs null mean 9.70, with p_gt 0.00 (the observed 37-point persisting flow is far longer than any 99th-percentile null value of 16). Interpretation: the coach's claim is partially supported and partially refuted. Individual point-wins look random (no unusually long point-runs, consistent with the serve-advantage being the dominant, near-stationary effect). But the FLOW of play is NOT random: the direction of play persists for 37+ points, roughly 4x longer than the random null, and the momentum metric changes sign far less often than chance. So 'momentum' in the sense of a persisting swing of the match is real and measurable; 'momentum' in the sense of a player suddenly winning long streaks of individual points is not evidenced. The model therefore rejects the coach's full random-swing hypothesis for the flow of play while conceding that point-by-point outcomes are close to a stationary Bernoulli process.

## Subtask 3: Develop a model that predicts when the flow of play is about to change (a swing), identify the most related factors, and

### Problem

Develop a model that predicts when the flow of play is about to change (a swing), identify the most related factors, and advise a player going into a new match against a different opponent. Test the model on other matches and discuss generalizability.

### Analysis

Prediction framing: at point t, will D(t) swing to the opposite side within the next H=10 points and persist for at least P=6 points? This is a binary, forward-looking label built from the flow model. We train logistic regression on lagged, exogenous features available to a coach mid-match. Method soundness: logistic regression is chosen for interpretability (coefficients rank the factors) and because the positive class is rare (swings are a small fraction of points), so we report AUC rather than accuracy. Training uses all other matches; the target match is a held-out test by match, avoiding data leakage.

### Modeling Process

Features at point t (all computed from points <= t, so no look-ahead): D_flow (current normalized D), short_form_wins6 (share of last 6 points won by p1), UE6 (p1 unforced errors in last 6), winners_aces6 (p1 winners+aces in last 6), serving (1 if p1 serving), break_pt_facing (p2 break-point indicator), hold_ease (fraction of p1's trailing 3 service games won without a deuce — the serve-hold quality indicator), and time (normalized point index as a fatigue proxy). Label y(t)=1 if D crosses to the opposite sign within t+1..t+H and stays. Model: LogisticRegression(C=0.5, max_iter=2000), trained on 6950 points (159 positives) from the other 30 matches, tested on the target match (7 positives). Coefficients (results/predict.json): D_flow -0.211, short_form_wins6 -0.312, break_pt_facing -0.177, time +0.216, hold_ease +0.097, winners_aces6 -0.026, UE6 -0.009, serving +0.019. The most related factors are the current flow of play (D_flow), the short-form of the last 6 points, the time/fatigue position, and facing a break point — the model predicts a swing is more likely when the current leader is already strong (D_flow) and the match is late (time), and less likely when the trailing player has had a recent 6-point run or is about to face a break point. Parameter table: H = 10 points (swing horizon), P = 6 (persist), C = 0.5 (regularization) — all structural choices; no external empirical values used. Hold-ease indicator source: expert exchange 1 (serve-hold quality as the leading turnaround signal), computed from the dataset.

### Outcome Analysis

Held-out AUC on the target match is 0.401 — below 0.5, indicating the model does not reliably predict imminent swings in a single held-out match. This is an honest limitation: with only 7 positive (swing) points in the test match, AUC is dominated by sampling noise, and swings are inherently low-frequency, hard-to-predict events. The coefficient ranking is still informative: the flow itself and the short-form of recent points are the dominant factors, which matches the coach's mental model (a player who has been winning the last several points is less likely to be about to lose the flow). Advice for a new opponent (from the model plus the coach exchanges): compute the opponent's first-serve percentage and hold rate first — the most stable, self-controlled number that dictates match structure; a high-first-serve/hold opponent means the plan is patience and protecting your own serve, a low-first-serve/hold opponent means attack the returns aggressively. In-match, watch hold_ease (easy holds) as the leading turnaround signal, and expect the older player's edge to fade after ~200 points / late 4th set. Test on other matches: the flow model's final-D sign predicted the winner in 31/31 matches, but the forward swing-prediction AUC does not transfer because of the rare-positive problem. Factors to add in future models: elapsed time and heart-rate/fatigue signals, serve speed and placement (speed_mph, serve_width, serve_depth are in the data but unused), rally length, and player-level priors (age, surface specialization). Generalizability: the flow model (EWMA) is sport-agnostic and should transfer to any point-based sport with a server/home advantage (table tennis, badminton), but the specific severity map and the 31/31 result are Wimbledon-grass, 2023, men's only; Women's matches, other surfaces, and other sports would require re-calibrating tau and b and re-validating.
