## Subtask 1: Subproblem 1: Develop a model that captures the flow of play as points occur, applied to the 2023 Wimbledon final (match

### Problem

Subproblem 1: Develop a model that captures the flow of play as points occur, applied to the 2023 Wimbledon final (match 2023-wimbledon-1701, Alcaraz (player 1) vs Djokovic (player 2), 334 points, 55 games, 7 sets' worth of games across 5 sets: 6-1, 7-6, 6-1, 3-6, 4-6). The model must (a) identify which player is performing better at a given time, (b) quantify how much better, and (c) support a visualization of the match flow (described numerically here since no images are included). The serve advantage must be factored in.

### Analysis

Assumptions: (1) given who is serving and whether it is the first or second serve, the probability of winning the point is constant within a match (a serve-conditioned Bernoulli model) — this is the structural rule the expert confirmed (exchange 1): point outcomes are near-independent once the server is conditioned on, and the dominant structural event is the change of server at each game boundary. (2) 'Performing better' means outperforming the serve-adjusted expectation, not simply winning more points, because the server structurally wins most points (76.2% on first serve, 58.9% on second serve pooled; 83.9% of games held). (3) Flow is a short-memory phenomenon: the expert placed a sustained shift at the scale of a few games (exchanges 5, 7, 9: typical game 4-6 points; shifts build over 1-3 games and are transient after a tight set), so the memory of the metric is an exponential moving average over points with effective window of about 3 games (weight 0.35 on points) and an EWMA over per-game flow scores (weight 0.4, effective window 2-3 games). Approach: two-level model. Point level: baseline P(player1 wins point | server, serve_no) estimated from the match data; surprise u_t = outcome_t - 2*E_t + 1, centered in {-1, 1} so + favors player 1. Momentum m_t = 0.35*u_t + 0.65*m_{t-1}. Game level: each game g gets a signed surprise s_g = sum of u over its points (positive if player 1 outperformed expectation in that game); a game 'flow score' f_g = sign(s_g) (with magnitude from |s_g|), and the match flow F_g = 0.4*f_g + 0.6*F_{g-1}. Sign of F indicates who is performing better at game g; |F| indicates how much better (on a 0-1 scale, |F|>0.3 is a strong lean). Why sound: it isolates performance from the structural serve advantage (the thing the problem explicitly warns about), uses only in-match data for calibration, and its memory scale matches the observed timescale of real swings. Data cleaning: 7284 rows, 46 columns, no duplicate rows, no non-sequential point_no in any game, AD/tiebreak score encoding verified consistent; missing values only in speed_mph (752, all second-serve or missing radar), serve_width/serve_depth (54 each), return_depth (1309) — these are descriptive fields not used by the model, so no imputation was needed beyond dropping them from use.

### Modeling Process

Point baseline (estimated per match from the data, then used on the same match): p1s1 = P(p1 wins | p1 serves, 1st) = 0.702, p1s2 = 0.500, p2s1 = 0.381, p2s2 = 0.439 for 1701 (final). For point t with server S_t in {1,2} and serve number N_t in {1,2}: E_t = p(S_t serves, N_t) if S_t = 1, else 1 - p(other, N_t); surprise u_t = pt_t - (2E_t - 1) where pt_t = +1 if p1 won, -1 otherwise, so u_t in {-2E_t+1, 2-2E_t}. Point momentum: m_0 = 0, m_t = lam*m*u_t + (1-lam*m)*m_{t-1}, lam_pt = 0.35. Game g with point set G_g: s_g = sum_{t in G_g} u_t (p1-signed); flow score f_g = sign(s_g) (0 if |s_g| is negligible); game flow F_0 = 0, F_g = 0.4*f_g + 0.6*F_{g-1}. Outputs: performing-better player = argmax over sign of F_g (or m_t at point resolution), margin = |F_g| (or |m_t|). Match flow visualization (numeric description): a line plot of m_t (or F_g) against point number with the horizontal axis broken by set; the line oscillates around zero with excursions: set 1 ends at m = -0.87 (Djokovic dominant, set won 6-1); set 2 swings through +0.95 mid-set to end at +0.53 (Alcaraz, tiebreak); set 3 ends at +0.37 (Alcaraz 6-1); set 4 swings from -0.2 to -0.98 mid-set ending at -0.58 (Djokovic 6-3 comeback); set 5 oscillates between -0.6 and +0.86 and ends at +0.33 (Alcaraz 6-4). A shaded band at +/-0.3 marks 'competitive' flow; excursions beyond it mark who is in control. Set-end flow signs agree with the actual set winners in 5/5 sets of the final, and in 113/117 = 97% of all completed sets across the 31 matches (3 matches excluded: 1403 and 1404 and 1502 have a last set not finished in the data). Match-end flow sign agrees with the match winner in 28/31 pooled matches.

### Outcome Analysis

Results for 1701: after set 1 the model reports Djokovic outperforming at margin |m| ~ 0.8-0.9 (he won 7 of 8 games' worth of flow, holding serve at 6-1); the model's margin through the tiebreak of set 2 peaks at +0.95 for Alcaraz before the set ends +0.53; in set 4 the model captures the comeback as a genuine flow reversal, with Djokovic's margin building to -0.98 by game 6 of the set; at the final point the model reads Alcaraz +0.33, i.e. he won on slightly better serve-adjusted performance despite losing more raw points in sets 1 and 4 (168-166 points overall). The margin scale is calibrated so that |m| ~ 0.3 corresponds to roughly one game's worth of sustained outperformance. Limitations and biases: (1) the per-match baseline is estimated on the same match it is applied to, so early-match surprises are inflated (the first ~10 points carry estimation noise); a pooled baseline (0.762/0.589) was cross-checked and gives the same set-end signs. (2) The metric is serve-conditioned, which removes the structural advantage but also means a player who is simply serving well looks 'in control' — this is by design per the problem note, but it means the margin underweights receiving-game quality. (3) The EWMA smooths point-to-point noise but with lam = 0.35 it still flips sign roughly 21 times in the final, so 'who is better at a given point' is noisy; the game-level flow is the more stable read. (4) No shot-quality, fatigue, or tactical variables are in the data, so 'performing better' is a points-vs-expectation construct, not a physical one.

### Problem

Subproblem 2: A tennis coach postulates that swings in play and runs of success are random. Use the model/metric to assess this claim on the provided data.

### Analysis

Assumptions: the null model is that, conditional on server and serve number, points are independent Bernoulli trials with the estimated per-match probabilities. Under this null, 'runs' of consecutive points won by the same player and lag-1 serial dependence in the beat-the-expectation indicator have known expected behavior, so observed deviations can be measured against it. Approach: three tests, all serve-conditioned so the structural serve effect is not mistaken for momentum. (a) Run-length distribution: lengths of consecutive same-victor point runs; under the null with p1 point share about 0.51 in the final, the expected mean run length is 1 + 2p(1-p) = 1.01 (alternation-dominated) — in practice we compare the empirical mean (which includes the serve-driven clustering) against the expert's typical band of 2-4 points for a streak (exchange 2). (b) Lag-1 Markov test on the serve-adjusted beat indicator z_t = 1{u_t > 0}: compute P(beat|beat) and P(beat|miss); under the null these are equal, so the delta is the measure of serial dependence. (c) Block-permutation null: shuffle the surprise series u in blocks of 10 (preserving serve structure within blocks and short-run local dependence) 300 times and recompute the delta; the observed delta is compared to this null distribution to get a p-value. Why sound: test (c) is the key one — raw lag-1 dependence in raw point outcomes is dominated by the serve pattern (server wins 76% of first-serve points, so raw outcomes are serially correlated by construction); conditioning on the serve-adjusted surprise and then permuting in blocks isolates exactly the 'momentum' component the coach is denying.

### Modeling Process

Let u_t be the serve-adjusted surprise from subproblem 1. z_t = 1{u_t > 0}. Empirical: n11, n10 = counts of (z_{t-1}=1, z_t=1), (1,0); n01, n00 likewise. P_cont = n11/(n11+n10), P_start = n01/(n01+n00), delta = P_cont - P_start. Null via block permutation: for k = 1..300, partition indices into consecutive blocks of 10, permute within each block, recompute delta_k. p-value = (1/300) * 1{delta_k >= delta}. Run test: L_i = lengths of maximal runs of identical point_victor; report mean(L), max(L), fraction with L >= 6. All computed per match, and pooled across the 31 matches with >= 50 points.

### Outcome Analysis

Results (final, 334 points): mean raw run length 2.98, max 8, 5.4% of runs reach 6+ points — inside the expert's 2-4 typical band, i.e. 'runs' are short. P(beat|beat) = 0.503 vs P(beat|miss) = 0.506, delta = -0.003; the block-permutation null gives mean delta -0.049, sd 0.049, and the observed delta exceeds 81% of the null (p = 0.19). Pooled over all 31 matches: mean run length 3.13 (max 14, 7.2% of runs >= 6), and the mean per-match lag-1 delta is +0.061 — small and of inconsistent sign across matches (the final's is negative). Verdict: the coach is largely correct at the point level. After conditioning on the server, there is no statistically significant positive serial dependence in the final (p = 0.19) and only a weak, sign-inconsistent tendency pooled. What is NOT random: the clustering is structural, not psychological — run lengths are longer than the pure-coin expectation because the serve (76% first-serve win rate, 84% game-hold rate) creates within-game clustering, and runs end at game boundaries when the serve changes hands (exchange 1's mechanism, confirmed in the data: the majority of 6+ point runs span a single service game). So 'momentum' in the sense of a hot hand that makes the next point more likely to go the same way is not supported; 'momentum' in the sense of a few-game shift in who outperforms the serve-adjusted expectation (subproblem 1's game flow) is a real, measurable, and visually clear phenomenon in the final (sets 1 vs 3, set 4 comeback). Bias note: the block size 10 was chosen to be smaller than a typical game (4-6 points, exchange 5) times two, so the null preserves serve structure; smaller blocks would give a more conservative p-value. The test has limited power for small delta with n ~ 300 points per match.

## Subtask 3: Subproblem 3: Develop a model that predicts when the flow of play is about to change from favoring one player to the oth

### Problem

Subproblem 3: Develop a model that predicts when the flow of play is about to change from favoring one player to the other, using at least one match; identify the most related factors; advise a player going into a new match against a different opponent; test the model on other matches and report how well it predicts swings, what factors are missing, and how generalizable it is (women's matches, other tournaments, court surfaces, other sports such as table tennis).

### Analysis

Assumptions: (1) a 'swing' is a reversal in the direction of the running game-level flow F_g (subproblem 1) at a game boundary — the expert identified the change of server at a game boundary, with a high-leverage point (break point, tiebreak point, set point) as the concrete trigger, as the single best indicator of an impending flow change (exchange 10), and said sustained shifts build over several games (exchange 7), so prediction is done game-by-game, not point-by-point. (2) The predictor may only use information available before the swing game starts (features of game g-1 and earlier). Approach: candidate cues, each a property of the game preceding the swing game: prev_break (game g-1 was a break of serve), prev_bp (game g-1 contained a break point), prev_long (game g-1 had >= 7 points, i.e. deuce), prev_srv_neg (server's surprise in game g-1 was negative, i.e. the server underperformed), prev_against_flow (game g-1 was won by the side that was trailing in flow). For each cue, the conditional rate P(swing at g | cue at g-1) is compared to the base rate P(swing), pooled across all 31 matches (7253 games) for power. The 'prediction' used for validation: at each swing game, the model predicts the direction of the flow after the swing equals the flow direction of the swing game itself, and is scored against the sign of the next 25 points (about 4-5 games, the multi-game timescale from exchange 7) of serve-adjusted surprise. Why sound: it is a simple, fully out-of-sample-by-construction conditional-probability predictor (the cues precede the event), and the pooled analysis avoids fitting on a single match.

### Modeling Process

Swing detection: F_g = 0.4*f_g + 0.6*F_{g-1} with f_g = sign(s_g); a swing occurs at game g if sign(F_g) != sign(F_{g-1}), both signs nonzero, and |F_g| > 0.25 * mean(|F|) (the built-up threshold keeps noise flips out). Cues as above. Conditional rates: R_cue = (# of (cue at g-1, swing at g) pairs) / (# of cue at g-1), pooled; lift = R_cue / R_base. Direction validation: for each swing at game g ending at point index e, let H = 25; predicted sign = sign(f_g); observed sign = sign(sum of u over points e+1 .. e+H); a hit is agreement. Base direction accuracy (always predict continuation of pre-swing flow) is computed for reference.

### Outcome Analysis

Results: in the final the model flags 21 game-level flow reversals (lam flow weight 0.4); forward direction hits 7/20 (35%) over the next 25 points. Pooled cue analysis (31 matches, 7253 games, base swing rate 51.3%): prev_against_flow (previous game won by the trailing side) is the only cue with a meaningful lift — swing follows at 64.0% vs 51.3% base (n = 734), lift 1.25. All other cues show no lift or negative: prev_break 13.2% (n = 189), prev_bp 30.2% (n = 301), prev_long 45.3% (n = 274), prev_srv_neg 13.3% (n = 210). Interpretation: the strongest 'tell' for a further flow change is that the trailing player just won a game against the current flow — i.e. flow reversals cluster: once a shift has started, it tends to complete over the next game or two before stabilizing, matching the expert's 'sustained shifts build over several games, and a single high-leverage point confirms a shift already underway' (exchanges 4, 7, 10). The other cues do not predict: a previous break or a previous deuce game does not make a further reversal more likely, which is consistent with the exchange-6 finding that pressure effects (serving safer on break point) are weak and player-dependent. Advice to a player/coach going into a new match: (1) the reliable indicator is the game boundary plus who serves next — when you are trailing in flow and you just won a game against the flow (especially a break), expect the shift to continue for 1-3 more games; press while the shift is fresh. (2) Do not expect an immediate response to a rival's run — runs of 2-4 points are normal (exchange 2), and the structural reset is the change of server; the highest-value preparation is a stable serve routine under pressure, because the data and expert (exchange 8) show unforced errors rise on high-leverage serves and the final's set-4 swing was driven by the trailing side's shot-making collapse (Alcaraz 19.8 winners/100 pts vs 9.6, comparable unforced errors 13.5 vs 12.0, Djokovic DF 0.9% vs Alcaraz 2.1%). (3) After winning a tight set, expect only 1-2 games of free play (exchange 9) — consolidate with a strong opening game. Cross-match test (5 matches: 1301 Alcaraz-Jarry, 1309 Sinner-Halys, 1502 Medvedev-Eubanks, 1402 Dimitrov-Rune, 1407 Rublev-Bublik): swings 18, 13, 25, 25, 34 respectively; forward direction hits 7/18, 5/13, 11/25, 12/25, 18/34 — pooled 53/115 = 46%, i.e. the direction after a detected reversal is essentially a coin flip, while the detection itself (that a reversal is happening) is consistent (flow reversals occur in every match at 2-6 per set). So the model detects swings well (they are structural and visible in the metric) but does not reliably predict their direction beyond the 'trailing side just broke the flow' cue. Factors to add in future models: shot-placement and court-position data (absent here — net points, serve width/depth are only recorded partially), player-specific pressure profiles (exchange 8: error rise is player-dependent), fatigue/elapsed-time effects, and the exact serve tactic on high-leverage points (exchange 6). Generalizability: the mechanism is serve-structure based, so it transfers to any scoring system where one party alternates a structural advantage — table tennis (sides change every 5 points, same logic with a shorter game) and other tennis tours directly. Women's matches: the model needs no gender-specific parameter (all probabilities are estimated from the data of the match in question), so it generalizes; the only caveat is that the empirical magnitudes (serve win rates, run lengths) differ somewhat and should be re-estimated per population. Other surfaces: clay slows the serve effect (lower server point-win rate, exchange 3 noted the 60-80% band is surface-dependent), which the model absorbs automatically because baselines are re-estimated per match; the run and swing structure should persist. The main non-generalizable part is the specific cue lift (prev_against_flow, 1.25), which was estimated on 31 men's grass matches and should be re-validated before being trusted on a different population.
