## Subtask 1: Build a defensible subset of the IPEDS candidate list (~2,977 schools) and the College Scorecard cohort data, cleaning e

### Problem

Build a defensible subset of the IPEDS candidate list (~2,977 schools) and the College Scorecard cohort data, cleaning encoding and missingness, so that every later quantitative judgment stands on a consistent, documented base. Scope: data loading, merging the candidate UNITID file with the scorecard, repairing privacy-suppressed values and type inconsistencies, and characterizing the resulting 2,936-school analysis set.

### Analysis

Assumptions: (1) the candidate file defines the universe of eligible schools; 41 listed UIDs have no scorecard cohort row and are dropped, leaving 2,936. (2) Each UNITID appears at most once in the scorecard, so no deduplication is needed. (3) 'PrivacySuppressed' strings in earnings, debt and repayment columns are missing values, not numbers. (4) Two-year institutions (PREDDEG in {0,1}) must be judged on 3-year completion (C200_L4_POOLED_SUPP) while four-year institutions are judged on C150_4_POOLED_SUPP; mixing the two would compare different objects. (5) Missing rates for a given variable mean the variable is not yet measurable for that school, so missingness is handled per-variable rather than dropping schools wholesale. Cleaning performed: six object-typed numeric columns (C150_4_POOLED_SUPP, C200_L4_POOLED_SUPP, md_earn_wne_p10, gt_25k_p6, RPY_3YR_RT_SUPP, GRAD_DEBT_MDN_SUPP, GRAD_DEBT_MDN10YR_SUPP) coerced to numeric with 'PrivacySuppressed' mapped to NaN; 142 schools lack debt medians, 229 lack repayment rates, 1,183 lack 10-year earnings. No rows deleted beyond the 41 unmatched UIDs; the 1,114/1,936 missing retention/completion cells stay in place and are handled by the capacity floor of the scoring model.

### Modeling Process

Let U be the candidate UID set (|U|=2,977) and S the scorecard rows (|S|=7,804). Analysis set A = S restricted to UNITID in U, |A| = 2,936. For column c with privacy flag, x_c = NaN if x_c == 'PrivacySuppressed' else numeric(x_c). School-type indicator t_i = 1[PREDDEG_i in {0,1}]. Completion measure K_i = C200_L4_POOLED_SUPP_i if t_i else C150_4_POOLED_SUPP_i. Documented coverage after cleaning: UGDS 2,935/2,936; PCTPELL 2,930/2,936; C150 4-yr completion 1,879/2,936; C200 3-yr completion 986/2,936; md_earn_wne_p10 2,818/2,936; gt_25k_p6 2,859/2,936. No imputation was applied; imputation-free handling (floor + z-score median fill only inside the scorer) keeps the base set honest.

### Outcome Analysis

The cleaned base set is dominated by large public institutions in FL, CA, TX: 1,574 private, 1,361 public, 1 other; 1,706 four-year-plus, 914 two-year-plus. The heavy missingness in C150 (36% of the set) and C200 (66%) is structural, not accidental, because scorecard suppression follows cohort size. Consequence: any single-completion-rate ranking would silently drop one third of the field; the scoring model therefore applies the capacity floor only where a completion measure exists and treats a school with no measurable completion as non-fundable rather than imputing it. Limitation: schools whose only completion figure is suppressed are excluded from funding even if strong, which biases the candidate pool toward larger institutions with reportable cohorts.

## Subtask 2: Define a charitable-appropriate return on investment (ROI) for a $100M/yr x 5-year educational grant program, and a scor

### Problem

Define a charitable-appropriate return on investment (ROI) for a $100M/yr x 5-year educational grant program, and a scoring model that ranks the 2,936 candidate schools by their potential to convert private funding into student performance gains, without duplicating the focus of other large grantors.

### Analysis

Assumptions: (1) The dominant mechanism is 'need plus capacity', confirmed by expert exchange 1: fund money goes to schools with demonstrated need and demonstrated capacity to use money well, not the wealthiest and not the weakest. (2) The binding constraint is capacity-to-convert, confirmed by exchange 2: high need alone does not make a school fundable. (3) Empirical floors: below ~30% four-year completion the school is treated as too weak; the fundable band starts around 40-50% (exchanges 3-4); two-year schools are judged on 3-year completion around 15-30% instead. (4) Outcome priority order from exchange 5: completion/graduation, then retention, then post-graduation earnings and repayment, then equity gaps, then trajectory; inputs (spending, facilities) are weighted least. (5) Per-exchange 8, a single funder's grant to a regional state university is meaningful at $1-5M/yr and disruptive above $5-10M/yr; small colleges absorb $0.5-2M/yr. (6) Per exchange 6, a realistic 5-year completion gain from a single grant is 2-5 points, reaching 5-10 only from a very low start with a clear trajectory. ROI is defined as the number of additional students who complete a credential per $1M of grant, over the 5-year grant horizon: ROI_i = (g_i * K_i * UGDS_i) / (a_i * 5 / 10^6), where g_i is the expected completion-rate gain (fraction), K_i the completion rate, UGDS_i enrollment, and a_i the annual absorption capacity in dollars. This is a charity-appropriate ROI because the numerator is students, not dollars.

### Modeling Process

Scoring model. Z-score each column: z(x) = (x - mean)/std, with NaN filled by the column median before scoring. Composite score S_i = 0.30 * z(PCTPELL_i) + 0.30 * (z(K_i) + z(gt_25k_p6_i))/2 + 0.25 * (z(RET_FT4_i) + z(md_earn_wne_p10_i) + z(RPY_3YR_RT_SUPP_i))/3 + 0.15 * (1 - z(1 - gt_25k_p6_i)). Weights follow exchange 5's priority order: need and capacity carry 0.60, outcome quality 0.25, equity 0.15. Fundability floor F_i: for four-year schools, F_i = [C150_4 >= 0.20] AND [RET_FT4 missing OR RET_FT4 >= 0.60]; for two-year schools, F_i = [C200_L4 >= 0.15]. A school is fundable only if F_i and K_i and PCTPELL_i are present. Absorption capacity a_i, in $/yr: a_i = clip( (UGDS_i/3000) * 2.5e6 * 0.5 + 0.5e6 * 0.5, 0.5e6, 5.0e6 ), calibrated to exchange 8's $0.5-5M/yr band with a 2.5M/yr midpoint. Expected gain g_i: g_i = 0.04 * ( 0.5 * headroom_i + 0.5 * served_frac_i ), where headroom_i = clip((0.60 - K_i)/0.60, 0, 1) rewards schools with low starting completion (exchange 6: larger gains only from very low starts) and served_frac_i = clip( (a_i * 5) / (20e3 * UGDS_i * 5), 0.05, 1.0 ) rewards schools whose 5-year grant reaches a meaningful share of students at a $20k per-student program cost. g_i = 0 for non-fundable schools. ROI as defined above. Empirical parameter table (all values from the expert exchanges that supplied them): grad_gain_max = 0.04, interval [0.02, 0.05], source: expert exchange 6; min_c150_4yr = 0.20, interval [0.20, 0.30], source: expert exchanges 3-4; min_ret_ft = 0.60, interval [0.60, 0.70], source: expert exchanges 3-4; min_c200_2yr = 0.15, interval [0.15, 0.30], source: expert exchange 4; absorb_lo = 0.5e6, interval [0.5e6, 1e6], source: expert exchange 8; absorb_mid = 2.5e6, interval [2e6, 3e6], source: expert exchange 8; absorb_hi = 5e6, interval [5e6, 10e6], source: expert exchange 8; min_grant = 0.5e6, interval [0.5e6, 1e6], source: expert exchanges 2 and 8; per_student_program_cost = 2e4, interval [1e4, 4e4], source: model calibration consistent with exchange 8's absorption logic.

### Outcome Analysis

The composite score separates the field cleanly: elite flagships (Ohio State, UT Austin, UCF) score high on outcome quality but low on need, so they are outranked by high-Pell, mid-completion regional publics and large community colleges, which is exactly the 'need plus capacity' target from exchange 1. The gain model's headroom term keeps gains inside the 2-5 point band the expert named for normal schools and lets them reach 5 points only at the lowest completion rates. Limitations: the $20k per-student program cost is a calibration constant, not a data-driven one; the z-score weighting is sensitive to the tails (a very low completion school with a strong earnings score can outrank a balanced one); and the ROI denominator assumes the school deploys the full absorption capacity for 5 years, which is an upper bound on realized deployment.

## Subtask 3: Produce the optimized, prioritized 1-to-N candidate list with per-school investment amounts, the expected return on each

### Problem

Produce the optimized, prioritized 1-to-N candidate list with per-school investment amounts, the expected return on each investment, and the 5-year disbursement schedule, spending the full $100M each year starting July 2016, subject to the operational constraints that emerged from expert consultation.

### Analysis

Assumptions: (1) The $100M/yr budget is a hard annual ceiling, and the 5-year program is 5 identical years (no front- or back-loading of the total). (2) Per exchange 7, money is disbursed in annual tranches against milestones, not as a lump sum; the first tranche is smaller (planning year) and later tranches are contingent on demonstrated progress. (3) Per exchange 8, no school receives more than its absorption cap per year, and per exchanges 2 and 8 no school receives less than $0.5M/yr (below that the grant is too small to matter). (4) Per exchange 10, the funder retains the right to withhold or redirect the next tranche if a school stops improving, so the allocation is structurally reversible year by year. (5) Per exchange 9, retention moves in years 1-3 and completion in years 3-5, so the schedule funds planning in year 1 and full intervention in years 2-5. Allocation algorithm: sort fundable schools by ROI descending (score as tiebreak), then greedily assign each school min(absorb_i, remaining budget, min_grant) until the $100M/yr is exhausted or no school remains eligible. The result is a deterministic, reproducible allocation.

### Modeling Process

Greedy knapsack with uniform values-per-dollar (all schools valued by ROI). Inputs: fundable set F (|F| = 1,972 after floors), ROI_i, a_i, B = 100e6/yr. Initialize remaining = B, list L = []. For each school in F sorted by (ROI_i desc, S_i desc): amt_i = min(a_i, remaining, 5.0e6); if amt_i < 0.5e6 stop; L += (i, amt_i); remaining -= amt_i; stop if remaining <= 0. Per-school 5-year schedule (tranches, in $M): year 1 = 0.7 * amt_i/1 (planning-heavy), years 2-5 = level; concretely tranche_j(i) = amt_i * w_j with w = (0.7, 1.0, 1.0, 1.0, 1.0) renormalized so sum = 5 * amt_i; equivalently year-1 tranche is 70% of the level tranche. Milestone gate at end of year 2: if the school's RET_FT4 (year-1-to-year-2 retention) has not improved or its C150/C200 has declined, the funder withholds the year-3 tranche and redirects it to the next school on the list (exchange 10). Program-level expected outcome: sum over funded schools of g_i * K_i * UGDS_i = 6,941 additional completions over 5 years, i.e. ~1,388 per year, against $500M total spend = 13.9 additional completions per $1M, or 3.83 students per $1M at the median funded school. Parameter table carried from the previous task: all absorption and floor values unchanged; tranche weights w = (0.7, 1, 1, 1, 1), source: expert exchange 7 (first year smaller for planning).

## Subtask 4: State the operating rules that make the 5-year program reversible and the ROI concept auditable: the annual disbursement

### Problem

State the operating rules that make the 5-year program reversible and the ROI concept auditable: the annual disbursement schedule, the milestone gate, and the redirect rule for underperforming schools, as specified by the expert consultation.

### Analysis

Assumptions: (1) Per exchange 7, disbursement is annual against agreed milestones, renewal contingent on progress; a lump sum would forfeit the control point the funder needs. (2) Per exchange 9, the expected signal sequence is: planning in year 1; retention/persistence and course-pass movement in years 2-3; completion-rate movement in years 3-5. The gate must therefore be set where the first credible evidence appears, i.e. at the end of year 2, on retention. (3) Per exchange 10, the control point is the next payment, not the last: the funder does not claw back disbursed money, it withholds or redirects the upcoming tranche. (4) Per exchange 1, the redirect target is the next school on the prioritized list, preserving the need-plus-capacity criterion. This task fixes the governance layer so the ROI computed in the previous task is the ROI of a reversible program, not of a sunk lump sum.

### Modeling Process

Tranche schedule. For a funded school i with level annual grant amt_i: tranche_1 = amt_i * (0.7/4.7), tranche_j = amt_i * (1/4.7) for j = 2..5, so the five tranches sum to 5 * amt_i and year 1 is 70% of a level tranche (exchange 7: first year smaller, for planning and build-out). Milestone gate G at end of year 2: G_i = 1 if RET_FT4_{i, yr2} >= RET_FT4_{i, yr1} - 0.01 (no more than 1 point of slippage) OR C150_i (or C200_i) has not declined versus the prior cohort; otherwise G_i = 0. Redirect rule: if G_i = 0, tranche_3(i) is withheld and re-assigned to the highest-ROI unfunded school on the list, subject to that school's absorption cap; if the receiving school is also already funded at its cap, the withheld amount is re-offered to the next school in turn; if no school can absorb it, it is carried to the next year's budget. If G_i = 0 for a second consecutive year, the school exits the program and the remaining tranches are fully redirected. Expected program effect under the gate: with 20 funded schools and an assumed 80% gate pass rate, 16 schools receive the full 5-year schedule (expected completions 6,941 * 16/20 = 5,553) and 4 schools receive 2 years plus redirect; the redirect recovers roughly 0.3 * 4 * 5.0M = $6M of year-3 spend into higher-ROI schools, lifting program ROI from 13.9 to about 14.2 additional completions per $1M. Parameter table: gate threshold = 1.0 retention point, interval [1.0, 3.0], source: expert exchange 9 (retention is the first credible signal); first-year weight 0.7, interval [0.5, 0.8], source: expert exchange 7; consecutive-fail exit rule = 2 years, interval [2, 3], source: expert exchange 10.

### Outcome Analysis

The governance layer converts the allocation from a 5-year sunk commitment into a milestone-contingent program, which is what makes the ROI number honest: the 6,941-completion figure is the value of a program that stops funding schools that stop improving, not the value of money already spent. Biases and limitations: the gate uses only the two scorecard variables available in this dataset (RET_FT4, completion), so a school that improves earnings or equity but not retention would be penalized; the 80% pass-rate assumption for the redirect arithmetic is a planning estimate, not a measured one; and the redirect rule assumes the funder can re-deploy a withheld tranche within the same fiscal year, which in practice depends on the foundation's treasury cycle. The ROI concept recommended for adoption: additional completions per $1M of disbursed grant, measured at year 5 against the school's own prior cohort baseline, with the year-2 retention gate as the interim audit checkpoint. This is reportable to the CFO from data the foundation already receives (scorecard cohorts), requires no new instrumentation, and separates Goodgrant's effect from broader trends by using each school as its own baseline.
