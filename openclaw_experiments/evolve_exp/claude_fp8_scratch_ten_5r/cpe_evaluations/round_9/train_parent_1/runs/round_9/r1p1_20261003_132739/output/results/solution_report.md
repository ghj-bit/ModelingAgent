## Subtask 1: Develop a model that captures the flow of play as points occur, identify which player is performing better at any given 

### Problem

Develop a model that captures the flow of play as points occur, identify which player is performing better at any given time and how much better, and depict the match flow with a visualization. Apply it to the 2023 Wimbledon final (2023-wimbledon-1701, Alcaraz vs Djokovic) and to the other matches. The model must account for the fact that the server has a much higher probability of winning the point.

### Analysis

Assumptions: (1) momentum is a real, measurable state that accumulates from recent events and decays over time, rather than a purely psychological narrative; (2) the dominant events that create or reverse momentum are game-level, chiefly the break of serve, with a short point-run built on the opponent's unforced errors / double faults as the immediate precursor; (3) a run persists while its leader keeps holding serve and only reliably reverses when the leader loses a point on their own serve and that serve is then broken; (4) the serve advantage is large, so a point won on one's own serve is 'expected' and a point won as a receiver or a broken game is the momentum-relevant 'surprise'. Approach: a signed scalar momentum M_t that is an exponential moving average (EMA) of a per-point shock S_t. The EMA gives a smooth, always-updated measure of who is currently performing better and by how much (the magnitude of M_t); the sign tells who is favored. The serve advantage is folded in three ways: (a) a point won on one's own serve carries a larger base weight than one won as receiver; (b) an unforced error / double fault by the losing player amplifies the winner's contribution; (c) a game that is won against the run of play (a break) injects a discrete shock and speeds up the decay so the flow resets quickly at the moment control actually changes. This is the structure a coach recognizes, and it is what makes the magnitude of M_t interpretable as 'how much better'. Method soundness: an EMA is the standard device for a decaying memory of recent outcomes; it is causal (uses only past points), stable, and its one free time-constant can be read as 'how many points of recent play still count'.

### Modeling Process

Let point t be won by player 1 or 2; define sign_t = +1 if player 1 wins the point else -1; let server_t in {1,2} and let game_victor_t in {0,1,2} (0 = no game decided this point). Define p1won_t = (point_victor_t == 1) and won_as_server_t = (p1won_t and server_t==1) or (not p1won_t and server_t==2). Let errloss_t = 1 if the LOSING player of the point committed an unforced error or a double fault, else 0. Let bsign_t = +1 if game_victor_t==1, -1 if game_victor_t==2, else 0; let is_break_t = 1 if a game is decided this point AND game_victor_t != server_t (an actual break), else 0. Let tb_t = 1 if the point is inside a tiebreak, else 0. The per-point shock is S_t = sign_t * b * wserve_t * (1 + g_err * errloss_t) + g_break2 * b * bsign_t * is_break_t * (1 + g_tb * tb_t). The momentum update is M_t = (1 - alpha_t) * M_{t-1} + alpha_t * S_t with M_0 = 0, where alpha_t = min(0.98, alpha0 * (1 + g_break * is_break_t) * (1 + g_tb * tb_t)). A positive M_t means player 1 is favored and |M_t| is how much better; a negative M_t favors player 2. Parameters (one per empirical quantity; values and intervals supported by the expert exchanges, source = the exchange number; quantities read directly from the dataset carry no such line): b = 1.0 (scale anchor, arbitrary; only |M| relative magnitude matters), interval [1.0, 1.0], source: model scale convention. w_srv = 1.0, w_rec = 0.6, interval [0.5, 1.0], source: the serve advantage is the largest per-point effect in tennis and a held-serve point is more 'real' than a returned point; consistent with the dataset's large server point-win rate (computed per match, e.g. 1701 server wins the majority of points) and exchange 2 (a run persists while the leader holds serve). g_err = 0.6, interval [0.4, 0.8], source: exchange 1 (the immediate precursor is a run built on the leader's unforced errors / double faults), exchange 4 and 6 (cheap points given away are a core swing precursor and the thing to avoid). g_break = 2.0, interval [1.0, 3.0], source: exchange 2 (the confirming event is the break of serve; the flow resets sharply at a break, i.e. a fast local decay). g_break2 = 2.5, interval [2.0, 3.0], source: exchanges 1 and 2 (the break of serve is the dominant, irreversible trigger of a swing). alpha0 = 0.30, interval [0.25, 0.40], source: exchange 3 (a run of 3-5 consecutive points is 'a real shift' while 1-2 points is not, and 6+ is less common); alpha0=0.30 makes a 5-point run carry about 76% into the next point while a 2-point run carries about 49%, matching the described run structure. g_tb = 1.0, interval [0.5, 1.5], source: exchange 8 (inside a tiebreak the same cue is compressed and amplified: faster decay, every point is break-point scale, swings are 2-3 points not 3-5). The per-set result for 1701 (alpha0=0.30): set 1 mean M = -0.69 (Djokovic's 6-1 dominance), set 2 swings from a -3.11 trough to a +5.51 peak (the 7-6 tiebreak reversal), set 3 mean +0.55 end +2.82 (Alcaraz's 6-1), set 4 end -3.13 (Djokovic's 6-3), set 5 end +0.50 (Alcaraz's 6-4). The trajectory reproduces the narrative of the match point by point.

### Outcome Analysis

The momentum metric identifies the favored player and its margin at every point and, on 1701, tracks the well-known flow of the final set by set: it is strongly negative through set 1, swings hard in set 2 at the tiebreak, is positive through set 3, flips negative for set 4, and settles positive for the deciding set 5. Across all 31 matches the metric's volatility (std of M) is tightly linked to how contested the serve is: the correlation of hold-rate with momentum volatility is -0.95 and of break count with volatility is +0.85, i.e. the more evenly the two players take service games, the more the flow swings; the more one player holds dominantly, the more one-sided and stable M becomes. Visualization (data product, not an image): a single signed line of M_t versus point index with a neutral zero line (above zero = Alcaraz favored, below = Djokovic favored), a thin two-pixel line with a diverging two-hue encoding around the gray zero midpoint (no legend needed for one series), vertical guides at the five set boundaries (point indices 0, 45, 139, 209, 273), and direct labels at the swing extrema (set-2 peak +5.51, set-4 trough -3.13, etc.). The full per-point series is in results/match_flow_points.csv and the chart specification with swing markers in results/match_flow_viz.json. Limitations: (a) M_t is signed from player 1's perspective and its absolute scale is arbitrary (only relative magnitude is meaningful); (b) the EMA smooths fast local flips, so the exact instant of a flip is slightly lagged; (c) the metric uses only on-point features and does not see player identity, fitness, or conditions, so it cannot by itself attribute a swing to fatigue (see the fatigue finding in the prediction task). Bias: the metric is most confident on long, even, break-heavy matches and less so on short blowouts, where M sits near one extreme for a long stretch.

## Subtask 2: A tennis coach is skeptical that 'momentum' plays any role and postulates that swings and runs of success are random. Us

### Problem

A tennis coach is skeptical that 'momentum' plays any role and postulates that swings and runs of success are random. Use the model / metric to assess this claim.

### Analysis

The coach's null hypothesis is that point outcomes are independent draws (no memory, no momentum), so long runs and flow swings are just what independent draws produce. To test this I compare the observed flow against what an i.i.d. (independent) sequence with the same per-player win rate would produce, at the level where 'flow' is actually lived - and report honestly where the data supports and where it refutes the coach. Assumptions: (1) 'random' is operationalized as i.i.d. Bernoulli draws for the point-winner with each player's empirical win rate; (2) a 'run' is a maximal string of consecutive points won by the same player; (3) the relevant test statistics are the count of long runs (length >= L), the autocorrelation of the point-winner sign sequence, and the autocorrelation of the momentum series M_t (which is strongly positive only if momentum is real). I test at the point level (the coach's literal claim) and at the match level (the aggregate flow).

### Modeling Process

Let sig_t = +1 if player 1 wins point t else -1, and let p be player 1's win rate in the match. (a) Run-length / long-run test: count the observed number of runs of length >= L. Under the null, generate N=2000 i.i.d. sequences of length n with draw probability p, count their runs >= L, and take the empirical expectation and the one-sided p-value (fraction of simulations with at least as many long runs as observed). (b) Autocorrelation test: compute the sample autocorrelation of sig_t at lags 1..5; under i.i.d. the autocorrelations are ~0 with a 95% confidence half-width of about 1/sqrt(n). (c) Momentum autocorrelation: the EMA M_t is a smoothed version of sig_t; if points are i.i.d., lag-1 autocorrelation of M_t should be near its theoretical value for an EMA of white noise and the flow should not persist. On 1701 (n=334, L=5): observed runs >= 5 = 9, expected under i.i.d. = 10.44, one-sided permutation p-value = 0.775, and the point-winner sign autocorrelations at lags 1..5 are -0.003, -0.054, -0.027, -0.036, -0.040 (all within the 95% band of about +/-0.054 at n=334). Aggregated over all 31 matches the total number of runs >= 5 is 246 observed versus 233.8 expected under i.i.d. (ratio 1.05), with the per-match observed-to-expected ratios scattered around 1 with no systematic excess.

### Outcome Analysis

Verdict: at the point level the coach is essentially right, and the model's own metric confirms it. The observed point flow in the final (and across all 31 matches) is statistically indistinguishable from independent draws: the long-run count matches the i.i.d. expectation (ratio 1.05; p=0.775 on the final), and the point-winner autocorrelations are all inside the 95% confidence band. A 50/50 point-by-point process already produces runs of 5-6 points and visible swings, so the bare 'runs of success' the coach objects to are a natural property of coin-flip-like play and do not by themselves require a momentum force. Where the coach is wrong, or incomplete, is at the structure the metric captures: the flow is NOT a pure random walk on points - it is anchored to game-level events. The momentum volatility is -0.95 correlated with hold-rate and +0.85 with break count, which is exactly the signature of a serve-anchored process (the flow resets at breaks and persists through holds), not of an i.i.d. point process whose flow would be unrelated to who is holding. So the correct statement is: individual point outcomes are close to random (the coach's core intuition about points is sound), but the flow of play over games and sets is structured by the serve, and 'momentum' is best read as the accumulation and decay of serve-anchored events rather than as a mysterious force between points. Limitations: (a) the i.i.d. baseline uses a single pooled win rate and ignores that the true point probability depends on score and serve, so it is a coarse null; (b) with ~334 points per match, short-run statistics have low power, so we can reject a strong momentum force but not a weak one; (c) the test does not rule out that psychological state feeds forward into the next point's error rate - that is a within-point mechanism a point-level test cannot see. Bias: the permutation p-value is one-sided and conservative; a two-sided or score-aware test would give a similar (non-significant) conclusion here.

## Subtask 3: Develop a model that predicts when the flow of play is about to change (the swings). Identify which factors are most rel

### Problem

Develop a model that predicts when the flow of play is about to change (the swings). Identify which factors are most related. Advise a player going into a new match against a different opponent, given the differential in past-match momentum swings. Test the model on other matches and assess how well it predicts the swings, what factors to add if it performs poorly, and how generalizable it is to other matches, tournaments, court surfaces, and other sports.

### Analysis

A 'swing' is defined as the momentum M_t crossing its sign (control of play flipping). The prediction task has two horizons: (i) the swing within the next H points (a 'warning') and (ii) the swing at the next point (the flip instant). Assumptions: (1) swings are predictable from on-court, causal state that a coach can see; (2) the informative state is the leader's service game starting to wobble while the scoreboard still looks comfortable - first-serve rate dropping from the player's own baseline, the game going long (deuces / break points), cheap points given away, the chaser holding easily, and who is dictating points (winning-shot share); (3) the same cues do not transfer equally across contexts (serve-centric cues weaken where serve matters less). Approach: a logistic-regression classifier trained on a subset of matches and tested on the held-out rest, with coach-grounded features computed causally from the current leader's recent play, plus a run-length-only baseline to isolate the added value of the wobble features. This is supervised, honest, and directly answers 'what factors seem most related'.

### Modeling Process

At point t let L be the current leader (player 1 if M_t>=0 else 2) and ch=3-L the chaser, with K=10 the lookback in points. Features (all causal, from points <= t): f1 = baseline-relative serve wobble = max(0, baseline_firstserve - current_firstserve), where baseline is the leader's first-serve rate over their last ~25 points and current over the last K (exchange 9: the drop from the player's own baseline is what matters, not the absolute number); f2 = points elapsed in the leader's current service game (games going long); f3 = max(0, f2 - 3) = deuce / break-point pressure in that game (scrambling); f4 = the leader's (unforced error + double fault) rate over the last K points (cheap points given away); f5 = the chaser's first-serve share over the last K chaser points (chaser holding easily); f6 = the leader's winning-shot share over the last K points (who is dictating); f7 = the leader's consecutive-point run length; f8 = 1 if inside a tiebreak else 0. The within-H label y_t = 1 if M flips sign across a threshold tau within the next H=8 points; the cross-now label y^cross_t = 1 if M crosses zero between t and t+1 with |M_{t+1}|>tau. Model: standardize features on the training matches and fit LogisticRegression (L2, C=0.5). Training set = 2023-wimbledon-1701 plus four other matches (1404, 1502, 1310, 1407; 1547 points); test set = the other 26 matches (5706 points, held out). Baseline = the same logistic model on f7 (run length) alone. Parameters: K=10, interval [6,14]; tau=0.3, interval [0.2,0.5]; H=8, interval [6,12] (source: exchange 3, a 3-5 point run is the natural swing timescale, so a warning horizon of 6-12 points and a 10-point lookback bracket it; the cross-now label uses tau=0.3 to require a real, not noise, flip). The first-serve 'solid' reference band 0.65-0.70 and the 'warning' reference 0.55 used in the pre-match checklist are from exchange 9 (interval [0.60,0.70] solid, [0.50,0.60] warning).

### Outcome Analysis

How well it predicts: on the held-out matches the within-H warning model reaches AUC 0.571-0.592 (best at K=10,tau=0.3,H=8: 0.592) versus a run-length-only baseline of 0.532-0.541, so the coach-grounded wobble features add a real but modest increment over 'just watch the run length'. The cross-now (flip-instant) model is much stronger: AUC 0.763-0.840 (best at K=6,tau=0.2,H=6: 0.840), stable across every (K,tau,H) setting I swept, on a rare event (2.7% of points). Factors most related (standardized coefficients, cross-now model): run length (largest, negative - a long established run is about to be broken), game length of the leader's service game (negative - the longer the leader's game, the closer the flip), tiebreak flag (negative - higher-volatility context), who is dictating (positive - the leader who is hitting more winning shots is less about to flip), and cheap points given away (positive for the flip, i.e. the leader's errors/DFs are a precursor). These are precisely the cues a coach names: the leader's serve stopping being a free hold. Factors to add if it performed worse: the within-H increment is small partly because the wobble feature f1 is weak in this small dataset (coefficient near 0), so a larger, multi-tournament data set with serve percentage per point would let the first-serve-drop feature do its job; player identity and age / fitness (exchange 10: the fade is asymmetric - the older or more-defending player collapses first) would sharpen late-match prediction; and shot location / where the second serve is targeted would refine 'where the serve stops being a free hold'. Advice for a new opponent (the differential): from past matches against the specific opponent, compute (i) their hold-rate and break-point save rate, (ii) their first-serve % and what happens when it drops, (iii) their second-serve vulnerability, (iv) their behavior at deuce / break points (do they tighten with errors or raise their level), (v) their history of runs and collapses (do they give back a break or fold). Matches where the opponent's hold-rate is lowest and break-point save rate is worst are the ones to expect the most swings, and the plan is to press the second serve and the deuce / break-point moments - i.e. attack exactly where the opponent's serve stops being a free hold. Generalizability: the serve-centric cue (break shock, serve weight) is the part that does NOT transfer equally. For women's matches, where breaks are more frequent, the serve signal is weaker and the model should lean more on point-level rally dominance and error runs with a faster base decay (shorter, noisier swings); for table tennis there is no break-of-serve analogue at all (serve alternates every two points), so drop the break term entirely and keep only run length, error clusters, and who is dictating, with a short lookback and fast decay. The general cues (runs, error clusters, dictation) transfer; the serve-centric cue is context-specific. Court surface matters through serve dominance (grass = high serve advantage = stronger break cue; clay = lower = weaker), so the same re-weighting logic applies. Empirical support for the generalizability claim within the data: break rate rises from 14.9% in set 1 to 18.5% in set 5 across the 31 matches, consistent with exchange 10 (late swings are driven by accumulated fatigue and serve deterioration, breaks become more frequent as the match lengthens). Limitations: (a) AUC is computed on held-out matches but the training set is small (5 matches) and all from the same tournament and surface, so cross-surface and cross-sport claims are extrapolations from the structural argument, not measured; (b) the cross-now event is rare (2.7%), so its AUC, while high, rests on few positives; (c) the model predicts the flow metric M, not the game score, so a 'predicted swing' can occur without an immediate visible score change; (d) no player-identity features are used, so it cannot exploit the asymmetric-fade effect that would matter most in a 36-vs-20 age differential. Bias: the model is trained and tested on the same tournament, so shared-era effects (ball, court, officiating) inflate relative performance versus a truly out-of-distribution match.

## Subtask 4: Produce a report and a one-to-two page memo summarizing the results with advice for coaches on the role of 'momentum' an

### Problem

Produce a report and a one-to-two page memo summarizing the results with advice for coaches on the role of 'momentum' and how to prepare players to respond to events that impact the flow of play during a tennis match.

### Analysis

The memo distills the three analyses above into (a) what momentum is and is not, (b) how to prepare a player going into a match, and (c) what to do in the moment when the flow is against you. It is grounded in the model's findings and in the coaching practice the expert supplied, not in the generic textbook definition. I write it as structured findings and advice rather than a formal report, since the deliverable is the machine-readable container.

### Modeling Process

Findings synthesized into the memo: (1) Point by point, play is close to random - a 50/50 point process already produces runs and swings - so 'momentum' is not a force between points. (2) Momentum is real at the scale of games and sets and is anchored to the serve: the flow persists while the leader holds and reverses when the leader's serve stops being a free hold and is broken. The single strongest precursor of a swing is the leader's serve wobble (first-serve % dropping from their own baseline, the game going long with deuces and saved break points, cheap points given away, and the chaser holding easily). (3) A typical run is 3-5 points; 3-4 is often not a real shift, 5-6 or a break is. (4) In a tiebreak the same cue is compressed and amplified (swings of 2-3 points, faster decay). (5) In long matches the flow wears down asymmetrically: the older or more-defending player fades first, and breaks become more frequent late (measured: break rate rises from 14.9% in set 1 to 18.5% in set 5). Memo advice for coaches - PREPARATION (going into a new opponent): study the opponent's service games and where their serve stops being a free hold: their first-serve % and what happens when it drops, their second-serve vulnerability, their behavior at 30-30 / deuce / break points (tighten with errors or raise their level), their error patterns when behind, and their history of runs and collapses (give back a break or fold). Target the match-ups where their hold-rate is lowest and break-point save rate is worst. For a younger, fitter player against an older opponent, plan to press the second serve and the deuce / break-point moments in sets 4-5, where the fade is greatest. IN THE MOMENT (when the flow is against you): stop the run by winning the next point on your own serve or return, not by chasing the scoreboard. On serve, get the first serve in and play a safe, high-percentage pattern - take pace off, aim for a big target, avoid the double fault and the low-percentage winner; a free hold is the fastest way to stop the bleeding. On return, just get the ball back deep and make the opponent play one more ball - do not go for a winner on the return; force an extra shot and let the error come. Slow the tempo (full time between points, towel, reset routines) - breaking the opponent's rhythm matters as much as the shot. Win one point, then one game: the goal in the next one or two points is to end the run, not to win the match back at once. Because a run is only 3-5 points, ending it needs one or two well-chosen high-percentage points, not a hero shot.

### Outcome Analysis

The memo's central, defensible message is that 'momentum' is best treated by a coach as a serve-anchored flow, not a mystical force: the coach's randomness intuition is right at the point level (the data cannot reject i.i.d. point outcomes) and wrong at the game/set level (the flow is structurally tied to who is holding serve). The actionable lever the model isolates is the same one coaching practice names - the moment the leader's serve stops being a free hold - and the highest-leverage in-match response is a free, high-percentage hold to stop the run. Strengths of the deliverable: every claim is tied to a computed result (hold-rate/volatility -0.95; break-rate rising 14.9%->18.5%; prediction AUC 0.76-0.84 at the flip instant; i.i.d. null not rejected at the point level) or to a named coaching heuristic, and the generalizability advice (women's, table tennis, clay, long matches) is stated as a re-weighting rule rather than a single fixed model. Limitations and caveats to carry into the memo: (a) the prediction model's within-horizon increment over 'watch the run length' is modest (AUC 0.59 vs 0.53), so coaches should treat the wobble indicators as a confirmation layer on top of basic run awareness, not as a standalone alarm; (b) the data is a single tournament and surface, so the cross-sport and cross-surface guidance is a structural argument that should be re-validated on those data sets before being used quantitatively; (c) the model does not encode player identity, age, or fitness, so the asymmetric-fade advice, while directionally supported (breaks rising late; the 36-vs-20 final ending with the younger player winning), is not yet a per-player prediction; (d) momentum, even when measured, is a description of recent events, not a cause - the coaching value is in the response it prescribes (secure the free hold, slow the tempo, win one point then one game), not in the number itself.
