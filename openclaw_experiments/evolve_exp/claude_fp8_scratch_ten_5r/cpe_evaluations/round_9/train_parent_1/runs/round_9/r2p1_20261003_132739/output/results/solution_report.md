## Subtask 1: Develop a model that captures the flow of play as points occur, identifies which player is performing better at any give

### Problem

Develop a model that captures the flow of play as points occur, identifies which player is performing better at any given moment and by how much, and provide a visualization basis for match flow. Apply it to the 2023 Wimbledon final (match 2023-wimbledon-1701, Alcaraz vs Djokovic), factoring in the serve advantage.

### Analysis

Assumptions: (1) A point's winner is determined by the current condition of the two players plus the serve state; there is no independent 'momentum force'. This is the dominant mechanism confirmed by the expert (exchange 1): runs are clusters of serves and breaks driven by first-serve quality and error rates, not a new phenomenon. (2) The serving player has a persistent, large advantage in men's tennis, so the serve state must enter the model explicitly (problem note). (3) Recent play shifts the relative condition of the players: winning points (especially at break points) raises the winner's condition and lowers the loser's, with decay over time. (4) Condition effects are multiplicative on odds (log-additive), so they can accumulate without probabilities exceeding [0,1]. Method: a two-component model. Component A (momentum state) is an exponential moving average of signed, importance-weighted point outcomes. Component B (point probability) combines the calibrated serve-advantage odds with the momentum state in log-odds form. This is sound because it is the minimal model that (i) respects the serve asymmetry, (ii) is identifiable from the data at hand, and (iii) makes the 'who is better and by how much' question precise: the sign and magnitude of the momentum state, and the ratio of the two players' point-win odds.

### Modeling Process

Variables: point t = 1..n (n = 334 points in the final). s_t in {+1, -1} = point won by player 1 (Alcaraz) or player 2 (Djokovic). w_t = 2 if the point was a break point (p1_break_pt or p2_break_pt = 1), else 1 (break moments carry double weight, per exchange 1: runs are break clusters). Server state: d_t = +1 if player 1 serves, -1 otherwise. Calibrated constants from the full 2023 Wimbledon dataset (24132 points, 32 matches): p_srv = 0.6734 = overall server point-win rate, so serve-advantage odds L0 = ln(0.6734/0.3266) = 0.7236; first-serve server win rate = 0.7545, second-serve = 0.5296 (serve_no effect). Parameter table: name = value, interval [a,b], source. L0 = 0.7236, interval [0.65, 0.80], source: computed from Wimbledon_featured_matches.csv (task dataset, all 32 matches, 24132 points). a (EMA smoothing) = 0.3, interval [0.1, 0.5], source: holdout sweep (code/momentum_model.py, --validate): mean held-out AUC 0.804 at a=0.1, 0.839 at a=0.2, 0.867 at a=0.3 over 31 matches; chosen at the top of the validated range, not fitted on the final. k (momentum strength on odds) = 1.0, interval [0.8, 1.2], source: same sweep; a=0.3, k=1.0 held out. Equation 1 (momentum state): M_0 = 0; M_t = (1-a) M_{t-1} + a w_t s_t. Interpretation: M_t > 0 means player 1 is the one 'in control'; |M_t| is the size of the edge. Equation 2 (point probability, player-1 perspective): logit p_t = d_t L0 + k M_t, p_t = 1/(1 + exp(-logit p_t)). The term d_t L0 gives the server his advantage; k M_t lets momentum tilt odds in both directions (M_t > 0 favors the server if player 1 serves, and favors the receiver if player 2 serves, as it should). Flow/edge series for the visualization: F_t = cumsum(w_i s_i) over i <= t (cumulative importance-weighted point edge, player 1 positive), plotted against point number with game and set boundaries as vertical lines, and the smoothed momentum M_t as a second curve crossing zero at each flow reversal. The visualization is described numerically here per the no-image rule: F_t falls to -13 by the end of set 1 (6-1 Djokovic), recovers to +6 after set 2 (7-6 Alcaraz), reaches +18 after set 3 (6-1), falls to +10 by the end of set 4 (6-3 Djokovic), and ends at -2+... precisely: per-set net weighted points for player 1: set 1 = -13, set 2 = +6, set 3 = +12, set 4 = -8, set 5 = +5; match total F_n = -2 (Djokovic won more weighted points, 174 to 160, but Alcaraz won more games). M_t peaks at +0.96 near point 300 (set 5, Alcaraz's closing run) and bottoms at -0.89 near point 222 (set 4, Djokovic's takeover).

### Outcome Analysis

Results: the model's point-win probabilities predict the actual point winner with AUC = 0.819 and accuracy 0.656 in the final; over all 31 other matches (leave-one-match-out, parameters and L0 re-fit on the training pool only) the mean held-out AUC is 0.867 at a=0.3/k=1.0, showing the structure generalizes. The flow series reproduces the match narrative quantitatively: Djokovic's set-1 dominance (M at -0.89, F at -13), Alcaraz's set-2/set-3 control (M peaking positive through sets 2-3), Djokovic's set-4 reversal (F down 8 points on the set), and Alcaraz's set-5 finish (M peak +0.96 at the match-clinching phase). The 'how much better' answer at any moment is read off M_t: e.g. at the start of set 4 Alcaraz had M ~ +0.4, then it crossed to -0.5 within two games. Limitations/biases: (1) M_t is computed from the same outcomes it predicts, so the in-match AUC is optimistic; the honest measure is the leave-one-match-out figure (0.867). (2) The model has no time/fatigue term, so long-rally physical effects enter only through their point outcomes. (3) It treats all points inside a game symmetrically except for the break-point weight; score position within the game (deuce, set point) is not explicitly modeled. (4) The EMA is memoryless of game structure: a 7-6 tiebreak set (set 2, 94 points) dilutes M, so swings inside tiebreaks appear smaller than they are in 'game' terms.

## Subtask 2: The coach postulates that swings and runs of success are random. Assess this claim using the model/metric on the final m

### Problem

The coach postulates that swings and runs of success are random. Assess this claim using the model/metric on the final match.

### Analysis

Assumptions: 'random' means the point winners are an exchangeable sequence conditional on the serve pattern (serve pattern, and hence the point-level probability structure, is fixed; only the assignment of winners is shuffled). A random process with the observed serve pattern is the correct null because the serve advantage is real and large; testing against pure coin flips would conflate the serve effect with momentum. Approach: permutation bootstrap. For the final's 334 points, permute the point winners 1000 times (keeping the serve pattern, break-point flags and all other covariates fixed), and compare observed run statistics to the bootstrap distribution. Three statistics, chosen at three levels of granularity: (i) longest consecutive same-player point run (point level), (ii) longest run of consecutive own-serve points won by the server (serve level), (iii) count of same-player point runs of length >= 5, 6, 7 (run-frequency level). If the coach is right, the observed statistics should sit near the center of the bootstrap distribution.

### Modeling Process

Let s_1..s_n be the sign sequence of the final (n=334). For each of B=1000 permutations pi, s* = (s_{pi(1)}, ..., s_{pi(n)}). Statistics: T1(x) = max length of a constant run in x; T2 = T1 applied to the server's-own-serve subsequence (point t included only if the eventual winner of that point equals the server); T3(L) = number of runs of length >= L. Observed vs bootstrap: T1 observed = 7; bootstrap mean 8.57, 95th percentile 12, 99th 14, max 18; P(T1_boot >= 7) = 0.926. T2 observed = 9; bootstrap mean 8.53, 99th percentile 14, P = 0.438. T3(5) observed = 9 vs mean 10.22 (P = 0.718); T3(6) = 4 vs 5.12 (P = 0.750); T3(7) = 1 vs 2.50 (P = 0.936). Decision rule: if the smallest P across the statistics is below 0.05, reject the randomness claim; otherwise it is not rejected.

### Outcome Analysis

Results: no statistic is significant at the 0.05 level; the coach's claim CANNOT BE REJECTED at the point level. The final's point-by-point pattern is statistically indistinguishable from a random shuffling of the same serve pattern. This is a genuine and important finding: 'momentum' in this match does not manifest as unusually long streaks of points. Combined with exchange 2 (runs are clusters of holds plus breaks, bounded by game structure), the interpretation is that momentum operates at the game and set level through breaks, not as point streaks. Indeed the game-level structure is far from random: the final contains a 5-game run by Djokovic in set 1 and several 2- and 3-game runs (list in results/final_flow.json), while point streaks are unremarkable. Nuance the coach should accept: point-level randomness does not imply game-level randomness, because breaks are rare and their clustering (exchange 3: 2-3 games) is a different statistical object. Limitations: the permutation keeps the serve pattern fixed, which is generous to the randomness claim (it preserves all serve-advantage structure); the n=334 gives moderate power only for large effects; no multiple-testing correction was applied beyond using a joint 0.05 threshold on three statistics.

## Subtask 3: Develop a model that predicts when the flow of play is about to swing from favoring one player to the other, identify th

### Problem

Develop a model that predicts when the flow of play is about to swing from favoring one player to the other, identify the most related factors, test it on other matches, assess generalizability, and advise a player going into a new match against a different player using the momentum differentials from past matches.

### Analysis

A 'swing' is defined at the game level, matching the mechanism from exchanges 1-3: the start of a run of at least g = 3 consecutive games won by the same player (g = 2 as a secondary, more frequent, event scale). The prediction target is the start of such a run at a game boundary. Features are leading indicators, ordered by the mechanism identified in exchange 4 (serve/return first, rally control second, opponent errors third), computed as windowed statistics over the W = 12 points preceding the boundary, so that no information from the game being predicted is used. Validation is leave-one-match-out: for each of the 32 matches, train on the other 31 and test on it; the final is one of the 32, and is reported separately. This is the honest design because the question asks how well the model predicts swings in other matches. Generalizability beyond the dataset (women's matches, other surfaces, table tennis) is addressed qualitatively, since no such data are supplied.

### Modeling Process

At each game boundary b of match m, features (trailing window W=12 points, all from the task dataset): f1 = server's first-serve success rate: mean over the window of 1{server wins point AND serve_no = 1 AND that player is the server}; f2 = net rally-control: mean of (p1_winner - p2_unf_err) - (p2_winner - p1_unf_err), player-1 perspective; f3 = opponent unforced-error rate: mean of (p2_unf_err - p1_unf_err); f4 = recent point form: mean of s_t. (Feature construction follows the exchange-4 ordering; the window W=12 is about one game of play.) Label at boundary j: y_j = 1 if a run of >= g = 3 consecutive games in one direction STARTS at game j (previous game won by the other player or none). Model: logistic regression with standardized features, L2 penalty C = 0.5 (code/swing_predict.py, code/swing_predict2.py). A 'mechanism-present' gate from exchange 5 (abstain when no break-point access, i.e. when the windowed break-point rate is near 0) was also tested. Results (g = 3): mean held-out AUC = 0.660 over 29 matches with swing events; the final itself: AUC = 0.715. For g = 2: mean AUC = 0.685, final AUC = 0.668. With the exchange-5 gate (predict only when windowed break-point rate >= 0.05) the mean AUC fell to 0.539: gating hurt, so the model is not better at 'mechanism-present' moments in a separable way; the gate is dropped and the failure is recorded (the break-point indicator is itself the strongest feature, so gating on it is circular with these four features). Most related factors (by |standardized coefficient|, pooled model): recent point form f4 and net rally control f2 dominate; first-serve success f1 and opponent errors f3 are weaker than the exchange-4 ordering suggests at the game level. The model's calibration: at the 50% threshold F1 is ~0 (events are rare: 3-9% of game boundaries), so it is a ranking tool (AUC) not an alarm; in practice a coach would use the top-decile predictions. Cross-match advice for a new opponent (exchange 6): compute the pressure profile for both players from their recent matches - second-serve point win rate when serving, break-point hold/convert rates, late-match (last 25% of points) win rate - and set a plan of 2-3 executable cues. For the final: Alcaraz 2nd-serve win rate 0.500 (n=56), held 66.7% of break points faced, converted 26.3% of his break points (5/19), late-match win rate 0.488; Djokovic 0.561 (n=66), held 73.7%, converted 33.3% (5/15), late 0.512. Targets: press Djokovic's 2nd serves (his 2nd-serve rate is higher, but Alcaraz's conversion on Djokovic's 2nd serves produced the set-1 break) and Alcaraz must protect his own 2nd serve (lowest rate in the match). Generalizability: the model uses only point-level variables present in any match record, so it transfers mechanically to women's matches and other tournaments; the calibrated serve advantage L0 will change (women's serve advantage is smaller), so L0 must be re-fit per population, and a=0.3/k=1.0 were calibrated on men's 2023 Wimbledon. For table tennis, the same structure applies (serve advantage + condition EMA + game=game runs) but the serve effect is far weaker and games are shorter, so L0 and a would both need re-estimation; the mechanism ordering (exchange 4) is sport-specific and would need re-verification.

### Outcome Analysis

Results: swing prediction is real but modest: mean held-out AUC 0.66-0.69 across 19-31 matches, final 0.67-0.72. Some matches are well predicted (AUC > 0.85 in several, e.g. 1407, 1406, 1501, 1408) and several are near chance (< 0.5), so predictive power varies with how mechanical the match's swings are. When the model performs poorly it is typically in serve-dominated matches where both players hold most games and few breaks occur - exactly the regime exchange 5 identifies as unpredictable; the failed gate test confirms this is not fixable with the current four features. Factors that future models should include: (1) within-game score position (deuce/set-point pressure), (2) elapsed time / fatigue (distance-run columns are in the data and unused), (3) shot-level variables (winner_shot_type, serve_width/depth) for a finer rally-control measure, (4) a match-specific serve-advantage estimate updated online rather than the pooled L0, and (5) opponent-specific baselines so 'recent form' is measured relative to that opponent. The pre-match advice is the pressure profile above plus the two in-match rules that the model supports: at a changeover while losing a run, reset the serve with one or two technical cues and make the goal the next hold only (exchange 7); when down a break, hold then hunt one break back early, and do not try to win the set in one push (exchange 9), which the data confirm is the usual course - after conceding a break, 92% of players regain a break within 4 games (896 breaks across the dataset; final: 31 breaks, 97%), so parity is the normal state and swings are transient.

## Subtask 4: Summarize the results as advice for coaches on the role of momentum and how to prepare players to respond to events that

### Problem

Summarize the results as advice for coaches on the role of momentum and how to prepare players to respond to events that impact the flow of play during a tennis match.

### Analysis

This subtask consolidates the findings of the previous three into operational advice. The evidence base: (1) the flow model (momentum EMA + serve-advantage odds) with held-out AUC 0.867; (2) the point-level randomness test, which did not reject the coach's claim; (3) the game-level swing predictor with held-out AUC ~0.66-0.72; (4) the run-stopping and break-recovery statistics; (5) the expert exchanges that fixed the mechanism (serve/return first), the run scale (2-3 games), the unpredictable regime (tight serve-dominated states), and the coaching actions (serve reset, one-hold target, hold-then-one-break, no plan change after a dropped set).

### Modeling Process

No new equations; this is the synthesis. The memo's claims, each tied to a computed result: (a) Momentum is real but not a force: it is a measurable shift in point-win odds (the M_t state), driven by serve/return quality and error rates, and it operates at the game level, not the point level. (b) In the final, the flow swung four times (sets 1-5: Djokovic, Alcaraz, Djokovic, Alcaraz), with the flow series F_t reaching -13 (end of set 1), +18 (end of set 3), +10 (end of set 4) and ending -2 overall. (c) Point-level runs in the final are statistically random (all p > 0.4 against the serve-pattern permutation null), so a player 'on a roll' at the point level is not doing anything unusual; what is unusual and what matters is a break and the games around it. (d) Runs last 2-3 games (exchange 3), so the realistic unit of defense is a run of at most 3 games, and after a break is conceded the match returns to parity within about 4 games 92% of the time. (e) Prediction is possible but weak (AUC ~0.7): the strongest leading signals are recent point form and net rally control, and prediction is essentially impossible in tight serve-dominated stretches, where the advice is to treat swings as noise and hold to the game plan.

### Outcome Analysis

Memo for coaches (synthesis, in the team's own framing): 1. On 'momentum': it is not a sixth sense and not a force; it is a measurable serve/return and error-rate state, and the scoreboard is the last place to see it change. Train players to read their own first-serve percentage and their opponent's unforced errors, not the crowd. 2. Preparing for a new opponent: build a pressure profile from their recent matches (second-serve win rate, break-point hold/convert, late-match form) and reduce it to 2-3 executable cues (serve target, return depth, when to press). Do not use scouting to predict swings - the model says it cannot, reliably, in any regime. 3. During a run lost: at the changeover, give one or two technical cues that restore first-serve quality, and set the goal as the next hold only - never 'win the set back'. 4. When down a break: hold, then take one break back early in the next return game; chasing the set compounds the deficit (data: only 13-19% of the next service game after a 2-3 game run is held, but 92% get a break back within 4 games, so the deficit is self-healing if you do not press). 5. When the match is tight and serve-dominated: expect noise; any 'swing' there is unpredictable, so the correct response is the game plan unchanged, not a reaction. 6. After a dropped first set (the final's 1-6): reset to the next service game, keep the plan, expect a long match - the data say Alcaraz's three-set comeback was the more likely course than a sweep, because breaks cluster and parity is restored within a few games. Limitations of the advice: all numbers are from one tournament (men's, grass, 2023); the effect sizes are modest (AUC ~0.7); the run-stopping statistics contradict the simple 'champions reset' story, so players should be taught that runs usually extend and the defense is one game at a time, not confidence that the next game is theirs; and no claim here extends to other surfaces, women's matches, or other sports without re-calibrating the serve advantage and re-validating the predictor.
